# 木属性术式系统设计文档

**岁木·枯荣精简版机制与战斗循环**

| 项目 | 内容 |
| --- | --- |
| 版本 | 0.1 |
| 日期 | 2026-11-09 |
| 状态 | 机制整理稿 |

这套术式围绕枝印、含苞、花开、落英与岁荣展开。玩家在敌人身上种下枝条，在短暂的开花窗口完成收割，再决定保留花瓣控场，还是吸收花瓣续航。

> **三度岁荣，一岁枯荣**
>
> 木属性战斗循环的设计整理稿。

## 01 文档说明

本文档整理木属性术式系统「岁木·枯荣」的精简版机制。方案以植被生命周期为核心，将攻击、控制、爆发、场地与终结技串成一条可重复的战斗循环。当前版本已经确认舍弃腐殖土，并将原资源“年轮”暂命名为“岁荣”。

文档面向战斗、数值、关卡和表现团队，用于统一机制边界与首轮原型目标。文中的百分比和持续时间均为原型基线，不代表最终平衡；岁荣为暂定命名，后续可在不改变机制的前提下替换。

> **本版确定的四个设计结论**
>
> - 核心对象只保留三类。枝印在敌人身上，落英在地面，岁荣在玩家身上。
> - 每轮只有两个决策。含苞时何时催花，落花后留场还是收瓣。
> - 花谱只改变收益形态。不新增资源条，也不改变三枝成苞的基础规则。
> - 岁荣只服务终极技。不作为普通技能消耗，不额外提供属性。

## 02 核心循环

玩家先用攻击把枝条钉入敌人体内，叠满三道后将其缚住，形成短暂的开花窗口。下一次命中引爆枝条，留下落英；落英可以留场成为控制区域，也可以用技能吸收，换取回复与下一轮强化。每完成一次花开，玩家获得一道岁荣；三道岁荣可释放终极技“一岁枯荣”。

```mermaid
flowchart LR
    A["插枝 ×3<br/>叠满枝印"] --> B["缚枝含苞<br/>定身 2.5 秒"]
    B --> C["花开<br/>下一次命中"]
    C --> D["落英<br/>留场 / 收瓣"]
    C --> E["岁荣 +1<br/>三度成一岁"]
    D --> F["留瓣<br/>控场 / 易伤"]
    D --> G["收瓣<br/>回血 / 护盾"]
    E --> H["一岁枯荣"]
```

**图 1 岁木·枯荣核心战斗循环**

循环的关键不是资源数量，而是节奏。插枝提供明确的前置目标，含苞制造一次短暂停，花开给出发力点，落英把爆发后的余韵变成下一次选择。玩家能清楚判断自己处在循环的哪一段，也能看懂敌人何时脱困。

## 03 规则与资源

以下规则是所有花谱共用的基础框架。花谱只修改“花开”和“落英”的结算，不改变三枝成苞、岁荣获取与终极技的结构。

| 对象 | 机制 | 限制与反馈 |
| --- | --- | --- |
| 枝印 | 敌方状态。直接命中或指定技能插入，最多 3 道。 | 每次攻击动作最多插 1 道；每道移速降低 10%；持续 6 秒。 |
| 含苞 | 第 3 道枝印触发。目标被枝条缠住并定身 2.5 秒，进入含苞。 | 下一次命中触发花开；含苞每存在 0.5 秒，花开伤害提高 15%，最多提高 45%；到期未引爆则枯萎。定身只限制移动，不禁止攻击和施法。 |
| 花开 | 按当前花谱结算爆发或控制，并在目标位置生成落英。 | 每发生一次花开事件获得 1 道岁荣；同一次攻击造成的多目标花开只计 1 道。 |
| 落英 | 花开后留下的唯一地面资源，持续 6 秒。 | 留场时范围内敌人减速 30%、受到木属性伤害提高 15%；用枯木逢春收瓣时转化为回血、护盾或下一次花开强化。自然消失后不生成腐殖土。 |
| 岁荣 | 玩家身上的长线资源，0 至 3 道。 | 仅用于一岁枯荣的充能，不被其他技能消耗，也不提供额外属性。满 3 道显示“岁荣圆满”。 |
| 残枝 | 花开后的短暂保护状态。 | 持续 4 秒，目标获得缚枝抗性，避免连续定身形成无限控制。 |

数值说明：以上时间、减速和伤害提升均为首轮原型基线。枝印层数、含苞时长与花开收益必须在实际手感测试后统一调整，避免为了数值平衡破坏循环节奏。

> **三个核心对象各回答一个问题**
>
> - 枝印回答“什么时候能开花”。它是敌方身上的进度条，负责把战斗推进到含苞。
> - 落英回答“花开之后拿什么”。它是地面上的战术资源，负责控场与续航之间的取舍。
> - 岁荣回答“什么时候能放终结技”。它是玩家身上的长线充能，只服务一岁枯荣。

## 04 两处核心决策

木系的深度来自两次清晰的选择，而不是第三套资源。第一次发生在含苞形成后，第二次发生在落英落地后。两次选择都必须能在一眼之内判断收益与风险。

### 4.1 催花时机

含苞形成后，下一次命中即可触发花开。玩家可以立刻引爆，也可以利用重击或短暂走位蓄势。蓄势越久，花开伤害越高，但含苞最多只存在 2.5 秒，且目标可能被净化或脱困。

| 处理方式 | 收益 | 风险 |
| --- | --- | --- |
| 立即催花 | 快速完成循环，稳定积累岁荣，适合残血收割。 | 花开伤害较低，放弃蓄势收益。 |
| 蓄势后催花 | 花开伤害最高提高 45%，重击和长前摇技能能吃到完整加成。 | 含苞到期会枯萎，敌人脱困后整套铺垫失效。 |

### 4.2 落花处理

花开后只生成一种地面资源「落英」。玩家不额外管理花瓣数量，只决定这片落英是否保留。留场提供控场，收瓣提供续航，两者互斥。

| 处理方式 | 收益 | 代价 |
| --- | --- | --- |
| 留瓣 | 维持 6 秒的减速与木属性易伤区域，可配合聚怪、范围爆发或队友输出。 | 放弃本次即时回复和护盾。 |
| 收瓣 | 用枯木逢春吸收落英，回复生命或获得护盾，并强化下一次花开。 | 落英提前消失，失去区域控制。 |

> **复杂度约束**
>
> - 不新增第三种地面状态。落英自然消失后只做视觉淡出，不转化为腐殖土，也不生成新材料。
> - 不新增第二种货币。花瓣始终以落英场的形式存在，吸收后直接结算效果，不进入独立背包资源栏。

## 05 花谱体系

花谱是木属性的武器附魔或战斗流派。所有花谱共享三枝成苞的基础规则，只改变花开与落英的结算。每个花谱最多增加一条主题规则，避免同一职业同时管理多套资源。

### 5.1 基准花谱：灼灼桃花

**附魔花谱：灼灼桃花**

| 项目 | 说明 |
| --- | --- |
| 战斗定位 | 控制与范围爆发。作为首个教学花谱，完整展示基础循环，不附加额外资源或特殊触发条件。 |
| 插枝 | 直接命中钉入 1 根桃枝，每个攻击动作最多 1 根，最多 3 根，持续 6 秒；每根使目标移速降低 10%。 |
| 含苞 | 第 3 根桃枝使目标定身 2.5 秒并进入含苞；下一次命中触发花开。含苞期间可蓄势，最多提高 45% 花开伤害。 |
| 花开 | 以目标为中心 3 米范围造成 180% 攻击力的木属性爆发，并生成落英。 |
| 落英 | 持续 6 秒；范围内敌人移速降低 30%，受到木属性伤害提高 15%。可用枯木逢春吸收。 |

设计意图：灼灼桃花承担教学职责，完整展示三枝、含苞、花开与留瓣或收瓣的基础节奏。后续花谱只在这个认知上叠加一条差异，不重新教学基础操作。

### 5.2 其他花谱

| 花谱 | 定位 | 花开变化 | 落英变化 |
| --- | --- | --- | --- |
| 青竹·节节高 | 连击、穿透 | 含苞后的下一击化为直线竹刺，命中多个目标。 | 竹叶阵强化自身移速与攻速。 |
| 紫藤·垂影 | 聚怪、群控 | 含苞时与最近敌人连藤；花开将连藤目标拉向中心。 | 留场形成减速花田，便于范围爆发。 |
| 寒梅·傲雪 | 防反、续航 | 自身受击也会给攻击者加枝；花开回血并获得护盾。 | 落英区域提供减伤。 |
| 幽兰·空谷 | 辅助、净化 | 友方命中也能催花；花开治疗并净化周围友军。 | 落英持续回复生命。 |
| 彼岸花·忘川 | 处决、凋亡 | 缚枝附带减疗；花开按目标已损生命提高伤害。 | 落英转为腐蚀场，持续压低生命。 |

花谱约束：每个花谱只新增一条主题规则，不新增资源条、叠层或独立 UI。

## 06 技能与战斗节奏

主动技能只负责推进或回收基础循环，不作为新的资源入口。普通攻击负责稳定插枝，飞花摘叶提供远程起手，枯木逢春负责收瓣，一岁枯荣负责把长线积累转成团队级爆发。

| 技能 | 类型 | 作用 | 设计边界 |
| --- | --- | --- | --- |
| 普通攻击 | 武器命中 | 直接命中插入 1 道枝印。 | 每次攻击动作最多插 1 道，多段攻击另设内置冷却。 |
| 飞花摘叶 | 远程起手 | 向目标插 1 道枝印，建立安全的第一层。 | 不额外加快叠枝，不能替代近身催花。 |
| 枯木逢春 | 收瓣 | 吸收周围落英，回复生命或获得护盾，并强化下一次花开。 | 吸收后落英立即消失，不能同时保留场地收益。 |
| 盘根错节 | 控场 | 区域减速或聚怪，把敌人留在落英范围内。 | 不参与枝印叠加，避免出现第二套控制循环。 |
| 一岁枯荣 | 终极技 | 消耗 3 道岁荣，使场上所有带枝敌人补齐 3 枝并立即花开；已含苞目标直接花开。 | 本次花开不返还岁荣；释放后岁荣清零。 |

### 6.1 实战节奏示例

**单体快速循环**

1. **起手**：飞花摘叶命中，插下第一道枝印。
2. **成苞**：两次普通攻击补满三枝，目标定身并进入含苞。
3. **催花**：走出攻击前摇或使用重击，在含苞剩余约 1 秒时触发花开。
4. **落花**：若血量安全，留瓣继续输出；若需要续航，用枯木逢春收瓣。
5. **积累**：每完成一次花开获得 1 道岁荣；三道岁荣后释放一岁枯荣。

群怪场景可以使用另一条节奏：先用飞花摘叶给主要目标插枝，再用盘根错节聚怪，花开后保留落英，把减速与易伤区域作为队友的范围输出窗口。若生存压力高，则提前收瓣，放弃场地收益换取回复。

## 07 复杂度与平衡边界

木系的复杂度上限应低于“同时管理多层状态”的构筑职业。当前版本只要求玩家识别三个信息：敌人身上的枝印、地面的落英、玩家身上的岁荣。其他状态仅作为反馈或限制存在。

| 潜在风险 | 处理方式 |
| --- | --- |
| 多段攻击瞬间叠满三枝 | 每个攻击动作最多插 1 道枝印；多段攻击另设内置冷却，避免多段技能一秒成苞。 |
| 连续定身形成无限控制 | 定身只限制移动；含苞最多持续 2.5 秒；花开后目标获得 4 秒残枝抗性。 |
| 范围攻击瞬间充满岁荣 | 同一次攻击造成的多目标花开只计 1 道岁荣；一岁枯荣本身不返还岁荣。 |
| 落英铺满场景 | 同屏最多存在 1 至 2 片落英，同类花田自动合并，过期后只做视觉淡出。 |
| Boss 免疫定身导致体系失效 | Boss 可将定身换算为减速或削韧，但必须保留花开与落英结算。 |
| 火属性或净化直接废掉体系 | 允许烧枝、清苞、烧花瓣作为反制，但反制应有冷却与可见提示，不能无条件覆盖。 |
| 玩家把花瓣当成独立货币 | 落英不做背包货币；吸收时直接结算回血、护盾或下一次花开强化。 |

### 7.1 原型验收标准

- **三枝成苞是否易读**：玩家应在两轮循环内理解枝印、定身与含苞的关系。
- **蓄势是否形成决策**：玩家需要根据敌人状态选择立即催花或等待更高收益，而不是永远使用同一套连段。
- **留瓣与收瓣是否都值得选**：两种处理都应在实战中产生可感知收益，不能出现固定最优解。

## 08 表现与界面建议

表现层应让玩家在不阅读说明的情况下理解循环进度。枝印、含苞、落英和岁荣各自拥有不同形态与位置，避免所有信息都堆在目标头顶。

- **枝印**：目标周围出现 1 至 3 段逐渐生长的枝条；第 3 段枝条缠绕身体，提示即将成苞。
- **含苞**：目标头顶出现花苞图标与 2.5 秒收敛条；蓄势增伤时花苞由青转暖，颜色越暖，花开收益越高。
- **落英**：地面出现唯一的花瓣或叶片场，边缘带有 6 秒消散提示。自然消失时颜色变暗、碎入地面，只做视觉表现，不生成腐殖土。
- **岁荣**：玩家 HUD 使用三片叶子、三个花苞或三朵小花，满层合为一朵花；不要使用年轮图形。
- **一岁枯荣**：全场带枝目标同时亮起，枝条收束后统一花开；落英结束后保留短暂视觉余韵，再淡出。

> **界面信息上限**
>
> - 敌方侧：只显示三格枝印与含苞倒计时。
> - 地面侧：只显示落英及其剩余时间。
> - 玩家侧：只显示 0 至 3 道岁荣。

## 09 待定事项

本版先锁定机制结构，不锁定具体数值和养成方案。以下内容进入下一轮评审后再确定。

| 待定项 | 需要确认的内容 |
| --- | --- |
| 数值基线 | 各花谱花开倍率、蓄势收益、落英持续时间、收瓣回复量。 |
| 花谱获取 | 花谱是武器附魔、职业分支还是关卡掉落；切换花谱是否需要代价。 |
| 高难适配 | Boss、精英与多人场景中的定身转换、残枝抗性和落英数量上限。 |
| 操作手感 | 重击蓄势、花开前摇、收瓣技能与终结技的镜头、停顿和音效反馈。 |
| 命名确认 | 岁荣仍为暂定命名；后续可在不改机制的前提下替换。 |

下一步建议先以「灼灼桃花 + 基础循环」制作最小原型，只验证三枝成苞是否易读、含苞蓄势是否有决策、留瓣与收瓣是否都值得选择。基础手感成立后，再扩展其他花谱。
