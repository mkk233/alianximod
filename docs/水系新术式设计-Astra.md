# 「术」水属性术式设计提案

- **状态：提案未实现**
- **日期：2026-10-21**
- **设计：Astra**
- **依据：`docs/底座功能点.md`**
- **适用环境：Minecraft Forge 1.20.1，模组 `xueximod`**
- **本轮范围：仅依据题给事实编写设计文档；没有读文件、没有改代码、没有构建、没有进游戏。**

---

## 一、设计目标

水套以**曲线上的压力与曲线之间的让位空间**建立战术。

玩家沿直线冲向攻击源时，容易穿过中央空档、擦到侧面的危险边，或被绕向侧后的水流截住。观察流向、顺着弧线移动、进入弯曲内部的空档，可以主动降低受击风险。位置变化全部来自玩家自己的走位。

“以柔克刚”落实为三个可操作特征：

1. **让开正面。** 多数攻击将伤害体积布置在侧弧、外缘与回弯处，正前方保留可读空档。
2. **绕行遮挡。** 水沿连续曲线流动，局部受阻时保留仍能通过的支流。绕到障碍后方的水必须具有真实、连续的绕行路径。
3. **绵延施压。** 水流在有效时间内连续扫过曲线，通过释放节奏和装配形成连绵压力。单发伤害保持克制。

本提案包含 **7 个新攻击、0 个新路径术式、0 个新规则术式**。所有新攻击登记为 `ATTACK`，局部曲线负责水的形态，已有弹道负责根载体的运动。

本套不提供通用投射物拦截、反射、伤害减免或自动闪避。“化解直线威胁”通过空档、侧向攻击路线和玩家走位实现。

## 二、底座事实与设计边界

### 2.1 固定结算规则

> ChainRole 只有 8 个，禁止新增：ATTACK、ACTION、SEEK_SPACE、SEEK_ENTITY、TRAJECTORY_DROP、TRAJECTORY_SCATTER、RULE_TRIPLE、RULE_DUAL。结算顺序是索敌 → 弹道 → 规则 → 攻击。不按术式 id 写特判。同类修饰离攻击更近的覆盖更远的。

### 2.2 已有索敌和弹道

> - 锁定实体：只改方向，不改生成位置，不持续追踪。
> - 落点指定：可变弹道在准星落点周围边长 3 格的立方体里取点。斩击不走这个立方体。
> - 垂落：从选定点上方 8 格垂直下落，重力 0.08。
> - 风暴轨迹：Trajectory.VORTEX，角色仍是 TRAJECTORY_DROP。从落点上方 12 格、半径 5 格旋入落点，转 3 圈，寿命前三分之二旋转，之后停在落点。
> - 三维交错：改散布，不做索敌。
> - 新的曲线如果是「给后面的可变弹道改路径」，可以新增一个 Trajectory 枚举值，并登记到已有的 TRAJECTORY_DROP 角色上，用轨迹种类和垂落、风暴区分。不要为此新增 ChainRole。攻击自己的局部曲线（飘带、弧、环）不算新角色，放在攻击的局部几何里。
> - trajectoryMutable == false 的斩击只改生成位置，形状不变。要吃垂落、风暴、新曲线路径的攻击必须 trajectoryMutable == true。

本提案不新增 `Trajectory` 枚举值。绕弯、回弯、分流与开口环全部属于攻击局部几何。

### 2.3 已有规则

> - 一分为三：后面第一个攻击同一 tick 复制三份，三份共账，约 6 tick 后一次结算，伤害乘命中份数。不要再设计「错开三份」的三叠奏。
> - 双重释放：下一个术式再带后面两个；有伤害的按装配顺序隔 10 tick 逐个放。不要再设计接力齐发。
> - 魔力是 ceil(基础伤害 × 2)，规则花费 0。不要另做按份预留和退款。不要另做第二套跨份 6 tick 共账。

所有新攻击采用**整发一次**的单目标命中节奏。单份攻击的基础伤害等于本文的 `B`，魔力为 `M = ceil(2B)`。

长时间视觉延续不增加伤害次数；多段曲线、多条支流、一个目标同时碰到两条边，也只算该份攻击命中一次。

### 2.4 保留的已有水术

> - 断潮 tide_sever：剑术斩击，trajectoryMutable 为 false，静止薄切，长 5、宽 0.4、高 3，寿命 6 tick，伤害 6。形状不随弹道改。
> - 潮印 tide_mark：附魔，命中时熄灭目标身上的火，自己不造成攻击。
> - 生成水 magic_create_water：在目标位置放置水源。新攻击默认不改方块，不把「放水」再做成攻击。

新攻击默认不破坏地形、不放置流体、不改变方块状态。灭火效果仍只由潮印提供。

火系提案及命中接续、延时接续仍属于未实现内容。本套不依赖这些槽位，不新增门控、接续或规则角色。

## 三、共同的空间、视觉与命中约定

### 3.1 根载体与局部几何

每份攻击由两部分组成：

- **根载体：** 接收 `CastFrame` 中的生成位置、初始方向及已有弹道修饰。
- **局部几何：** 描述相对根载体的水带、水弧、分流线和开口环。

本文使用以下局部坐标：

| 符号 | 含义 |
|---|---|
| `O` | 根载体当前位置 |
| `F` | 释放时确定的前向 |
| `R` | 释放时确定的右向 |
| `U` | 与前向、右向组成局部坐标架的上向 |
| `s` | 曲线从出生端到末端的进度，范围为 0 至 1 |

锁定实体可以在释放时改变 `F`。释放后局部坐标架保持稳定，目标移动不触发持续追踪。

已有弹道移动根载体，局部几何整体随之平移：

- 垂落中的开口环保持环形。
- 风暴中的水带保持带形。
- 根载体转弯时，局部几何不累积扭转成漏斗。
- 局部尺寸不随根速度膨胀。

本文给出的默认摆放方向用于无修饰释放。接入弹道后，应由白沫准确表达实际危险体积。

### 3.2 统一时序与结算

为兼容已有约 6 tick 的一分为三共账，本套首版采用短命中窗口：

| 时间 | 行为 |
|---|---|
| `t = 0` | 生成根载体，显示清透轮廓和深青流向；危险边出现的位置必须同步可见 |
| `t = 0—5` | 六个 tick 的有效攻击期；各攻击按自己的曲线规律展开或扫动 |
| `t = 6—11` | 可选的视觉收尾；白沫危险边消失，只保留清透残水与少量飞沫 |
| `t ≥ 12` | 清理表现 |

**攻击有效寿命为 6 tick。** 收尾效果独立于攻击实体的有效寿命，不延长弹道寿命、不延长共账，也不继续命中。

每个有效 tick 检测该 tick 内实际扫过的危险曲线，避免移动过快产生断点。同一份攻击对同一目标最多登记一次命中。

- 普通释放：按现有攻击命中流程处理一次伤害。
- 一分为三：每份对目标最多贡献一次命中，交由原有共账在约 6 tick 后统一结算。
- 双重释放：各次攻击保持独立释放时间与独立命中记录。

本套的“绵延”主要体现在连续流动的几何与多次释放节奏。首版不提出十几秒驻留、反复伤害或额外周期账本。

### 3.3 三层视觉语言

| 视觉层 | 表达内容 | 是否命中 |
|---|---|---|
| 清透 | 水的总体积、曲线走向和空档边界 | 否 |
| 深青 | 主体流速与流向；使用顺流移动的条纹 | 否 |
| 白沫 | 当前有效的危险边，亮度与粗细对应实际命中范围 | 是 |
| 飞沫、尾迹 | 速度感、转弯残影和收尾 | 否 |

危险边使用圆润、连续的窄带或管状体积。水面可以起伏，攻击边界必须稳定可读。

不使用火苗粒子。水体表现采用连续曲面、弯曲边缘和透明层次，不使用热光束式四片硬光柱。

### 3.4 分段遮挡与绕行

绕行遵守以下共同规则：

1. 每条局部曲线具有明确的出生端和流动方向。
2. 实体方块遮挡处关闭对应危险段。
3. 受阻支流的下游停止获得有效水流。
4. 其他仍与出生端连通的支流继续流动。
5. 分流后重新汇合的曲线，允许由仍然通畅的支流供应后续段。
6. 完整墙体封住所有可用路线时，墙后的水不具备命中能力。

曲线只沿预先设计的弯曲形状绕行。首版不提出自动寻路、穿墙恢复、搜索整面墙边缘或跨墙传送。

这里的“水绕过遮挡的一段继续流”，指水经过障碍侧面的真实空隙继续前进。只有视觉残迹可以在失去连通后短暂消散，白沫必须立即关闭。

## 四、新攻击总览

所有名称及 `id` 均为提案登记名。

| id | 中文名 | 角色 | trajectoryMutable | 战术特点 | 单目标上限 B | 魔力 M |
|---|---|---|---|---|---:|---:|
| `water_yielding_ribbon` | 让锋 | `ATTACK` | `true` | 正面让空，双侧绕弧 | 4 | 8 |
| `water_winding_stream` | 曲溪 | `ATTACK` | `true` | 贴地蛇行，封直线进路 | 5 | 10 |
| `water_parting_flow` | 分汀 | `ATTACK` | `true` | 双支绕障，一侧受阻仍可续流 | 6 | 12 |
| `water_returning_bend` | 回澜 | `ATTACK` | `true` | 外绕回弯，压迫侧后走位 | 6 | 12 |
| `water_open_ring` | 缺月 | `ATTACK` | `true` | 开口环缘，内圈与缺口让位 | 7 | 14 |
| `water_weeping_arc` | 垂丝 | `ATTACK` | `true` | 三维下垂弧，保留侧向通道 | 5 | 10 |
| `water_braided_current` | 合流 | `ATTACK` | `true` | 双曲线相让，形成错位通道 | 8 | 16 |

`B` 表示**单份攻击对单目标的上限**。一分为三的总伤害继续遵循已有“伤害乘命中份数”规则，最多为 `3B`，没有额外附加倍率。

水套数值定位低于同体量火系硬爆发。题给事实未提供火系完整伤害表，本文数值属于待实测的初始值；相同覆盖体量下应继续维持水系较低的单发伤害。

## 五、攻击详细设计

### 5.1 让锋

**登记**

- `id`：`water_yielding_ribbon`
- 中文名：让锋
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 4`
- 魔力：`M = ceil(2 × 4) = 8`
- 命中节奏：整发一次。

**战术**

正面保留狭长空档，左右水带向外让开后收向两肩。适合迎接直线冲近的目标：目标坚持沿正中进入时可能穿过空档，临时横移到两侧则容易撞上白沫。

使用者需要判断目标的横向走位，单纯将准星对准胸口不保证命中。

**曲线与体积**

两条水带分别从 `O ± 0.65R` 出生：

- 前半段向左右弯至 `±1.8R`。
- 后半段向前延伸，收至 `O + 4F ± 0.9R`。
- 两条曲线始终保留中央通道，不在末端合拢。
- 每条清透水带宽约 `0.65` 格，高约 `1.2` 格。
- 危险边位于水带外侧，白沫命中带半径约 `0.16` 格。
- 中间净空至少约 `0.9` 格，曲线内侧只表现清透薄水。

**时序**

- `t = 0—1`：外侧危险边从两侧出生端向外弯展开。
- `t = 2—3`：白沫沿中段向前流动。
- `t = 4—5`：白沫进入前端收弯，随后消退。
- `t = 6—11`：两条透明尾迹顺流散去。

**弱点**

正中通道清晰；目标顺着中央前进或向水带内侧走位可以避开主要危险边。狭窄空间会同时截断两侧曲线。

**底座叠加**

锁定改变双带的初始朝向；落点将根放到既有取点范围内；垂落和风暴移动整组双带。三维交错散布根位置。一分为三、双重释放沿用共同结算约定。

**不做什么**

不招架武器、不弹开投射物、不提供免伤，不向目标施加位移。

### 5.2 曲溪

**登记**

- `id`：`water_winding_stream`
- 中文名：曲溪
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 5`
- 魔力：`M = 10`
- 命中节奏：整发一次。

**战术**

以低位蛇行水带切割直线进路。玩家沿曲溪内弯行走较安全，直接横穿外弯容易受击。

**曲线与体积**

水从 `O` 出生，沿前方约 `6` 格延伸，形成两个连续反向弯：

- 第一弯向右，最大偏移约 `1.5` 格。
- 第二弯向左，最大偏移约 `1.5` 格。
- 末端回到前向轴附近。
- 水带宽约 `0.8` 格，清透体积高约 `0.4` 格。
- 每个弯的外缘出现白沫，危险带半径约 `0.18` 格。
- 反曲点两侧各保留短暂的无白沫过渡段，避免危险边瞬间从一侧跳到另一侧。

无修饰释放时，根默认位于使用者前方近脚部位置。曲溪沿固定平面展开，不自动贴合复杂地形。

**时序**

- `t = 0—1`：第一外弯形成。
- `t = 2—3`：危险前沿经过反曲点，向第二外弯延伸。
- `t = 4—5`：第二外弯与末端完成扫动。
- `t = 6—11`：低位透明水痕消退。

**弱点**

跳过低位危险边、进入内弯或在反曲过渡段穿越都更安全。高低差、台阶和完整障碍容易截断水路。

**底座叠加**

落点便于将曲溪放到前方通道；锁定只确定初始前向。垂落时蛇行带整体下落，固定平面保持。风暴搬运同一蛇行形状。三维交错不增加地形贴合能力。两个规则复用共同约定。

**不做什么**

不生成水方块、不冲走实体、不施加减速，不自动沿墙或台阶爬行。

### 5.3 分汀

**登记**

- `id`：`water_parting_flow`
- 中文名：分汀
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 6`
- 魔力：`M = 12`
- 命中节奏：整发一次。

**战术**

面对窄柱、树干或局部掩体时，让水在前方分成左右两支，沿掩体外侧继续流动。任意一支畅通，汇流后的短尾仍可成立。

这是本套最明确的绕障攻击。

**曲线与体积**

- 水从 `O` 出生，前行约 `0.6` 格后分流。
- 两支分别弯向 `±2.1R`，绕过中央长约 `2.5` 格的空区。
- 在 `O + 5F` 附近重新汇合，形成约 `1` 格的短尾。
- 每支清透水带宽约 `0.6` 格，高约 `1` 格。
- 外侧白沫危险带半径约 `0.17` 格。
- 中央空区以及支流内缘提供主要空档。
- 汇合处保持两条可辨认的白沫边，不形成爆炸体积。

**时序**

- `t = 0—1`：出生段分流。
- `t = 2—3`：两支流沿侧弧展开，分别检查连通性。
- `t = 4—5`：畅通支流进入汇合区与短尾。
- `t = 6—11`：残水沿各自路线散去。

**弱点**

掩体过宽、两侧同时封闭或出生段受阻时，绕行失败。目标站在中央空区可以避开侧弧；目标向汇合点横移则更危险。

**底座叠加**

锁定朝向决定绕行结构朝向，生成位置保持底座语义。落点帮助把分流结构放到窄掩体旁。垂落与风暴移动整个分流结构，分段遮挡需要随实际位置重检。三维交错只散布根。两个规则不改变每份攻击的分支去重。

**不做什么**

不读取掩体尺寸自动扩宽，不搜索墙边，不让断流下游自行恢复伤害，不因两支同时碰到目标而加倍。

### 5.4 回澜

**登记**

- `id`：`water_returning_bend`
- 中文名：回澜
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 6`
- 魔力：`M = 12`
- 命中节奏：整发一次。

**战术**

水先从侧面远离目标正面，再沿大回弯切回侧后。适合惩罚沿直线后退、只盯着攻击源的走位。

**曲线与体积**

- 出生点位于 `O + 0.6R`。
- 先向右外绕至约 `O + 2F + 2.4R`。
- 再绕到约 `O + 5F + 1.5R`。
- 末段向左回弯，朝 `O + 3.5F - 0.5R` 收回。
- 整体呈开放的长钩形，回弯末端与出生段保持至少约 `1` 格间距。
- 水带宽约 `0.7` 格，高约 `1.1` 格。
- 回弯外缘及回收段前缘为危险边，命中带半径约 `0.18` 格。
- 钩形内部和开口处保持空档。

**时序**

- `t = 0—1`：侧向外绕。
- `t = 2—3`：远端回弯展开。
- `t = 4—5`：回收段向内扫过。
- `t = 6—11`：末端水丝向开口散去。

**弱点**

向钩形内部走位或从开口离开更安全。攻击方向固定，目标及时横移到另一侧可使回弯落空。外绕段被墙封住时，后续回收段失效。

**底座叠加**

锁定仅确定初始钩形朝向。落点移动整个钩形。垂落时开放钩形整体下落；风暴时整体旋入，钩形不额外自转。三维交错散布钩形位置。规则不赋予回程第二次命中。

**不做什么**

不追着目标转弯，不在返回途中再次伤害同一目标，不变为回旋飞刀式硬质刃片。

---

### 5.5 缺月

**登记**

- `id`：`water_open_ring`
- 中文名：缺月
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 7`
- 魔力：`M = 14`
- 命中节奏：整发一次。

**战术**

以开放环缘控制一个区域的外圈，鼓励目标进入内圈、沿环内侧移动或从缺口穿出。环中心始终可读，适合制造“退到边缘更危险”的局面。

**曲线与体积**

- 根位于开口环中心。
- 水从后侧缺口的两端出生，分别沿左右弧流向前侧。
- 半径约 `2.2` 格，保留约 `100°` 的后侧开口。
- 水带径向宽约 `0.65` 格，清透体积高约 `0.7` 格。
- 外圆弧为危险边，命中带半径约 `0.18` 格。
- 内部半径约 `1.5` 格的区域保持安全。
- 缺口固定朝后，不追随目标关闭。

**时序**

- `t = 0—1`：两端沿环缘起流。
- `t = 2—3`：左右弧延伸至两侧。
- `t = 4—5`：前侧弧形成，后侧开口仍然存在。
- `t = 6—11`：环缘分成薄水片消散，白沫先行退去。

**弱点**

目标进入内圈后，缺月自身无法继续施压。后侧缺口提供明确离场方向。环缘被地形分割时，有效覆盖会明显缩小。

**底座叠加**

锁定决定环的前后朝向；落点决定根的取点位置。垂落保持环形，风暴保持开口与内圈。一分为三可产生多个开口环，但各份仍需显示真实危险边，重叠不得掩盖边界。

**不做什么**

不闭环困人，不缩圈追赶，不在环心爆炸，不提供墙体碰撞或实体阻挡。

### 5.6 垂丝

**登记**

- `id`：`water_weeping_arc`
- 中文名：垂丝
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 5`
- 魔力：`M = 10`
- 命中节奏：整发一次。

**战术**

以三维下垂曲线覆盖前方不同高度。危险集中在低垂弧腹，左右留出稳定通道，适合压迫直线跳跃或从高处落向固定位置的目标。

**曲线与体积**

- 两条水丝从 `O ± 1.3R + 1.5U` 出生。
- 向前延伸约 `4.5` 格，同时向中央靠近。
- 中段下垂至约 `O + 2.5F - 0.6U` 的高度附近，两丝保持至少约 `0.8` 格间距。
- 末端再次抬起并向左右分开。
- 每条水丝的清透体积半径约 `0.3` 格。
- 危险边位于弧腹朝前、朝下的一侧，白沫命中半径约 `0.15` 格。
- 两侧外部以及两丝之间的连续缝隙构成空档。

**时序**

- `t = 0—1`：水丝由高位向前下垂。
- `t = 2—3`：危险前沿进入低弧腹。
- `t = 4—5`：沿上扬末段向外离开。
- `t = 6—11`：水丝变细、断成无伤害飞沫。

**弱点**

侧向移动可以避开低弧腹。低矮天花板容易截断出生段。目标处于两丝中间且保持走位时，命中可靠性较低。

**底座叠加**

锁定调整整体朝向，保持出生位置规则。落点将三维弧整体搬到取点位置。垂落只改变根的运动，不追加局部重力；风暴不会把双丝绕成封闭水柱。规则继续整发一次。

**不做什么**

不吊起目标、不缠绕、不改变跳跃高度，不形成持续伤害水帘。

### 5.7 合流

**登记**

- `id`：`water_braided_current`
- 中文名：合流
- 角色：`ATTACK`
- `trajectoryMutable`：`true`
- 单目标伤害上限：`B = 8`
- 魔力：`M = 16`
- 命中节奏：整发一次。

**战术**

两条水流互相让位，在不同高度交错经过，形成可以跟随的弯曲通道。直线横穿容易碰到外侧白沫，沿深青流向移动更容易保持在间隙中。

这是本套体量最大的攻击，定位为可读的路线压迫。

**曲线与体积**

- 两条水带从 `O ± 1.1R` 出生。
- 在前方约 `6` 格内，各完成一次左右换位。
- 交错区域中，一条上抬约 `0.7` 格，另一条下沉约 `0.7` 格，空间上保持分离。
- 后半段各自向外舒展，末端不封口。
- 每条水带宽约 `0.65` 格，厚约 `0.3` 格。
- 外弯侧为危险边，命中带半径约 `0.17` 格。
- 两条水带之间保留至少约 `0.9` 格的连续可行间隙；交错处需要用高度差保持这条通道。

**时序**

- `t = 0—1`：左右水带开始向内弯。
- `t = 2—3`：一高一低经过交错区。
- `t = 4—5`：向外舒展，打开末端出口。
- `t = 6—11`：深青流线逐渐变浅并消失。

**弱点**

攻击覆盖体量较大，地形容易截断其中一条水带。对方读懂流向后，可以沿中间通道通过。出生点附近和末端外侧都留有撤离空间。

**底座叠加**

锁定确定交错通道朝向；落点移动整个通道。垂落与风暴只搬运根，保留上下让位关系。三维交错会散布整份双带形状，不会自动把多份攻击拼接成新通道。一分为三仍按命中份数结算。

**不做什么**

不把两条水带分别计伤，不封闭通道，不形成水龙、爆炸冠或旋转硬刃，不引入阶段连击。

## 六、底座修饰的统一兼容方式

### 6.1 索敌

**锁定实体**

仅在释放时决定根与局部坐标架的初始方向。水流随后按照既定曲线展开。目标离开预测位置后，攻击可以落空。

**落点指定**

七个攻击均为可变弹道，根在准星落点周围边长 3 格的立方体内取点。局部几何从该根展开，因此实际覆盖范围还包含曲线自身的尺寸。

这意味着落点指定不能承诺把缺月中心、分汀分叉点精确放到准星坐标上。

### 6.2 弹道

| 修饰 | 对本套的作用 | 必须保留的特征 |
|---|---|---|
| 垂落 | 根从选定点上方 8 格垂直下落，重力 0.08 | 曲线形状、开口与内部空档 |
| 风暴轨迹 | 根执行既有 `Trajectory.VORTEX` | 局部水形不被拉成漏斗 |
| 三维交错 | 改变整份攻击的散布 | 不新增索敌、不拼接独立水路 |

攻击有效寿命只有 6 tick，垂落可能在到达地面前结束。这是首版明确的适用限制：**垂落组合更适合处理高位或空中目标。**

风暴按现有寿命比例运行，短寿命可能使根运动很快。因此需要验证扫掠检测和视觉可读性。若六 tick 内完成既有风暴行为过于急促，相关组合应保留为待验证兼容项；本文不另行改变风暴参数或共账规则。

### 6.3 规则

**一分为三**

- 同一 tick 复制三份攻击。
- 每份内部全部曲线共享该份的单目标命中记录。
- 三份交由已有 `ReleaseBatch.Tally` 共账。
- 不新增延迟副本、分支账本或阶段结算。
- 不对规则新增魔力预留、退款或按份计费。

**双重释放**

- 保持“下一个术式再带后面两个”的现有语义。
- 有伤害的术式按装配顺序隔 10 tick 释放。
- 每次水攻击保持自己的六 tick 有效期。
- 视觉收尾可以短暂衔接后一次释放，危险白沫必须按各自有效期关闭。

### 6.4 同类覆盖

同类修饰离攻击更近的覆盖更远的。例如：

`垂落 → 风暴轨迹 → 缺月`

缺月使用更近的风暴轨迹，不叠加两套根运动。

水攻击不根据自己的 `id` 改写覆盖关系、取点方式或规则结算。

## 七、组合示例

以下名称只用于说明玩法，**不注册为术式，不新增角色或规则**。箭头表示装配顺序。

### 7.1 「绕墙的水」

**装配：**

`落点指定 → 分汀`

将落点放在窄掩体近侧，让分汀的两支曲线经过掩体左右空隙，在其后方汇流。

- 适合窄柱、树干与局部墙角。
- 由于落点存在既有取点范围，使用者需要给两侧预留空间。
- 一侧受阻时另一侧仍可续流。
- 宽墙封住全部曲线时，墙后没有有效攻击。

### 7.2 「贴地的流」

**装配：**

`曲溪`

无修饰时使用其低位默认根，在平坦地面附近展开蛇行水带。

**变体：**

`三维交错 → 曲溪`

散布可以覆盖相邻进路，但部分根可能偏离地面。该变体需要接受散布带来的不确定性。

### 7.3 「连绵的弧」

**装配：**

`双重释放 → 让锋 → 回澜 → 缺月`

三个攻击按已有规则，约在 `t = 0、10、20` 依次释放。

- 让锋先给出中央通道。
- 回澜随后压迫侧后撤退。
- 缺月最后限制外圈横移。
- 目标可以持续通过空档调整位置。

连绵感来自已有释放节奏和曲线方向变化，不增加接续触发条件。

### 7.4 「三道曲水」

**装配：**

`三维交错 → 一分为三 → 曲溪`

曲溪同一 tick 复制三份，并使用既有散布机制。命中份数交由原有共账处理。

视觉上每份曲溪都显示自己的白沫。三份没有先后启动关系，空间重叠也不合成为额外攻击。

### 7.5 「高处让月」

**装配：**

`落点指定 → 垂落 → 缺月`

根从选定点上方 8 格下落，开口环保持平面结构。

这组用于高位目标、空中交战或高度差场景。六 tick 有效期是否能覆盖目标高度，需要实际验证；不能承诺落到地面后再完整攻击一次。

### 7.6 「旋入的双丝」

**装配：**

`落点指定 → 风暴轨迹 → 垂丝`

根使用现有风暴轨迹旋入落点，双丝保持自身的高位出生、低垂弧腹与侧向空档。

这是高风险的可读性验证组合。若根移动过快使白沫难以辨认，需要在后续提案评审中处理，不能通过暗中扩大命中体积补偿。

### 7.7 「熄火的回澜」

**装配：**

`潮印 → 回澜`

回澜提供攻击，潮印提供既有命中熄火效果。没有潮印时，回澜只造成自身伤害。

## 八、能力依赖与复用边界

### 8.1 直接沿用的底座职责

以下是设计上的复用归属，未进行代码可用性核查。

| 既有能力 | 本提案的复用方式 |
|---|---|
| `ATTACK` | 登记全部七个新攻击 |
| `CastFrame` | 提供根的生成位置、初始朝向和修饰后的施法上下文 |
| `TechniqueHitSpec.spawn` | 作为攻击体积生成的统一入口 |
| `TechniqueHitEntity.tryHit` | 作为统一命中处理入口 |
| 现有落点、锁定和弹道 | 处理根载体的位置与运动 |
| `ReleaseBatch.Tally` | 处理一分为三的现有共账 |
| 现有魔力公式 | 按单份攻击基础伤害计算 `ceil(2B)` |
| 潮印 | 提供已有熄火效果 |
| 双重释放 | 提供既有按装配顺序间隔释放 |

复用入口不代表已有攻击体积已经支持连续曲线。曲线能力仍属于下节的新增通用依赖。

### 8.2 尚不存在、需要另行批准的通用能力

| 通用能力 | 本套是否依赖 | 需要解决的问题 |
|---|---|---|
| 曲线采样与曲线带体积 | 全部依赖 | 将局部曲线转换为稳定、连续的危险边；处理曲率与厚度 |
| 曲线的逐 tick 扫掠 | 全部依赖 | 根和局部前沿同时运动时，避免漏检或跨空档误伤 |
| 分段遮挡 | 全部依赖 | 只关闭被实体方块挡住的段，保留有效支流 |
| 水路连通性 | 分汀、缺月等分支结构重点依赖 | 防止断流段在障碍后恢复伤害；允许畅通支路供应汇合段 |
| 多段几何共用整发去重 | 全部需要确认并补齐通用支持 | 多个采样段碰到同一目标时，只贡献该份一次命中 |
| 阶段去重 | 本套首版不依赖 | 所有攻击采用整发一次，没有阶段伤害 |
| 曲线视觉与命中边界同源 | 全部依赖 | 保证白沫所在的位置就是实际危险边 |

这些能力应面向通用曲线攻击设计，以几何、遮挡和命中数据描述行为。本文不允许按七个水术的 `id` 单独接入底座结算。

### 8.3 需要在后续评审确认的接口问题

1. 现有命中流程如何保存同一份攻击跨多个几何段的目标记录。
2. 分段遮挡如何表达分流、汇合与出生端连通。
3. 攻击有效寿命与纯视觉收尾如何分离。
4. 一分为三的共账关闭边界如何与第六个有效 tick 对齐。
5. 风暴短寿命运动的扫掠路径如何保留曲线空档。

这些问题属于后续实现前的通用能力评审。本文只提出玩法约束与验收标准，不宣称相关支持已经存在。

## 九、平衡原则与风险

### 9.1 伤害与覆盖

- 单份伤害维持在 `4—8`，全部落在建议的 `4—9` 区间内。
- 较大覆盖体积不自动获得更厚的危险边。
- 清透体积可以宽，白沫命中带保持窄而明确。
- 两条水带同时命中只算该份一次。
- 一分为三的增伤全部来自既有命中份数。
- 水攻击不附带免费灭火、减速、流体放置或地形收益。

### 9.2 空档必须可用

图形上出现缝隙还不足以构成战术空档。后续验证应以玩家实际碰撞体积为准：

- 通道必须允许玩家通过。
- 曲线采样体积不能跨接两个相邻弯，填平内弯空区。
- 高速扫掠不能用包围整个形状的大盒子覆盖安全区域。
- 多份攻击重叠时，玩家应能辨认空档是否仍然存在。

### 9.3 主要风险

| 风险 | 设计约束 |
|---|---|
| 绕障演变为穿墙 | 下游必须具有连续、未受阻的供流路径 |
| 白沫与命中不一致 | 渲染和命中使用同一曲线边界定义 |
| 持续外观造成多次伤害误解 | 白沫在有效期后关闭，收尾只保留低亮残水 |
| 风暴速度压缩阅读时间 | 列为重点验证项，维持现有弹道事实 |
| 垂落未触及地面 | 明确首版适用高度，避免承诺地面落击 |
| 多份复制掩盖空档 | 独立显示危险边，控制透明叠加和飞沫密度 |
| 伤害被多段采样重复计算 | 整份去重，并继续使用既有三份共账 |
| 曲线数量带来性能压力 | 限制采样复杂度、收尾密度与同时存活表现量 |

### 10.5 伤害与规则

- [ ] 单份攻击对同一目标最多命中一次。
- [ ] 同时接触多段、多支水流不会增加伤害。
- [ ] 一分为三同一 tick 生成三份。
- [ ] 三份只使用原有共账，约 6 tick 后一次结算。
