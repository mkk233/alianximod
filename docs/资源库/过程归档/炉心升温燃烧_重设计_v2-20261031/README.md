# 升温、燃烧 — 炉心特效重设计 v2

2026-10-31 用户要求重新设计制作中的升温和燃烧。本目录为 Aseprite 二维过程稿。用户随后确认升温“效果很好，采用”，升温原样归档至正式资源“升温_贴身炽热_v2”；燃烧v2未采用，按双手附焰、身体燃烧和火焰披风重画v3。未修改游戏代码、制作表或编译。

## 设计

- 升温（fire_heat_up）：贴身暖橙亮边，手臂与躯干两侧热流向上移动，少量余烬脱离。普通炉心维持保留低密度，人体中央和头部留空。
- 燃烧（fire_burn）：橙红外缘、橙黄内焰、少量黄白高温芯；火舌沿手臂和腿侧向上翻卷，错相升降并脱落火星，形成明显强于普通炉心的火焰外衣。肩侧火舌控制高度，避免头顶形成对称尖角。
- 入场与维持拆开：一次入场8帧×60ms，随后持续20帧×80ms循环。预览在一次入场后展示两轮维持，接入时不能循环重放入场。从普通升级只播放燃烧入场。
- 不新增攻击或地形点燃的视觉暗示；没有地面火圈。此方案仅改变视觉，不改变炉心数值、状态转换、费用或冷却。
