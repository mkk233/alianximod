# 周身水环 · Blockbench 3D验证 v1

2026-10-27。采用现有 Aseprite v2 展开水纹，由正在运行的 Blockbench 5.2.2 / MCP 1.10.1 创建并渲染。待用户确认，未正式采用、未接入游戏。

- `周身水环_3D验证_v1.bbmodel`：可编辑自由模型，嵌入全部纹理；人物占位与水环分开。
- `water_band.png`：Aseprite v2 原纹理副本，128×256，16帧，每帧128×16，10fps，1.6秒循环。
- `water_ring_3d_fixed.gif`：固定相机，网格不旋转，播放贴图本身的流动动画。
- `water_ring_3d_orbit.gif`：48帧/4.8秒环绕观察；水纹持续流动。
- `frames-fixed/`、`frames-orbit/`：Blockbench真实视口逐帧PNG，GIF仅合成深色背景与调色板。
- `侧面检查.png`、`背面检查.png`：检查视角。
- `build-scene.js`、`export-previews.ps1`：制作和导出过程。

环带内半径10、外半径14，高度15；人物高32。32段四边形共64顶点，周向UV连续覆盖0～128，径向0～16，首尾共边。双面渲染、深度测试开启；模型自身完全静止。环带是水平薄片，低视角会变窄，后续是否增加水流厚度待视觉确认。

已核对16帧互不相同、前后遮挡及背面，模型内含纹理和10fps参数。打开模型后可用纹理面板播放按钮继续循环。未修改游戏代码，未编译、打包或测试游戏。
