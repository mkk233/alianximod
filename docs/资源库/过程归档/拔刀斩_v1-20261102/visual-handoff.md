# 拔刀斩 v1 空间与动画交接

Blockbench 适用性：适用，动作涉及人物骨架、持刀、刀鞘和空间旋转。
版本：iaido-single-v1，2026-11-02。
确认：用户尚未确认本次实际版本；当前仅交付预览。

二维源：iaido-atlas.aseprite，64×64，2 层、静态单帧；二维导出 iaido-atlas.png，二维预览 atlas-preview.png。
模型：iaido-single-v1.bbmodel，原生 Blockbench project 导出，free 格式，25 cubes / 12 groups / 1 texture。
实际预览：iaido-front-preview.gif 与 iaido-side-preview.gif，均由真实 Blockbench 960×720 视口采样。blockbench-active-view.png 为活动视口截图。
上述资产 SHA-256 与文件大小见 manifest.json，同一版本绑定。

## 空间

换算：本示意 16 模型单位 = 1 游戏格；假人高 32 单位即 2 格，仅为展示比例。
轴向：+Y 向上，人物前方 -Z，人物左侧 +X。ActorRoot 原点 [0,0,0] 为脚底参考。
Body 旋转中心 [0,12,0]，Head [0,24,0]；左右肩分别 [±6,24,0]，肘 [±6,18,0]，腕 [±6,12,0]。
层级：ActorRoot → Body → ArmRight → ForearmRight → SwordHand；Body → ArmLeft → ForearmLeft → Scabbard；Head 隶属 Body；双腿隶属 ActorRoot。
手部轨迹使用 Body 局部参考坐标；烘焙到层级局部旋转，最终位置受 Body 整体动作影响，不是世界固定点。

初始鞘口 [3,17,-5]；刀轴 [cos20°,0,sin20°]；右掌位于鞘口减 2.75 倍刀轴处。拔刀段右掌沿刀轴反向移动 8 单位，左手鞘口沿刀轴正向移动 8 单位，相对抽出 16 单位。挥斩开始前刀尖已离开鞘口。
刀柄局部 Y=9.5–14.5，刀锷 14.5–15，刀身 15–29.5，掌心 Y=12；刀尖距掌心 17.5 单位。鞘主体长 16 单位，由四壁及尾盖构成开口结构。
横斩阶段刀轴局部水平角从 20° 变为 -120°；腕部在 0.48–0.54 秒滚转 90° 配合水平切割。躯干同时从蓄势偏转 -12° 至挥斩 +20°。
终态右掌局部 [-9,16,-4]，刀轴归一化 [-0.45,-0.65,-0.62]；左手鞘口 [4,16,-3]。终态为低位持刀，不入鞘。

## 材质与时间

UV：64×64 静态图集，逐面 UV 存储在 bbmodel 中；材质源两层。模型嵌入 PNG 与 iaido-atlas.png 已按字节核对一致。
材质：不透明像素材质，深蓝衣服、暗红刀鞘、钢色刀刃与金色刀锷；本版未附加斩击光效。
动画 animation.iaido_single_v1，时长 1.6 秒、once；10 根有实际关键帧的骨骼，每 0.02 秒采样。
时序：0–0.20 秒蓄势，0.20–0.48 秒抽刀，0.48–0.60 秒横斩，0.60–0.85 秒停势，0.85–1.60 秒落刀。
运动绑定：单刀固定 SwordHand，刀鞘固定 Scabbard，两者随对应前臂/上臂/躯干运动；不使用双刀切换、不使用缩放隐藏模拟抽刀。
预览：每 0.04 秒采样，共 41 帧。GIF 首帧 0.20 秒、尾帧 0.60 秒用于观看，总 2.36 秒循环播放，不代表游戏施法时长。

## 辅助和运行边界

示意辅助：示意人物_* 方块组成假人；示意辅助_地面为地面参考。这些不直接当运行资源。
正面机位 [52,38,-72]，侧面 [72,28,7]，目标 [0,15,-2]；离屏预览正交 zoom 0.37。
运行资源：尚未指定/复制，不自动接入。free 模型双节手臂不是 Minecraft 原版玩家骨架；后续若采用，应由 Cursor 对接实际渲染/动画系统，不能假定直接加载此 bbmodel 即可运行。
Blockbench 不能代表：玩家第一人称、联机同步、命中时刻和判定、武器替换、游戏遮挡及光照、配置适配。
