# 拔刀斩 v4 空间交接

Blockbench 适用性：适用，人物佩刀和动作空间关系。版本 iaido-single-v4-side，2026-11-02。用户最新要求：身侧佩刀、刀尖朝背后；v4 实际效果待用户评价。

资源绑定：iaido-atlas.aseprite 为沿用的 64×64、两层静态材质源，iaido-atlas.png 为原尺寸导出，atlas-preview.png 为二维预览。iaido-single-v4-side.bbmodel 为实际 Blockbench project 导出，free 格式；20 cubes、11 groups、9 根动画骨骼。预览为 iaido-front-preview.gif、iaido-side-preview.gif，两个 *-waist-start.png 是真实视口起手图。manifest.json 记录同版哈希。

## 空间与姿态

本示意 16 模型单位 = 1 游戏格，假人高 32 单位；不代表实际碰撞尺寸。+Y 上、人物前方 -Z、人物右侧 -X、人物背后 +Z。
ActorRoot 在脚底 [0,0,0]，Body 中心 [0,12,0]。右臂层级 Body→ArmRight→ForearmRight→SwordHand；左臂 Body→ArmLeft→ForearmLeft。上臂、前臂各 6 单位；肩 [±6,24,0]，肘 [±6,18,0]，腕 [±6,12,0]。没有 Scabbard 或刀鞘。
手部位置用 Body 局部参考坐标表示，实际受躯干动画影响。初始右掌 [-6.8,14.7,-3.6]，位于右侧腰带外；初始刀轴 [0,0,1]，与人物前向相反。刀柄向 -Z，刀尖向 +Z，沿身体侧面前后排布，不横在腹部。
刀柄原始 Y=9.5–14.5，刀锷 14.5–15，刀身 15–29.5，原始掌心 Y=12，刀尖距掌心 17.5。刀身与右手始终同一绑定，不切换双刀、不插入刀鞘。
右掌前带终点 [-7.1,17,-8.68]，挥斩终点 [-9.5,18,-4.5]，最终低位 [-9,16,-4]。左掌从 [6.8,15,2.4] 让至 [7.4,16,2]，最终 [6.5,14.5,1.8]。

## 连续衔接与时间

animation.iaido_single_v4_side，1.6 秒，once，0.01 秒烘焙。0–0.20 蓄势，0.20–0.48 向前带刀，0.48–0.60 快斩，0.60–0.85 停势，0.85–1.60 落刀。
带刀进度 d=2u²−u³，u=clamp((t−0.20)/0.28)。挥斩右掌为三次 Bézier：P0=clearR，P1=clearR+(clearR−startR)×0.12/(3×0.28)，P2=P3=endR。入弧速度与前带末速相同。
刀轴水平角从初始 90°，在 0.28–0.48 秒轻转到 100°；0.48–0.60 秒按 a=3q²−2q³ 转至 240°，从右侧外方划至前方。腕滚转共用进度 90°a。该路径与 v2 保持时间和连续衔接方式，但按新的佩刀方向重排，不声称空间轨迹相同。
结束刀轴为归一化 [-0.45,-0.65,-0.62]。
