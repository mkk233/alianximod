## 动画

- `waterfall_flow.psd/png`：64×128每帧，16帧竖排64×2048。固定48像素宽的流水参考。每帧100ms，纹理每帧向下8像素，纵向可连续接段；16帧内包含两次0.8秒水纹循环。
- `waterfall_charge.psd/png`：同规格聚能演示，宽度从12增加到48像素，前12帧展开，末4帧保持。左右同步扩展，长度固定，不把纵向流线拉胖。GIF回到窄态仅为演示重播，接入不能让蓄力过程自动反复重置。
- `waterfall_flow.gif`、`waterfall_charge.gif`：4倍最近邻深底预览；底色不在正式PNG中。
- `单帧/flow`、`单帧/charge`：PS原尺寸透明导出。

## 分件

`waterfall_left.psd/png`、`waterfall_middle.psd/png`、`waterfall_right.psd/png` 为从固定宽流水源中分出的左水边、中水体、右水边。每帧分别8×128、16×128、8×128，都是16帧同步序列。中段横向16像素重复，填充扩宽区域；边缘保持原像素厚度。左右分件来自源图x=[6,14)、[50,58)，中段来自[14,30)。正式接入应按聚能进度布局、对齐纹理横向相位，分件不自行控制网格宽度。细于左右分件合计宽度的初态以12像素演示态为参考，不能强压边缘互相叠加。

水色沿用青蓝六色硬边像素，深蓝不规则边、浅青长流线及少量白沫均向下移动。未加落地水花，方便之后由实际落点处理。`验证记录.json`检查向下位移与导出序列一致性。

流水相位与聚能宽度须独立：流水循环播放，宽度由蓄力值决定。自定义渲染直绑序列使用当前帧UV，不能把整张序列纵向当作单帧拉伸。
