## 存放约定

- 按需使用 `图标/`、`界面/`、`模型/`、`音效/` 等分类；分类下按对象、版本建目录，不预建空目录。
- 每个正式版本保留可编辑源文件、原尺寸导出和预览，记录采用状态、尺寸、用途及参考来源。
- 草稿、对照图、参考资料和制作脚本放 `过程归档/<对象>-<日期>/`。历史脚本仅供查阅，复用前确认目标文档与输出路径。
- 像素素材原尺寸导出保持透明和硬边，预览使用最近邻缩放。
- 游戏实际加载的资源仍位于 `src/main/resources/assets/xueximod/`。资源库归档不等于接入游戏；接入任务中复制确认版并检查相应模型引用。
- 本次原版图标参考取自本机 Minecraft Java 1.20.1 客户端：燧石、粗铁、海晶碎片、紫水晶碎片、铁锭、下界合金碎片，仅作为风格参考。
