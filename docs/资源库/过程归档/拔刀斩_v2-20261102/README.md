右手抽刀末段保留速度，沿同切线 Bézier 轨迹接入横斩；刀轴转向与腕部 90° 滚转共用挥斩进度。刀尖退出鞘口后才开始旋转。去掉斩后多余正弦回摆。单刀与右手绑定保持不变。

原动作 1.6 秒且 once：0–0.20 蓄势，0.20–0.48 抽刀，0.48–0.60 快斩，0.60–0.85 停势，0.85–1.60 落刀。关键帧从每 0.02 秒加密到 0.01 秒。

正面/侧面 GIF 从真实视口每 0.02 秒采样，共 81 帧；首尾观看停顿为 0.20/0.60 秒，显示总长 2.38 秒并循环。慢放只截取 0.32–0.68 秒，按四分之一速度展示衔接。GIF 循环不代表模型循环。

沿用 v1 的 64×64 Aseprite 静态材质和人物/刀鞘尺寸。本版修改动作，不重画贴图。free 格式示意未映射游戏玩家骨架，假人和地面仅作空间参照。未改 Java、未编译、未打包、未启动游戏。
