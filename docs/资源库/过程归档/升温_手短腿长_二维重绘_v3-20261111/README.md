# 升温 v3 · 手短腿长 · 二维审稿

2026-11-11，用户反馈升温三维预览中手部火焰过长、腿部火焰过短，随后明确要求先重新绘制二维版。本目录由 Aseprite MCP 绘制，等待二维观感确认。

## 这版的变化

- 手焰集中在手掌与前臂下段。手掌参考为 y=59–67，火根在 y=68–69，主火舌顶部约 y=52–58；火焰下端最多略超过手掌。
- 腿焰从脚踝附近向上窜，主火舌顶部约 y=73–82，超过示意人偶的膝盖位置 y=86。脚底参考为 y=104。
- 保持暖橙色、细长像素火舌和少量上升余烬；手、腿分别分层，便于后续单独挂载与调节。
- 人偶以 MC 身体比例作为二维参考：头部 24×24，躯干 24×36，手臂及腿部各 12×36 像素。人偶不包含在特效源素材内。

- `heat_up_v3.aseprite`：96×112，7 个独立图层，20 帧循环，每帧 80 ms。

- `draw_heat_up_v3.lua`：通过 Aseprite MCP 执行的绘制脚本。
- `manifest.json`：源与导出文件的 SHA-256。
