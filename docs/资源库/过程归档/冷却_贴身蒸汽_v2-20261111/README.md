# 冷却 · 贴身蒸汽 v2 · 二维候选稿

2026-11-11，用户查看现有冷却素材后反馈“雾气效果不太好”。本版通过 Aseprite MCP 重新绘制，先交二维候选稿供用户判断。

## 视觉

淡蓝灰色边缘、浅白色汽芯。蒸汽从手臂、腰腹和腿部附近冒出，沿弯曲细汽流上升，顶部形成松散的小团蒸汽；后半程出现断口、漂散碎片，透明度逐渐降低，最后完全消失。

参考人偶高 48 像素，仅用于二维预览。深色和浅色背景同时展示，便于判断昼夜环境中的辨识度。

## 源与导出

- `cool_v2.aseprite`：64×64，16 帧，每帧 75 ms，一次播放 1.2 秒。三个可编辑图层分别为后侧蒸汽、前侧轻汽流和消散碎片。
- `cool_v2_strip.png`：64×1024 的完整透明纵条，按时间从上到下排列。
- `cool_v2_rear_strip.png`、`cool_v2_front_strip.png`、`cool_v2_fragments_strip.png`：同尺寸分层导出。
- `cool_v2_preview.aseprite`：176×100 的二维审稿板。
- `cool_v2_preview.gif` / `.png`：4 倍最近邻审稿图，704×400。GIF 的最后透明帧停留 450 ms，方便区分重复预览的各次播放；源动画的最后一帧仍为 75 ms。
- `draw_cool_v2.lua`：在 Aseprite 中执行的绘制脚本。
- `manifest.json`：源文件与导出文件的 SHA-256。
