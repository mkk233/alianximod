## 空间运动与几何换算参数

- **换算**：`16.0 模型单位 = 1.0 世界格`（地面棋盘单格 `16×16` 模型单位 = `1×1` 世界格；施法玩家假人总高 `28.8` 模型单位 = `1.80` 格，眼高参考带中心 `Y = 25.92` 模型单位 = `1.62` 格）。
- **轴向与前向**：
  - `+Y`：世界竖直向上（喷涌单份初速度轴，以及多份向上锥形分散的中心锥轴）。
  - `-Y`：世界重力加速度方向。
  - `+X`：示意场景中施法玩家假人面朝前向（假人站于 `[-40, 0, 0]`，即抛射源点后方 `2.5` 格，避免遮挡中心竖直抛落轴）。
  - `XZ` 平面：地面基准面（顶面严格位于 `Y = 0.0`）。
- **原点 / 锚点 / 旋转中心**：
  - 示意抛射源点 `Origin`：`[0.0, 16.0, 0.0]`（离地 `1.0` 格高；游戏实际运行中由链上索敌落点或施法者出生源点 `entity.origin()` 决定，不写死固定世界坐标）。
  - 投射物示意体锚点：位于各自采样时刻的质心位置，旋转对齐瞬时速度切线向量 `direction = normalize(v0x, v0y - g*t, v0z)`。
