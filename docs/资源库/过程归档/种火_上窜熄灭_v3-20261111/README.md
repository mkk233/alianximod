# 种火 v3：上窜、由下至上熄灭

状态：二维动画草稿，待用户确认。未替换运行资源、未修改代码。

用户本轮要求：保留 v2 火焰画风，从下方升起烧过敌人，然后由下至上自然消失。

通过 Aseprite MCP 批处理绘制。沿用 v2 前八帧调色板和火焰，取消整体缩小；后段火焰保持宽度并上移，锯齿状消退边界从底部向火尖推进，最后留下分离的亮色余烬，再全透明。尾端没有长期停留的火苗。

规格：64×64，16 帧，50 ms/帧，单次 0.8 秒；竖条 64×1024，第 16 帧透明。预览 GIF 在末帧额外停顿便于区分重复播放，停顿不属于素材时间。
