# 水牢 v3 原画 · 等比公告板验证 v4

状态：修正先前按目标宽高分别缩放、把泡泡拉成长椭圆的问题。游戏方向仍是单张二维动画平面，始终朝向当前客户端镜头；此目录为正确比例的预览，未接入游戏。

## 固定设计规则

- 原画是 96×96 动画帧，展示平面必须为正方形，两轴使用同一个缩放值，保留原图轮廓。
- 根据目标投影包围范围计算足以包住目标的统一尺寸，只整体放大或缩小，不分别改变宽高。
- 继续直接使用已确认的 Aseprite 二维 v3 PNG；原素材没有重绘或拉伸。
- 朝向按当前客户端渲染相机计算，多人各客户端独立，无需同步朝向角度。
- 面片仍保持透明混合、深度测试开启、深度写入关闭，位于目标近侧前方。

## 预览与文件

- [镜头环绕动画](water_prison_billboard_orbit.gif)：720×720，96 帧，4.8 秒。
- [固定视角](water_prison_billboard_fixed.gif)、[宽矮目标](water_prison_billboard_wide.gif)：各 32 帧，1.6 秒。

- `preview-billboard.js`：打开工程后通过 MCP 执行，复现等比缩放、镜头朝向及纹理播放。动态朝向回调并非 bbmodel 单文件自带。
- `build-billboard.js`、`render-previews.js`、`export-previews.ps1`：建模与预览复现脚本。
- `render-validation.json`、`source-validation.json`：160 帧的展示宽高一致、朝向与深度位置检查，以及原图一致性核对。
