## 保留结构的检查

与v7模型逐项比对，网格顶点、面、UV、层级、组、动画均一致；主体贴图逐字节一致。只替换两张浪缘贴图，结果见 `validation.json`。

根组仍2.4秒逆时针一圈；纹理仍1.6秒局部水舌伸长、珠滴断离、回缩循环，不增加整周UV滚动。0与4.8秒的根变换、贴图帧完全一致。斜视和俯视各96帧均有不同画面。

为严格保留v7结构，部分网格名称仍包含旧称“锯齿”；实际贴图已改为本版水膜毛边。

重开Blockbench后，运行 `preview-water-unlit.js` 可复现本次水体原色展示；只关闭水体材质的会话明暗衰减，人物仍正常受明暗影响。该会话设置不存入模型。
