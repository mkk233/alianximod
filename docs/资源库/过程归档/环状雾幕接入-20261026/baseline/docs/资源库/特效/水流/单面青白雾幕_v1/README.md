# 水雾领域 · 单面青白雾幕 v1

状态：2026-10-26 美术预览，待确认，未接入游戏。保留已有细雨与所有旧素材。

通过 Photoshop MCP 路径选区填充绘制，无生成式图像。每帧128×64，32帧，每帧50ms，循环1.6秒。青灰、青白雾团采用2像素阶梯层次，低透明度，上下边缘透明，横向64像素周期可连续平铺。漂移与浓淡变化均完成整数周期。

- `mist_panel.psd`：128×2048，可编辑的32个帧图层。
- `mist_panel.png`：原尺寸透明竖向序列，每帧128×64。
- `单帧/`：32张PS直接导出的透明PNG。
- `mist_dark.gif`、`mist_grass.gif`：深色和草地色背景循环预览；背景仅供查看。
- `mist_three_layers.gif`：三层同位置叠加的浓度上限预览，不是环形领域的游戏实测。

用于竖向单面雾幕，未来可沿圆周多方向布设；材质本身不含雨丝、水面纹理、粉色或背景。接入时保持2:1画幅比例，避免上下平铺，横向可重复；多面重叠应控制透明度。直接绑定序列PNG时由渲染器选帧，不能假定mcmeta自动播放。

粉色可能来自资源缺失、顶点染色或材质配置；本次仅制作正确色相素材，不宣称修复游戏渲染。未来接入时需分别核对雾幕与雨丝的资源引用和颜色。

制作脚本见 `docs/资源库/过程归档/单面青白雾幕-20261026/`。
