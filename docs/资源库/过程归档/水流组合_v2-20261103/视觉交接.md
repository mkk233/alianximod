# 水流组合 v2 草稿视觉交接

状态：用户要求水流更饱满、水域内也看见水流；本版本已修改并送看，尚未确认，禁止正式采用或运行接入。主会话为本目录唯一作者。

本版沿用真实 Blockbench 项目 water-vortex-composition-v1（UUID 2f8f5270-05b0-e005-ffd6-5478b717a7a1），保留旧版导出、不动其他项目。Blockbench 5.2.2 / 插件1.10.1。模型通过 MCP 原生建模、UV编辑及 project codec 导出为 water_vortex_v2.bbmodel。Aseprite 1.3.17 batch 制作与预览 water_flow_v2.aseprite/png（64×32，增强蓝色主体和泡沫）；bubble_v2.aseprite/png（16×16）沿用 v1 同像素泡膜。water_reference_v2 仅边界示意备用，不作为运行水材质。

16 模型单位等于1游戏格，Y向上。左右面板分别位于x=-176/+176，仅预览排版。旋流吸引外沿8格：5条较宽平面内旋带，单带宽约0.8格。右侧龙卷上升高度8格，6条错相水带，单带宽9模型单位（0.5625格），底部半径约1.81格、顶部约2.38格；服务端核心默认半径2.5格，视觉不扩大碰撞或受力边界。上升带纵向共旋转2圈；透明间隙让被卷实体仍可见。水下另有6条内旋带，分布在约0.44/1.19/1.94格高度，外沿3.25格向内汇入；水域边界需按实际自然/临时水裁切，不能在空气中假冒水下特效。

气泡从底部穿过水下层向上，水下新增28个错相泡膜示意；运行密度按性能限额，保持分层而非仅在水面画圈。纹理静态，运行用几何旋转、UV滚动和泡膜位置体现运动，不能把所有层锁在同相位。

原7×7×3实心蓝色参考盒在v2中隐藏，改为12条细边界线，以剖视方式展示水下水流；这不是游戏中水块消失或透明度承诺。所有 reference_*、temporary_water 以及中性立柱/地板都是辅助，不导入运行。运行继续使用真实临时水，水下流带需适配游戏透明渲染阶段与深度测试，在水中和从岸边观察均可见，同时不能穿实体方块。

实际视口：tornado_front_v2.jpg、underwater_cutaway_v2.jpg、dry_swirl_v2.jpg；动态actual_viewport_animation_v2.gif由20张真实视口截图经Aseprite合成，4fps、5秒，源在viewport-frames和同名aseprite。动画仍演示实体错相分布、上升、顶部外抛；演示速度不等于游戏持续时间。服务端运动、资源消耗、流体透明混合、遮挡及摔伤没有因此被游戏验证。
