## 空间运动与时序换算参数

- **换算**：`16.0 模型单位 = 1.0 Minecraft 世界格`（地面棋盘单格 `16×16` 模型单位 = `1×1` 世界格；`t=0` 冻结施法虚影与 `t=20` 实心玩家假人总高均为 `28.8` 模型单位 = `1.80` 格，眼高参考带中心 `Y = 25.92` 模型单位 = `1.62` 格）。
- **轴向与前向**：
  - `+X`：本组释放瞬间（`t = 0 tick`）冻结的发射主方向（`frozenDirection`）。
  - `+Y`：世界竖直向上；`XZ` 平面顶面 `Y = 0.0` 为地面基准面。
  - `+Z / -Z`：水平侧向（主展示道位于 `Z = 0.0`；旁侧单份对照道平行平移至 `Z = +48.0` = `+3.0` 格；`t = 20` 走位后的实心玩家假人移至 `Z = -42.0` = `-2.625` 格并向右后偏转 `+38°`）。
- **原点 / 锚点 / 旋转中心**：

  - **时序公式**：第 `i` 份已有副本（`i = 0, 1, ..., copies - 1`）的出生延迟 `birthDelay = 10 * i` tick；按标准直线投射载体参考速度 `v = 0.8 格/tick`（`12.8 模型单位/tick`）取 **`t = 20 tick` 同刻快照**：

    - `t = 0` 浅青色半透明施法虚影站于 `[-20.0, 0.0, 0.0]`，前方 `[0.0, 24.0, 0.0]` 立青色八角冻结发射环，沿 `+X` 贯穿 `X = 14..288.2` 标出笔直冻结视线轴。

  - **下道：`无复制 + 错时`（仅 1 份副本对照道，`Z = +48.0` = `+3.0` 格）**：
    - 未装配 `一分为三` 时仅有 `1` 份副本（`i = 0`），`birthDelay = 0 tick` 立即出手，在 `t = 20 tick` 时唯一弹体 `control_single_born_0t_pos16b` 位于 `[256.0, 24.0, 48.0]`（`+16.0` 格）。
    - 对应 `+8.0` 格 `[128.0, 24.0, 48.0]` 与 `0.0` 格 `[0.0, 24.0, 48.0]` 处仅摆放暗灰镂空虚线框与地面 `×` 标记，明确表达「只有 1 份时立即出手，后续 `10 / 20 tick` 槽位为空，绝不凭空多变出弹体」。
- **尺寸 / 偏移 / 朝向**：
  - 通用梭形箭头弹体示意尺寸：总长约 `15.2` 模型单位（`0.95` 格，橙红尾翼十字高宽 `10.4`、橙琥珀弹身配波次金环、明黄阶梯尖锥朝 `+X`），仅作高辨识度的通用方向载体占位；运行时实际碰撞盒、速度与渲染模型完全遵循底层攻击术式自身定义。
- **UV / 帧布局**：仅使用 `12` 张 `16×16` 纯色示意色板贴图，无序列帧动画贴图。
- **材质 / 透明**：`swatch_frozen_ghost` 采用半透明青色表达 `t = 0` 历史施法时刻虚影；弹体与刻度标识开启适度可读对比，无运行时自定义着色器依赖。
- **时间 / 循环 / 相位**：单帧静态空间快照固定在 `t = 20 tick` 时刻（覆盖三份示例 `0 / 10 / 20 tick` 全部刚出生与飞行拉开状态），非循环持续驻留物。
- **跟随对象与运动绑定（含代码核对要点）**：
  1. 整组默认冻结 `t = 0` 释放时的原点、目标与锚点（延迟波次须使用本组冻结的原点/锚点/方向，不得在延迟触发刻重新读取 `owner.position()` 或实时准星重瞄准）；
  2. 每个实际副本从自身出生刻（`nowTick + 10i`）开始独立计算寿命，不补算尚未出生时的命中；
  3. 整组共享同一次释放的上下文（不为每个波次重新创建新的火种上下文），且错开后的真实后续攻击纳入费用与取消规则。
- **预览速度**：场景展示用的直线载体速度 `0.8 格/tick` 与 `t = 20 tick` 定格位置仅用于直观呈现 `10 tick` 步长对应的等距空间波次差，不代表施法前摇或固定弹速限制。
