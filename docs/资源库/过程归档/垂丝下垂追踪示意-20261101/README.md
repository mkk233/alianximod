# 垂丝 · 上沿走弹道、帘身下垂

2026-11-01，按「弹道只移动瀑布上沿，水从上沿垂直泻下」用 Aseprite 1.3.17 MCP 重画。形态示意，不是运行贴图，未接入游戏。

水色沿用垂丝瀑布单帧的六色：`#143f7a`、`#126aaf`、`#199ed2`、`#66d8ea`、`#c6f8fa`、`#f5ffff`。亮纹向下流动。上沿是帘顶的亮口。

三栏从左到右：

- 锁定 → 垂丝：上沿沿锁定方向伸出后停住，并略微下沉。水从这道上沿往下泻。目标离开后，帘留在原处。
- 锁定 → 追踪 → 垂丝：上沿按追踪横移，帘身每次都从新的上沿垂下。深色疏点是上一拍到这一拍扫过的水。
- 领域 → 追踪 → 垂丝：上沿生在域内随机点，上方红叉是不再叠加的抬高。追踪只搬上沿，出生点留在域内。
