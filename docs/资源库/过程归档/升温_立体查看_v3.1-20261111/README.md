# 升温 v3.1 · 实际 Blockbench 空间预览

2026-11-11，按用户确认用于三维预览的二维 v3.1 制作。二维来源为 `../升温_躯干少量热纹_v3.1-20261111/` 中的循环与入场 Aseprite 源文件。

## 查看文件

- `heat_up_v3_1_front_entry_loop.gif`：实际 Blockbench 前侧视口，8 帧入场（每帧 60 ms），接两遍 20 帧循环（每帧 80 ms）；合计 3.68 秒。
- `heat_up_v3_1_rear_loop.gif`：实际 Blockbench 侧后方视口，20 帧循环，共 1.6 秒。
- `heat_up_v3_1_front.png`、`heat_up_v3_1_rear.png`、`heat_up_v3_1_side.png`：实际视口静帧。
- `heat_up_v3_1_spatial.bbmodel`：在真实 Blockbench 桌面实例内建立和保存的可编辑模型。
- `viewport_frames/`：通过 Blockbench `Preview.screenshot` 取得的原始帧。两段 GIF 由 Aseprite MCP 将视口帧编码而成。
- 预览同名 `.aseprite` 仅保存视口帧，不是特效绘画源。

## 同版本对应关系

`textures/` 的 14 张纵向图集由二维 v3.1 的 7 图层分别无损导出，包含循环和入场。二维素材本身没有重画或缩放。

空间映射采用 3 个贴图像素对应 1 个模型单位，以贴图坐标 `(48,104)` 对应脚底中心。正面为模型 +Z：

- X = (贴图 X − 48) / 3；
- Y = (104 − 贴图 Y) / 3。

短手焰分别挂到左右臂，长腿焰分别挂到左右腿。胸腹热纹在躯干前方，背部复用同一层稀疏热纹。手臂和腿部外侧使用对应区域火舌，使侧面也可见；肋部使用原腰侧热纹。各片的裁剪范围、面方向、深度与归属部位均记录于 `placement.json`。

示意人偶高 32 模型单位。当前未通过游戏实测标定模型单位与方块之间的最终缩放关系，不能把 1 模型单位当作 1 格。灰色人偶、眼睛与地面格均是单独命名的辅助物，不属于运行资源。

## 复现与状态

`build_scene_v3_1.js` 通过 Blockbench MCP 建立新的独立项目，保留原有项目；`capture_v3_1.js` 在该项目内拍摄视口帧。`manifest.json` 绑定二维源、模型、导出纹理和预览文件的哈希。

本次交付为三维观感预览，等待用户反馈。游戏内照明、实体运动和透明排序尚未实测；未改游戏代码、未编译、未打包，制作表仍保持现有状态。
