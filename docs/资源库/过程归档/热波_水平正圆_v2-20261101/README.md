## 现行输入与原因

当前制作表 fire_shock_ring 在制作中第7行：一次向外扩散的环形冲击，中间留空，动画不代表每帧命中。现行基础内半径1.5格、外半径5格、高3格，视觉12tick。完整N/O/DV与实际代码事实见 `docs/开发记录/热波正圆精修-20261101/Cursor形状输入报告.md`，由 Cursor CLI grok-4.7-high-fast 只读采集。

旧原稿脚本把纵半径写成横半径×0.52，圆心在(32,36)；现行运行PNG与旧正式v1同字节。实际渲染为水平XZ正方形，两轴等比、UV整帧，无额外压缩。故本轮采用素材修正，不改Java渲染、术式判定或聚能逻辑。旧正式README的“未接入”是历史文字，不是当前运行状态。

## 二维修正

圆心改为(31.5,31.5)，横纵半径严格相同。沿用旧版橙红/金黄色值、渐隐函数及12处外缘短火星。主体/光晕的16帧均逐像素验证x/y互换及居中镜像相等，内心留空。

扩散参数 r=5+24t，t=frameIndex/16；旧稿为5+25t。末段减少不到1px半径是为等比圆环留边，避免旧稿末帧横向截边问题。外光晕半宽4px，橙色主体1.8px，金边0.8px。没有改成实心圆盘，没有添加持续燃烧或多次命中。

16帧持续合计0.6秒，对应现行12tick；帧时长按40/40/30/40ms重复，以GIF可表达的10ms精度逼近等间隔37.5ms。预览额外留0.4秒空场方便区分每次播放，该停顿不在运行竖条与16帧源中，不代表术式新持续时间。游戏继续由实体age与现行duration映射16帧，不读取Aseprite帧时长。

## 真实Blockbench空间交接

Blockbench 5.2.2 desktop、MCP1.10.1，项目UUID `9ef18951-91d4-889d-1f8e-c5f52e08573e`。二维源在同一轮制作后用于真实原生Mesh和Texture；不是离线拼贴或生成图。

本示意专门复现现行游戏映射：16模型单位=1格，效果载体为XZ平面160×160模型单位，即10×10格，Y=0.8模型单位即0.05格；UV覆盖完整64×64单帧，X/Z等比。纹理圆心落在世界中心。10格是载体方形边长，具体可见光环半径随帧变化，不等于每帧都覆盖判定外半径5格。

俯视为正交相机(0,240,0.001)，目标原点；斜视为透视相机(190,170,235)，目标(0,2,0)，FOV48。斜视屏幕中会自然投影为椭圆，这是用户已确认的世界水平正圆方案。不是朝镜头公告板。

地面方格与玩家是假人参照，统一在“示意辅助_地面与玩家”下，全部不进运行资源。唯一效果Mesh为 `fx_heat_world_circle`。几何只需现有游戏水平面，不要求游戏加载这个bbmodel。

Blockbench的emissive预览模式会把本素材的低alpha显示得过实；最终模型改为default透明模式，预览材质SHADE=false、EMISSIVE=false，保留PNG alpha与颜色，未把预览照明烘焙到贴图。重新打开模型时若受光变化，恢复该预览设置；这不要求变更游戏材质或shader。实际预览和最终GIF已使用该设置重新导出。
