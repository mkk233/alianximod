## 空间与UV

16模型单位=1格，Y向上，假人朝-Z；根及人物动画沿用正式v1。斩光组中心[0,26,-24]，组X=-90、Z=±35；分身斩光额外[20,0,-8]平移。服务端出刀中心只用一次，真实演员眼高仍取运行实体。

以刀面局部U为宽向、F为瞄准前向、N为法线：C+uU+vF±hN。
- u=±2.5格；v=[-1.15,-0.75,-0.25,0.50,1.50]；h=[0,0.08,0.16,0.10,0]格。
- 原生Mesh在斩光组未旋转坐标中顶点为[x=16u,y=26+16v,z=-24±16h]。最大总厚0.32格；最近视觉点约眼前0.35格，最远3格。
- 原图128×128逐字节使用。原生BB贴图坐标X对应u从左至右0..128；Y沿用v1上端是PNG顶部，故Y=128×(0.5-v/3)。设计文档中的纵向归一化(v+1.5)/3用于几何轴，落实PNG顶部原点时须翻Y。裁剪只裁后部，不把整个PNG重新拉伸。上下表面一致连续，侧边沿原边界alpha取样。
- 原生Cube与新Mesh共用纹理slash_arc_plane_v1 (d3414cad-411f-f167-0ad6-d711514cb985)。透明、双面、全亮；新壳没有纯色侧盖，不改世界深度遮挡。
- 动作出刀、0.20秒相位、中心/宽深/roll、命中/费用都不因视觉壳变化而改。整个壳scale在出刀0.92、0.04秒1、0.14秒1、0.20秒0.001。
