- `ground_ash.png`：过程v5/A，16×16不透明静态灰烬。
- `ground_ash_b.png` / `ground_ash_c.png` / `ground_ash_d.png`：过程v5b/B、v5c/C、v5d/D，16×16不透明静态变体。

四种底纹按地表坐标稳定选择并在存续期间固定，避免按帧切换或固定棋盘排列；火星另作坐标相位偏移。最近邻采样，不做平滑插值。帧UV为frame/24至(frame+1)/24，frame为0–23。运行实现若原先硬编码64×1536，须适配16×384。本次不复制到src，由Cursor实现者接入 `textures/effect/liaoyuan_v3/` 对应同名PNG。

采用静态灰烬面加透明余烬两层。`ground_ash*_composite.png` 是保留的原尺寸合成动画导出（16×384），已包含余烬，不得再叠 `ground_embers.png`；推荐运行只用前述五张PNG。
