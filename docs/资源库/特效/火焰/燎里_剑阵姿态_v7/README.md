# 燎里 · 剑阵姿态 v7

2026-10-30 用户原话：`ok就用这一版特效还用现在游戏内的`。本目录只归档背后八剑的位置、朝向和俯冲跟随。运行时仍用燎里 v6 的六张透明贴图，不把灰蓝玩家、红柄金刃占位模型复制进游戏资源。

不采用未修正局部坐标的 continuous 模型，也不采用俯冲位移还是 `[0,-14,0]` 的那一版。

## 坐标

Blockbench 自由模型。玩家面向 -Z，背部 +Z，向上 +Y。人体高 32 个模型单位时，游戏里按现有 1.8 格身高换算，不能把模型单位直接当方块。预览动画 3 秒只说明站立和俯冲两段，不是新的施法时长。

八个柄点在上半弧，半径 7，背深 z=5.5，扇心高度 y=18，角度 -180、-154、-128、-102、-78、-52、-26、0，左右镜像。`sword_*` 是尖端更远离背的原始方向。站立朝下用同柄点上的 `down_mount_sword_*`，绕该柄点 X 轴 +90°。接入时只取这一套，不要把两组剑叠在一起。

`BodyPose` 原点 `[0,16,0]`。动画 `animation.liaoli_standing_to_dive`：0–1 秒身体 X 旋转 0°，2–3 秒为 -90°。`BackFan` 位置 0–1 秒 `[0,0,0]`，2–3 秒 `[0,-12,0]`。-12 是相对更早的 -14 朝头前移 2 个模型单位。横置后这个位移把整组剑阵放到腿部附近。
