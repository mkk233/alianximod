## 动画与空间约束

- 八柄视觉剑在玩家背后与两侧扇形排列，以玩家自身中线左右镜像。预览角度对应-180/-154/-128/-102/-78/-52/-26/0度，成对长度、间距、斜角一致；不是依赖摄像机屏幕的假对称。
- 剑柄朝后倾：每柄剑柄在玩家前后轴上比剑尖更靠后。斜侧面预览使用相对坐标柄z=-18、尖z=-6，只表示方向关系，不能把像素坐标直接当世界格数。
- 火从玩家身后起势，逐渐延伸并覆盖剑柄和剑身，再形成金黄色剑光与宽幅赤红流焰。禁止只从剑尖突然起火。
- 手持刺击剑有独立的左右分流，沿剑尖至玩家身后的方向流动。图片局部+x为流动方向，运行时必须将该局部轴反向对齐刺击方向。不是向剑尖前方喷射。
- 同时存在三道火焰环，环面围绕玩家前后轴，沿玩家后方移动且半径持续增大，三个错开相位循环接续。环不能固定在原位仅做缩放，也不能向玩家前方移动。
- 上述都是燎里的视觉表现，不新增伤害体、攻击次数、远程弹或资源消费。服从最长40tick、松开/换剑/死亡提前收招的同一生命周期。
- 游戏需要独立的空间剑/流光/圆环渲染接点，不将本目录带人物预览作为整幅贴图挂到玩家身上。
