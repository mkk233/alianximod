# 柳叶形次元斩 v1

状态：2026-10-25 已通过 Photoshop MCP 绘制，待用户确认，未接入游戏。

单道柳叶裂隙，两端尖细，中段稍宽并微弯，约8°倾斜。深靛核心、紫蓝边缘、单侧断续近白刃光；MC硬边像素风，无模糊光晕、无生成式图像。

- 原生96×48，16帧，每帧50ms，单次0.8秒。
- 0–2帧细缝伸展，3–4帧快速张开，5–6帧峰值，7–11帧先收宽后缩长，12–14帧断续残光，15帧全透明。
- `dimension_willow.psd`：96×768竖向序列，16个可编辑帧图层。
- `dimension_willow.png`：原尺寸透明序列；`单帧/`为16张透明PNG。
- `dimension_willow_preview.gif`：8倍最近邻深色底预览，每次动作后额外留400ms空白。GIF为方便观看而重复，正式素材是单次动作。
- `dimension_willow_keyframe_8x.png`：峰值放大预览；`dimension_willow_contact.png`：4×4总览。
- `验证记录.json`：透明度、空白尾帧及序列一致性检查。

接入时每次释放播放一次，帧15后停止；一分为三应分别创建三道该单次动画，不在贴图中预画三道。帧内纵向UV为 `(frame+localV)/16`，保持96:48画布比例；不用循环mcmeta代替单次播放控制。本次不改代码、不编译、不打包。
