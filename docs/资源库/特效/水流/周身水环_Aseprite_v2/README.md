# 周身流动水环 · Aseprite v2

2026-10-27，按用户要求改用新配置的 Aseprite MCP 完成。Aseprite 1.3.17 批处理引擎已验证可用；实时桥端口41235被占用，本次未更改端口或关闭其他实例。原PS草稿保留。

将PS完成的16帧水环移入Aseprite原生时间轴，拆成前后水体与白沫四层，并在Aseprite中增加周向流动水珠，完成展开水纹和角色遮挡演示。无生成式图像。每帧100ms，共1.6秒循环。

- `water_ring.aseprite`：128×64，16帧，后环水体/后环白沫/前环水体/前环白沫四个可编辑图层。
- `water_ring.png`：128×1024透明竖向序列；`water_ring.json`记录帧信息。
- `water_band.aseprite/png`：128×16每帧的展开水纹，16帧，水体和白沫两层；PNG为128×256。供未来三维环网格映射，水纹共用色板和动画相位，不含预画透视。
- `body_preview.aseprite`：128×96，后环/角色占位/前环三层，用于展示围绕身体及遮挡关系。占位人形只用于演示，不属于正式特效。
- `water_body_preview.gif`：环绕角色演示；`water_ring_preview.gif`：水环单独预览；`water_band_preview.gif`：展开水纹预览。
- `单帧/ring`、`band`、`body`：Aseprite直接导出的原尺寸PNG。GIF只封装这些帧，深底仅供观看。

核对原生文档为16帧、每帧0.1秒；全部帧中心透明，相邻帧均有变化。角色遮挡已在编辑器预览核对。待用户确认，未接入游戏、不改游戏代码、不编译打包。真正三维环绕需由环网格及深度测试完成，不能将椭圆图始终贴在角色前面。
