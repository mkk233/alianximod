# 卡通水弹 v1

状态：初稿，待用户确认；2026-10-24 在 Photoshop 中通过硬边选区填色绘制，未使用图像生成。

## 视觉与动画

向右飞行的透明水弹，包含弧形翻卷浪头、蓝青水核、两条摆动拖尾及循环脱落的水滴。原生 32×32 像素，5 色，不透明像素与全透明背景之间无抗锯齿。16 帧，100ms/帧，1.6 秒循环；动画保持水弹前端基本稳定，内部流纹和尾部独立变化。

## 文件

- `water_bolt.psd`：32×512 竖向序列，16 个可编辑帧图层。
- `water_bolt.png`：透明竖向序列，帧从上到下 0–15。
- `water_bolt.png.mcmeta`：32×32 帧，`frametime: 2`，不插值，按顺序播放。
- `单帧/frame_00.png` 至 `frame_15.png`：原尺寸透明 PNG。
- `water_bolt_preview.gif`：320×320 最近邻放大循环预览。
- `water_bolt_keyframe.png`：首帧的 10 倍最近邻预览。
- `water_bolt_contact.png`：4×4 帧总览，最近邻放大预览。

## 游戏接入

采用 Minecraft 原版的 PNG 序列及同名 `.png.mcmeta` 组织方式。原版 1.20.1 的 `water_flow.png` 与 `water_still.png` 及其元数据已保存在 [制作过程目录](../../../过程归档/卡通水流-20261024/原版参考/)，仅作为动画格式参考；本稿图案独立绘制。

`.mcmeta` 适用于支持动画的纹理图集加载。自定义飞弹实体若直接绑定整张纹理，不能仅靠放入 `.mcmeta` 自动播放，需在渲染端按帧裁切 UV 或使用相应动画图集。本次仅归档素材，未修改模组代码、未替换游戏资源，也未做游戏内验证。

UV 建议：每帧覆盖整张图宽度，帧 f 的纵向范围为 `[f/16, (f+1)/16]`。按 2 tick 一帧循环，在实际渲染中处理图集缩放及边缘采样。世界空间飞行速度与贴图播放速度独立。

预览导出：GIF 和总览 PNG 使用 ffmpeg 将 Photoshop 已导出的原始帧封装。Photoshop 制作额外总览时报告暂存盘已满，正式源文件与 16 帧均已保存。
