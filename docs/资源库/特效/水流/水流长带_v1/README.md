# 水流长带 v1

状态：2026-10-24 用户已确认，作为独立版本保留。按用户提出的溪流条状、水之呼吸式翻浪方向，在 Photoshop 中独立绘制；水弹版本另行保留。

## 设计

- 128×32 横向透明水带，贯穿画面，左右可连续拼接。
- 三处大小不同的卷浪，白色浪脊、青蓝长流线和深蓝下缘；没有封闭弹头或圆形水核。
- 16 帧，100ms/帧，循环 1.6 秒。大浪峰错开翻卷，内部细流线向右移动，水带轮廓仅轻微起伏。
- 6 色硬边像素，无抗锯齿、模糊或生成式图像处理。

## 文件

- `water_ribbon.psd`：128×512 竖向动画序列，16 个帧图层。
- `water_ribbon.png` 与 `water_ribbon.png.mcmeta`：原尺寸序列及动画配置，帧宽128、高32，每帧2 tick，无插值。
- `单帧/`：16 张128×32透明PNG。
- `water_ribbon_transparent.gif`：6倍最近邻放大，透明循环预览。
- `water_ribbon_preview.gif`：同一动画叠加深色底的观看预览，仅背景为展示用途。
- `water_ribbon_tile_preview.gif`：两段左右拼接的预览。
- `water_ribbon_keyframe.png`、`water_ribbon_keyframe_8x.png`：首帧及8倍预览。
- `water_ribbon_contact.png`：16帧总览。

## 用于术式特效

本版适合沿水流、曲线飘带或斩击轨迹铺设的特效纹理。要在三维中弯成绕身水流，需由带状网格或轨迹渲染器控制形状；贴图本身负责水纹翻卷。

`.mcmeta` 供支持动画的纹理图集使用。自定义实体直接绑定 PNG 时，需要渲染端逐帧裁切UV或接入动画图集；帧 f 的纵向UV为 `[f/16,(f+1)/16]`。当前仅归档素材，未接入游戏，未做游戏内验证。

GIF及总览仅从Photoshop导出的原始帧封装，正式素材以PNG与PSD为准。制作脚本与色号数据位于 [过程归档](../../../过程归档/水流长带-20261024/)。
