## 运行交接

16模型单位=1游戏格，Y向上。模型面板x=-176/+176仅是排版，不带进世界坐标。实际锚点为释放底座解析后的宿主中心。独立旋流外缘默认8格，5条饱满平面内旋带。组合高默认8格、服务端本体半径2.5格，主6条水带下窄上宽，rF=R×(0.30+0.65×t^1.15)，默认0.75→2.375格，单带竖直宽0.5625格。参数随实例有效R/H缩放，与服务器共用轮廓。

水下有三层汇入回旋和上升泡膜，按真实水范围裁切；岸边和水下视角均需可见，保留方块深度遮挡。宽目标或外侧合法候选周围用短弧和连接水流携带，依真实受控根ID和AABB绘制，不能猜附近实体或把底部整个画回圆柱。退出、抛出、关闭立即撤掉对应局部显示。实际窗口/视距裁剪不得更改游戏容量或费用。
