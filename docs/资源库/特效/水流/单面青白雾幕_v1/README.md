# 水雾领域 · 单面青白雾幕 v1

更新：用户反馈白天过淡，2026-10-26 游戏雾幕PNG已由v2白天增强版替换；本目录作为历史版本保留。用户已确认雨丝颜色修复有效。以下为v1接入时记录。

状态：2026-10-26 已接入雾雨领域 `DomainVisual.VOLUME` 的外围视觉。游戏路径 `assets/xueximod/textures/domain/mist_panel.png`。领域判定、碰撞和范围仍是盒子；环是内接在水平截面上的 16 面视觉，不改玩法边界。`compileJava --offline --no-daemon` 已通过。游戏内粉色是否消失、环形观感、专用 shader 是否加载，都还没有实测。PSD、单帧和预览仍留在本目录。保留已有细雨与所有旧素材。

通过 Photoshop MCP 路径选区填充绘制，无生成式图像。每帧128×64，32帧，每帧50ms，循环1.6秒。青灰、青白雾团采用2像素阶梯层次，低透明度，上下边缘透明，横向64像素周期可连续平铺。漂移与浓淡变化均完成整数周期。

- `mist_panel.psd`：128×2048，可编辑的32个帧图层。
- `mist_panel.png`：原尺寸透明竖向序列，每帧128×64。
- `单帧/`：32张PS直接导出的透明PNG。
- `mist_dark.gif`、`mist_grass.gif`：深色和草地色背景循环预览；背景仅供查看。
- `mist_three_layers.gif`：三层同位置叠加的浓度上限预览，不是环形领域的游戏实测。

用于竖向单面雾幕。材质本身不含雨丝、水面纹理、粉色或背景。游戏里 16 个侧面共用同一帧，周向按累计边长连续采样，整圈收成整数次横向重复；纵向只映射当前帧，不上下平铺。直接绑定序列 PNG，由渲染器选帧，不靠 mcmeta 自动播放。相邻面共边，只提交一份面。

实际导出 alpha 为 0、8、18、26、36。接入时没有把 alpha 加倍。雾环使用专用 shader，只丢弃 alpha 小于等于 0 的纹素，用来留下 8 和 18 两档。`compileJava` 不能证明这个 GLSL 已在游戏里加载。

粉色根因是雾盒和雨丝把 overlay 坐标写成了 0，采到受伤红；本次改为 `OverlayTexture.NO_OVERLAY`。游戏内是否还偏色，尚未看过。
