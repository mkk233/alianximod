# 水流长带 · 可扩宽拆分版 v2

2026-10-26：用于垂丝＋聚能的可扩宽素材，已在 Photoshop 拆分、补绘及导出。原水流长带_v1完整保留。仅素材归档，未改代码、未替换游戏资源、未编译打包或游戏测试。

## 三个分件

- `ribbon_upper.png`：上浪缘，每帧128×22，序列128×352。保留原版前20行完整卷浪和水滴，最后2行为接合蓝色。
- `ribbon_middle.png`：可重复中段，每帧128×16，序列128×256。重新补画连续蓝色水体与稀疏移动流线，横向和纵向可重复，首末行都是接合色。
- `ribbon_lower.png`：下暗缘，每帧128×12，序列128×192。保留原版下部轮廓和短流线，前2行为接合蓝色。

每个PNG均有同名透明PSD，16个可编辑帧图层；不是把整张图纵向拉伸。三部分均16帧、100ms/帧，循环1.6秒，使用同一帧号f。`单帧/upper`、`middle`、`lower`保存PS导出的原尺寸分帧。边界接合色为 #126AAF、不透明，拼接时共享边界，不额外叠加反向面。

## 扩宽方式

上缘22像素和下缘12像素保持固定厚度，中部重复填充目标宽度。原像素比例下，组合画布高度为34＋中部高度；若要真正细如丝，需要另做细丝起始态，不能把完整卷浪压扁。

- 随时间整体变宽：上下缘向两侧分开，中部高度随聚能进度增加，水纹动画独立循环。
- 沿长度渐宽：每个横向位置使用自己的中部宽度，两侧边缘沿相应轮廓布设，中部填满；不要把整张浪头拉伸成楔形。

中段重复不足完整16行时建议从平色边缘衔接，或在渲染侧保留一行接合色，避免局部流线被突然切到边界。自定义渲染直绑序列时三部分各用 `v=(f+localV)/16`；中部重复应在当前帧内部处理，不能跨动画帧垂直重复。mcmeta只在支持动画的纹理图集中生效。
