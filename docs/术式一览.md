# 已注册术式

当前代码里能装配的全部术式，共 40 个：剑术 11、动作 2、术法 13、通用 14。其中 5 个是附魔。

记述用词：资源称法力，MAGIC 类称术法，施法物品称伞，伞是基础法器。代码标识不改。不使用灵力，也不写修炼境界。

冷却按 20 tick 等于 1 秒。剑术和术法在对应熟练等级不低于复杂度时解锁；动作和通用默认可用。雾雨、深海重压的复杂度是 10。

有伤害的术式，释放法力为伤害向上取整后乘 2。附魔为 2。领域、水幕、水环按各自的生成消耗，维持费写在同一格。双重释放按现在的 5 tick、两个末端成员书写。

来源：`ModTechniques` 与 `WaterTechniques` 的当前登记。日期：2026-10-25。
