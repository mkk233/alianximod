落点指定术式应该是一个与锁定目标相同的修改锁定方式的术式而不是修改碰撞，落点锁定准确的说应该叫做空间锁定，具体表现为锁定准星最近实体周围3*3格子的空间，并在空间内随机位置生成装配链条上的下一个攻击术式

这样拼接 落点指定 → 一分为三 → 三维交错 → 点火 → 空间切割后就更应该正确在锁定目标出生成三道可以点燃别人的空间切割，
我们将术式详细分类一下
索敌逻辑修改术式
弹道逻辑修改术式
规则逻辑修改术式
动作术式
附魔术式
攻击术式
分为这六种类型
接下来我将说明这些术式类型的职责和具体表现

索敌逻辑修改术式为术式添加索敌方式，优先锁定准星附近的优先锁定血最少的优先锁定与玩家距离最近的，锁定一片空间，锁定一个方块，等等效果这类术式不会改变攻击术式的弹道逻辑原本这个术式是什么样的发射方式在适用索敌后依然保持什么样的发射方式，但是会根据锁定的目标位置去发射而不是根据玩家的准星方向发射。落点指定与锁定目标都是这个分类

弹道逻辑修改术式为术式修改弹道，攻击术式本身就拥有弹道这种术式会覆盖攻击术式原本的弹道并用新规定的弹道作为代替，部分剑术攻击的弹道无法修改，这会写在攻击术式上我们应该为攻击术式增加一个属性来判断是否可以修改弹道，弹道底座应该支持各类函数曲线与直线，三维的不同方向，例如螺旋弹道，抛物线弹道，直线弹道，垂直下落弹道，垂直上升弹道，旋转类弹道等。垂落术式和三维交错都是这个分类

规则逻辑修改术式是为术式的释放新增一种规则，这类术式的功能更像是代码语法终端if for这类，他们可以互相嵌套不会相互影响同时作用也不会影响其后方拼接的其他术式效果，而且一起带给遇到的第一个攻击术式，一分为三，双重释放是这个分类

动作术式的功能是完成一个动作并打出下一个遇到的攻击术式，如果前方有规则类术式则会改变这个逻辑变成完成一个动作动作过程中跟踪动作释放

附魔术式的功能是为攻击附魔，如果只装配附魔术式那么将会直接给武器附魔让下一次攻击获得附魔属性加成以及效果，如果附魔后又攻击术式则会让附魔效果添加在攻击术式上，当有攻击术式存在时附魔术式不算做被释放而是被继承，当没有攻击术式时附魔术式会算作会被释放然后将效果继承在武器上

攻击术式是最直接是生成一个碰撞盒加特效，有多个参数可调整之前我详细说过此处不再赘述你可以在代码中回忆一下，现在的攻击术式底座应该是正确的才对

他们互相组合拼接组成技能就是我们这个模组的核心玩法了目前的拼接逻辑明显存在问题
在设计上前三种逻辑修改术式应该可以互相嵌套无论摆放顺序如何最终结果都应该一致，三种逻辑修改应该同时生效并且互相影响无论玩家装配顺序如何这三种逻辑的互相影响的方案都统一为索敌逻辑影响弹道逻辑出现的方式规则逻辑记录并让收到索敌逻辑影响的弹道同步给收到规则影响的术式上链条上玩家可以随意摆放位置但一定要在后续有可释放的攻击术式情况下才结算，结算链条为索敌逻辑→弹道逻辑→规则逻辑→攻击术式，只有附魔术式的情况下就仅结算规则逻辑和附魔术式不结算索敌与弹道逻辑，同时出现附魔术式+加攻击术式的情况按照附魔术式的继承效果结算攻击术式。

1.落点指定 → 一分为三 → 三维交错 → 点火 → 空间切割 这段装配的正确效果应该是，指定落点遇到一分为三生效让后续被分为三份的攻击术式按照落点指定的范围内随机生成，一分为三遇到三维交错调整了后续被分为三份的攻击术式的弹道，在三维空间随机角度随机高度出现分布范围依然遵守落点指定，遇到点火记录点火的数值和效果进入检测如果后续没有攻击术式则仅释放三次点火在武器上，实际计算结果如下三次点火叠加1*1.3*1.3并缩减0.3+0.3总计60%的冷却，由于产生了元素叠加反应所以附加的附魔伤害2点不会生效三次而是让武器基础攻击力计算一次N*1*1.3*1.3，再让附加的2点附魔伤害计算一次2*1*1.3*1.3,最后同时提升剑原本的攻击力和附魔产生的额外伤害后相加最终数值同时造成5秒燃烧，燃烧时间不叠加，这个效果会记录在释放时玩家手持的武器上，释放完后整个链条进入CD，此时被记录的落点指定和三维交错不会生效因为没有可以生效的对象他们必须要有攻击术式作为承载对象才会生效，记录在剑上的效果在玩家攻击后被消耗，玩家攻击前会一直存在剑上，此时如果释放其他附魔效果会覆盖掉原有的附魔数值与属性重新计算不会叠加。如果后续有攻击术式则完全不一样，点火会继承在攻击术式上让攻击术式获得2.附加伤害和燃烧效果因为不产生元素叠加反应因为三次点火分开使用到三道攻击术式上没有产生叠加的效果所以最终伤害计算就是(攻击术式伤害+附魔额外伤害)*3此时落点指定+一分为三+三维交错同时生效，弹道生成在指定落点周围3*3*3的空间内并根据交错的算法随机分布，总计出现三道攻击术式；同时你要记得就算玩家没有这样组合这些术式单独使用或者和其他术式组合也该正确生效
