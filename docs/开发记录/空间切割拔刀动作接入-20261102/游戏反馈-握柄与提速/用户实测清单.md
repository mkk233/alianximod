# 空间切割握柄快拔 v6 实测

- 编号 / 名称：space_cut / 空间切割握柄与动作速度返修。
- 前置：装备原版布局的剑并装配空间切割，分别使用第一人称和第三人称；可另看左主手、细手臂、主副手及联机观察者。
- 步骤：释放一次、连续释放，再组合一分为三；观察开始握持、抽出、挥斩、动作结束与原斩面消失的先后。
- 预期：掌心在刀柄缠把上，护手和刀刃在手外；刀初始左腰朝后，由右手拔斩；约0.15秒拔出、0.19秒挥斩末态、0.5秒动作结束，早于1秒斩面结束，无旧1.6秒停姿；结束后持物恢复，伤害与三道斩面保持原行为。
