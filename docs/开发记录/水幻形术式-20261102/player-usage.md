# 水幻形怎么放

水幻形是法术。登录不会自动学会它。先让法术等级至少到 1，再用已有的 `/shu learn water_phantom` 学会。`/shu learn` 不提升等级；`/shu rank magic 1` 只改等级。`/shu learn all` 会把需要学习的术式一并学会，并把法术等级升到够解锁。

断潮登录就会学会。创造栏「术基础」里有基础法杖和术式收纳箱。`/shu stone water_phantom` 和 `/shu stone tide_sever` 给的是无属性术式石。带属性的原胚这一版不能用。

主手拿法杖，按 M 打开法杖装配。槽 0 先放水幻形，再放断潮。断潮在「全部」或「剑术」里。只放水幻形、只放断潮、反着放或换成别的攻击，都不能放。

主手法杖，右键释放。

- 不潜行：水形留在原地，直到敌人碰到它，或这次受击被接受。然后只响应一次，放出断潮并散成水。默认会留到被触发，或者寿命走到头。默认寿命是 0，这次加载里不会自己到期。
- 潜行：下一刻立刻放出断潮并散水，不用等碰到人。

按住不会连着放，松开再按才行。同一个人在同一个服务器刻里成功放过一次，这一刻再放会被拒绝。这不是全场只能有一具。每个人最多 4 具，全服最多 128 具。人下线、换维或这次加载结束会清掉，不会写进存档一直留着。

默认一次扣部署魔力 10 和断潮魔力 12。基础冷却是 20 刻加 20 刻，再按现有缩减算。魔力不够不会进入这次冷却。除断潮以外的下一格，收费前就拒绝。

可改的配置：`manaCost` 默认 10，`cooldownTicks` 默认 20，`lifetimeTicks` 默认 0（0 到 1200000 刻），`decoyRadius` 默认 8 格（0 到 16，潜行时写成 0）。没有伤害倍率。重新打开世界后才吃新配置。
