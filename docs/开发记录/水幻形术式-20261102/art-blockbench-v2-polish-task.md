# Steve v2 水感修整

继续同一固定模型 `--model grok-4.7-high-fast` 和既有艺术任务；不是正式逻辑复审，不计新阶段。只写当前v2过程目录及本批 `art-blockbench-v2-polish-report.md`，不写Java、src资源、制作表、配置、不编译或运行游戏。

主会话已看最终真实视口。六方体比例和方角方向正确，保持它们与Steve同尺寸，不再改轮廓。当前128根分解杆每面又画了矩形框，`bb_break_mid.png`读成大量空心金属框碎片，水滴太小而不明显，尚未达到“变成水撒掉”。本轮只精修这一观感并保留可编辑源。

先发现工具和正确项目，保护其它项目。仍直接在真实Blockbench绘材质，不要求Aseprite，也不使用ImageGen。沿用独占v2项目 UUID `20e6cc04-1d69-c38a-3030-5a2bacdaf4f4`，若存在先保存未改版到本过程目录 `initial/`；不要覆盖无关项目。用户没有确认任何v2，不作为采用版。

具体修正：
1. 静态六个标准Steve方块保留。方边仍清楚，面内部透明。外缘深蓝可减弱一档，避免过重的金属框感。
2. 分解碎片改专用实心水色纹理，不许每一根微小碎片仍画一个矩形空框。青蓝短水片、少量亮色水点，厚度细，透明感；可以开独立纹理/UV区，需在Blockbench内实际画。
3. 不要128根完整长杆同时漂浮。边缘断开后很快缩成短片/滴状方颗粒，下坠洒落为主，只有少量侧向飞散。合理降低可见片数（例如最多约48短片+20滴；最终按观感），不做整个人同时缩小。让中段看出从上身散下来的水，末端地面小水滴清晰可见后消失。
4. 稍增加驻留时沿方边移动的短高光，真正用可编辑动画或已验证的纹理帧，不把静止白块写成流动动画。基础方体保持静止。若Blockbench无法真实预览流动，明确记录限制，不伪造。
5. 重新输出真实视口全景、前侧背、散水中段、落地和GIF；不使用旧帧冒充修整后。同版更新 `.bbmodel`、实际纹理、`visual-handoff-candidate.md`、`bb-preview-evidence.json`哈希和数量。记录哪些时间是预览、单位换算仍不能谎称32单位=1.8格。
