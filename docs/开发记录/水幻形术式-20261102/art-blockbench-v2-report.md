# 水幻形 Steve 水线 v2 预览

这是候选，还没正式采用，也没有接入游戏。

用户要求造型改成原版 Steve 方体，并直接在 Blockbench 里画透明水线。v1 的圆润水线没有继续改。皮肤格式在 Blockbench 5.2.2 里没有动画、也不能进编辑模式，所以用独立 free 项目，按原版六方体的尺寸和 64 UV 来做。

项目 `water_phantom_steve_v2`，UUID `20e6cc04-1d69-c38a-3030-5a2bacdaf4f4`。v1 项目和 iaido 都还在，没有覆盖。

静止时是六个方角方体：头 8×8×8，躯干 8×12×4，双臂各 4×12×4，双腿各 4×12×4。脚底 y=0，头顶 y=32。手臂下垂，枢轴是原版右臂 [-5, 22, 0]、左臂 [5, 22, 0]、双腿 [-2, 12, 0] 与 [2, 12, 0]、头和躯干 [0, 24, 0]。这 32 单位是原版几何高，没有把它说成 1.8 格。

水线贴在每个面的方形边缘上：深蓝外缘、青蓝、短的近白高光，面内部透明。正、侧、背都有。边段是贴着这些边的直杆，1.20 秒阶跃替换方体外壳，再裂开、下坠、缩成小片和水滴。没有把整个人缩成一块蓝板，也没有画出手弧线。两触发形式共用这段散水；首批只准备配断潮，由装配决定。

灰色 Steve 用同一套方体，放在 X+26。叠合图是拍摄时临时挪到同一位置，拍完已撤销。

预览在 `docs/资源库/过程归档/水幻形_Steve水线_v2-20261102/`：`water_phantom_steve_v2.bbmodel`、`steve_water_lines.png`、七张 `bb_*.png`、`bb_preview_replay.gif`。GIF 由离屏视口的 17 帧编成。交接写在同目录 `visual-handoff-candidate.md`。

Blockbench 不能证明伤害、接触、网络或渲染缩放。淡出是缩放。关闭离屏视口时工具返回 `onContextMenu is not defined`，那是私有视口，没有动用户相机。
