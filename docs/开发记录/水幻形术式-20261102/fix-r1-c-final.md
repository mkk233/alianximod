原先那张静态的「主人 → tick」表会在同一个进程换世界后留下。新局 tick 再次走到同一个数字时，会被当成已经部署过。现在窗口必须同时对上 `MinecraftServer` 实例和这次的服务器 tick。只凭 tick 数字相同不会拒绝。

同一窗口里第二次成功仍然拒绝，第一次的记录留着。只有 `spawnCaptured` 接受之后才写入。失败、魔力不足和普通链都不入账。账里只存主人 UUID。

清空挂在捕获包自己的监听上：

- 服务器变了，或 tick 已经前进，就清掉旧记录。这一 tick 结束后也清掉，不把上一 tick 的主人留到下一 tick。
- 停服清空。
- 主人登出时去掉这名主人；没有别人时放开服务器引用。
