<meta charset="utf-8"/><div data-lark-html-role="root"><div><strong>## 1. 设计目标与硬约束</strong></div><div><br></div><div><strong>### 1.1 核心玩法</strong></div><div><br></div><div>火系的主玩法是围绕炉心·过载建立爆发窗口：</div><div><br></div><div>```text</div><div>燃烧进入过载</div><div>  → 火术式在敌人身上积累火种</div><div>  → 助燃术式消耗火种，把资源转化为本次伤害、持续时间或范围</div><div>  → 冷却结束窗口，用蒸汽冲击拉开距离</div><div>```</div><div><br></div><div>普通炉心是低风险过渡和预热；炉心·过载是火系最高伤害与最高火种获取效率的窗口。炉心本身不产生被动火种光环。</div><div><br></div><div><strong>### 1.2 硬约束</strong></div><div><br></div><div>1. 火种是火系唯一可积累、可消耗的资源。</div><div>2. 火种挂在目标实体上，不挂在施法者身上；不注册 CASTER 或 WORLD 火系资源。</div><div>3. 没有声明火种绑定的术式，不得自动产生或消耗火种；伤害数值不能反推火种。</div><div>4. 同一目标在同一次施法中最多获得一次火种。</div><div>5. 同一次施法对同一目标最多进行一次火种消耗。</div><div>6. 一个目标在同一次施法中被消耗火种后，不得再从该次施法获得火种。</div><div>7. 火焰伤害本身不会自动获得火种；必须是显式生产者。</div><div>8. 炉心火伤与火种 `BURST` 增伤在同一个加算层，不二次乘算。</div><div>9. 冷却释放是固定蒸汽伤害，不读取炉心层数、火伤爬坡、火种、能量或规则增伤。</div><div>10. 冷却只恢复生命上限，不恢复当前生命。</div><div>11. 炉心三式各自占技能栏、各自结算魔力与技能冷却，不能互相替换或改写冷却。</div><div>12. 火种获取量为 0 时必须得到 0，不能被“最低 1 点”规则错误地变成 1。</div><div>13. 规则类术式可以放大火术式基础伤害与体积，但不能放大火种获取量或消耗档位。</div><div><br></div><div>---</div><div><br></div><div><strong>## 2. 术语与稳定 ID</strong></div><div><br></div><div>| 对象 | ID &#x2F; 值 | 说明 |</div><div>| --- | --- | 玩家可见循环与目标数值</strong></div><div><br></div><div><strong>### 3.1 状态机</strong></div><div><br></div><div>```text</div><div>NO_CORE</div><div>  ├─ 升温 → CORE &#x2F; amp 0</div><div>  └─ 燃烧 → OVERLOAD &#x2F; amp 1</div><div><br></div><div>CORE &#x2F; amp 0</div><div>  ├─ 升温 → 拒绝</div><div>  ├─ 燃烧 → 原地覆盖为 OVERLOAD，保留运行态</div><div>  └─ 冷却 → NO_CORE，触发蒸汽冲击</div><div><br></div><div>OVERLOAD &#x2F; amp 1</div><div>  ├─ 升温 → 拒绝</div><div>  ├─ 燃烧 → 拒绝</div><div>  └─ 冷却 → `BURST`：</div><div><br></div><div>```text</div><div>火伤总加成 = +60% + 24% = +84%</div><div>最终火伤 = 基础伤害 × (1 + 0.60 + 0.24)</div><div>```</div><div><br></div><div>该 84% 是一个加算层，后续只经过项目正常的护甲、附魔、抗性与承伤管线，不允许再次乘以 1.6 或 1.24。</div><div><br></div><div>---</div><div><br></div><div><strong>## 4. 炉心状态</strong></div><div><br></div><div><strong>### 4.1 载体与生命周期</strong></div><div><br></div><div>- 载体必须是自定义 MobEffect `mod:furnace_core`。</div><div>- amplifier 只允许 0 和 1；amplifier 0 显示“炉心”，amplifier 1 显示“炉心·过载”。</div><div>- 持续时间为无限。正常玩法中只有 `升温` 和 `燃烧` 可以给施法者自己施加。</div><div>- 不注册药水、喷溅、滞留、药箭或酿造配方；管理员命令只用于调试。</div><div>- 牛奶不能移除炉心。拦截后必须保持同一 amplifier 与同一运行态，不得重新开始计时。</div><div>- 退服保留状态与运行态；登录后从保存进度继续，不额外累计离线时间。</div><div>- 死亡清除状态与运行态，不触发冷却冲击，不修改升温、燃烧的技能冷却。</div><div>- 主动冷却结束状态并触发一次蒸汽冲击，每目标只结算一次。</div><div>- 任何其他来源移除状态都按“非主动结束”处理：清理运行态，不触发冲击，不修改技能冷却。</div><div>- `燃烧` 覆盖普通炉心时，必须在同一服务端提交中完成 amp0→amp1，并保留同一个 `FurnaceRuntime`。若平台不支持原地修改 amplifier，可以替换 MobEffect 实例，但必须保留累计值、避免重复播放施加音效&#x2F;粒子，且不得表现为“先移除炉心再重新进入”。</div><div><br></div><div><strong>### 4.2 炉心运行态</strong></div><div><br></div><div>```text</div><div>FurnaceRuntime {</div><div>    playerId</div><div>    amplifier                  &#x2F;&#x2F; 0 | 1</div><div>    accumulatedFireBonus       &#x2F;&#x2F; 0.0 .. 0.60，当前已累计火伤</div><div>    lastRampUpdateGameTime     &#x2F;&#x2F; 服务器游戏时间</div><div>    enteredAtGameTime          &#x2F;&#x2F; 用于调试与 HUD，可选</div><div>}</div><div>```</div><div><br></div><div>- `accumulatedFireBonus` 是权威值，必须保存；不能只根据进入时间临时重算，因为运行中可能从 amp0 覆盖到 amp1、改变成长速率。</div><div>- 必须按玩家保存到持久数据；不能只放内存。</div><div>- 登录时恢复同一 amplifier 与累计值；离线期间不增加火伤。</div><div>- 登录时若存在 MobEffect 但运行态丢失，以当前 amplifier 建立新运行态并从 0 开始，同时写警告日志。</div><div>- 登录时若存在运行态但 MobEffect 丢失，清理运行态，不触发冷却，不补发状态。</div><div><br></div><div><strong>### 4.3
