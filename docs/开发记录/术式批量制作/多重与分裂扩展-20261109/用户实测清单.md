# 用户实测清单

以下是未执行的操作与预期。使用包含最终更新的Forge 1.20.1客户端/服务端，已运行旧实例由用户按原使用方式重开。代理未启动游戏、未打包。测试法杖原有32格；剑术四个独立释放入口，各自8格。所有具体术式还需遵守原有手持物品、魔力、学会与宿主资格。

## 三重释放
- 编号 / 名称：rule_triple_release / 三重释放
- 前置：进入世界，准备32格测试法杖或一条剑术入口、足够魔力，通用图标xueximod:textures/gui/technique/other_none.png。
- 步骤：打开装配界面，将三重释放放在三个可辨认宿主前释放；再把其中一格改为修饰，随后用短于三格的尾链施放。
- 预期：向后最多读3个原始格，修饰也占格；实际成员沿既有3tick时序，短链到尾即止，剑术另三个入口不参与。

## 四重释放
- 编号 / 名称：rule_quadruple_release / 四重释放
- 前置：进入世界，准备测试法杖或一条8格剑链、足够魔力，通用规则图标同上。
- 步骤：装配四重及四个后续原始格释放；再在其中加入内层双重或分裂声明，保持合法链长后施放。
- 预期：外层最多读4个原始格，内层与复制沿共享解析；成员无重复或漏放，副本只计算一次，不跨剑术入口。
用户反馈：

## 八重释放
- 编号 / 名称：rule_octuple_release / 八重释放
- 前置：进入世界，准备32格测试法杖、至少9格可用装配位置与足够魔力，通用规则图标同上。
- 步骤：用法杖装配八重后接8个可辨认原始格释放，再加第9个后续格查看边界；分别检查合法协同/批量混用。另尝试把八重放入剑术槽，并检查已有旧剑链的施放。
- 预期：法杖最多读取后续8个原始格，额外后缀按原步骤继续；剑术装配拒绝，旧数据也在所选链出手、扣费前拒绝；不影响其他合法剑入口。
用户反馈：

## 十六重释放
- 编号 / 名称：rule_sixteen_release / 十六重释放
- 前置：进入世界，准备32格测试法杖、至少17格可用装配位置与足够魔力，通用规则图标同上。
- 步骤：装配十六重后接16个原始格并释放，再以较短尾链重试；尝试剑术装配与已有剑链施放。
- 预期：法杖最多读取后续16格，短链只读到尾、不补足、不回绕；剑术禁止使用固定16重，拒绝前不消耗本次释放费用或推进步骤。
用户反馈：

## 穷尽释放
- 编号 / 名称：rule_exhaustive_release / 穷尽释放
- 前置：进入世界，分别准备测试法杖和剑术四个入口中一条链，足够魔力，通用规则图标同上。
- 步骤：把穷尽放在含宿主、修饰与内层规则的链中施放，改变剩余链长重复；剑术另一个入口装可辨认的不同内容，交替施放两个入口。
- 预期：法杖与剑术都允许穷尽，从自身下一原始格读到当前这条链尾；不跨四个剑入口，不回绕，不持续释放至魔力耗尽。
用户反馈：

## 一分为二
- 编号 / 名称：rule_double_cast / 一分为二
- 前置：进入世界，准备可接受复制的宿主、合法载具与足够魔力，通用规则图标同上。
- 步骤：装配一分为二→宿主释放，再放进合法多重链中释放，观察份数与魔力变化。
- 预期：后续首个接受复制的宿主展开2份，资格、作用域、几何和结算沿既有底座，报价与出手一致，不固定成3份。
