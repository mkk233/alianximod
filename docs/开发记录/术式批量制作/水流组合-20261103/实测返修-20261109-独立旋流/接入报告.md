## 本次实现

`DomainFlowRenderer` 在 `lifted == false` 时不再画五条贴地平带，改为确认版三层六带。锚点仍是领域盒的水平中心和盒底，跟现有宿主位置走，不锁在玩家脚下，也不另加朝向。

默认吸引 8 格时，水平尺寸与 `standalone_vortex_v4.bbmodel` 的建造式一致。吸引不是 8 时，中线半径和半宽同乘 `attraction / 8`。外缘在 t=0 为 7.42 + 0.406 = 7.826 格，再随吸引缩放，仍小于吸引范围。高度保持确认的绝对格数，不跟柱高或本体半径放大，避免把低矮水带拉成向上卷人的龙卷。

当前独立路径没有按寿命改透明度。本次保持 alpha 150、`RenderType.entityTranslucent`、原顶点色和满亮度。角速度仍是 `(gameTime + animSeed) * 0.08`，UV 滚动仍是该转角的 0.15 倍。预览里四秒转一圈只用于看形状，没有写成新的游戏速度。

段中心落在固体方块上就跳过该段，避免水纹穿墙。干地空气不要求有水，所以单独释放仍然可见。水下路径原来的「必须在水里」判断没动。

## 参数映射

坐标以柱底中心为原点，Y 向上，1 模型单位在建造时等于 1/16 格；运行直接用格。

| 确认式 | 运行 |
| --- | --- |
| 三层，每层两条，层间 60°，同层 180° | `layer * π/3 + band * π`，layer 0..2，band 0..1 |
| 每带 48 段，t=0..1 | `segmentCount = 48` |
| 角度 `层*π/3 + 条*π + 6.15*t + 相位` | 相位用现有 `spin`，约 0.979 圈 |
| 中线半径 `7.42 → 1.35 + 层*0.18` | 再乘 `attraction / 8`，缺省或非正吸引仍按 8 |
| 半宽 `0.58*(0.7+0.3*sin(π*t))` | 同样乘吸引比例；偏移沿半径，不是沿切线 |
| 中线高 `0.44 + 层*0.75 + 0.12*sin(2π*t+层*0.6)` | 不缩放。三层中心默认 0.44 / 1.19 / 1.94 |
| 两侧高度 -0.19 / +0.19 | 内缘减 0.19，外缘加 0.19 |
| 峰值约 2.25 格 | 第 2 层正弦为 1 时中线 2.06，外缘 2.25 |
| 每 8 段用完一遍 64×32，带宽 V 为 0..32 | 归一化 U 每段 1/8；外缘 V=1，内缘 V=0 |
| 每段两面可见 | 沿用 `bandQuad` 的正反面 |
| 流动 UV | `scroll = spin * 0.15`；一段 UV 跨过 1 时折回，与原水带相同 |
| 透明与深度 | 原 `entityTranslucent` 与 alpha 150 |

原生模型、参考地板和 1.8 格人形没有进运行资源。
