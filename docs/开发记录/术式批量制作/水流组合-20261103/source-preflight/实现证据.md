# 实现证据

本文件是源码实现回执的检查记录，不是游戏验收。

第一次失败的三处已改：`chunkPos` 改为 `loadedChunk`，`MIN_EDGE` 改为 `LEAST_EDGE`。未改动其他文件里的旧名字。

## 两条开域入口

- `SkillUsePacket` 领域分支调用 `SkillSegmentRunner.domainSpace`，再交给 `DomainWave.open`。
- `CastExecutionSession.commitMember` 同样调用 `domainSpace`，接触点来自本组成立时的点，动作命中才算明确接触。
- `SkillChainPlan` 的双重释放领域分支使用同一方法，否则该调用无法编译，也会漏掉空间结果。

## 名册

`ReleaseMotionLedger` 的键是释放组编号加声明下标。分体在放入活动表之前绑定这个身份，扩份循环共用同一次上下文。

## 原子水势

`WaterMomentum.settle` 先看可用额是否严格够付，再按「原余额 - 毛费用 + 返还」写一次，并只发一次通知。

## 上升优先

`WetnessFlight.clampDescent`、`adjustVexMove`、`adjustDragonMove`、`correctDragonDescent` 在施加潮湿下降前查询 `VolumeMotionRuntime.hasEffectiveUpdraft`。

## 水租约

`StillWaterLease` 随深海领域打开填空气格，关闭时释放。区块加载时核对；流体自身在无活租约时变成空气。静水注册在 `StillDomainFluids`，没有方块物品。

## 配置消费者

旋流、气泡的新键在 `DomainDefinition.declareFlowBalances` 声明。几何在打开时读取，吸引、环绕、上升、抛出和入卷费用在对应判定时读取。深海临时水不另设半径。
