# 最终接入证据

本文件只列 `实现裁决-3-运动撤销.md` 第 7 节在源码中的入口，供对照。它不是复审结论。

| 要求 | 入口 |
| --- | --- |
| 持续意图不写持久速度 | `VolumeMotionRuntime` 的 `orbit`、`pull`、`liftBubble` → `FlowMotionIntents.offer` |
| 抛出一次冲量 | `VolumeMotionRuntime.ejectGroup` |
| 关闭不回滚整段速度 | `VolumeMotionRuntime.onClose`、`FlowMotionIntents.retireInstance` |
| 多来源和旧回执 | `FlowMotionIntents` 的按根列表与 `epochOf`；`FlowPlayerBridge.receiptHolds` |
| 普通生物与静止物品 | `FlowStepMixin`、`FlowMotionIntents.finishStep` |
| 玩家模拟不注入 | `FlowPlayerMoveMixin.xuexiFlowSimulate` |
| 玩家与驾驶载具回执 | `FlowClientMotion.combine`、`FlowLocalMoveMixin`、`FlowPlayerBridge.acceptPlayer`、`acceptVehicle` |
| 在轨矿车 | `FlowMinecartMixin` |
| 上升免重力与悬浮踢出 | `FlowGravityMixin`、`FlowPlayerMoveMixin.xuexiFlowClearFloat` |
| 末影龙不二次平移 | `WetnessFlight.correctDragonDescent` |
| 晚包、重复步、纠正和日志 | `FlowPlayerBridge.correct`、`FlowCorrectionS2CPacket`、`FlowClientMotion.acceptCorrection` |
| 死亡、离维、换维 | `FlowMotionEvents` |
| 合成进原生 move | `DomainMotion.clip` 在近零返回之前调用 `FlowMotionIntents.compose` |
| 气泡挂载显示 | `DomainSyncPacket.mountedHost` 写入 `DomainInstance.mountedHost()`。`DomainMotionPreview.mountedHost` 供 `DomainFlowRenderer` 使用。独立气泡只在宿主编号为空时画自己的水柱；有宿主时由该旋流画一次气泡膜。宿主失效后链接随关闭包去掉，膜停止。不再用盒子包含关系猜测 |
