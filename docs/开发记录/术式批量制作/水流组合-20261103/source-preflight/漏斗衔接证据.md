# 漏斗衔接证据

日期：2026-11-03。只记录本轮写入，不是编译结果，也不是游戏验收。

## 已写

- `FunnelOutline` 提供唯一轮廓函数。服务端组合轨道用它。客户端以后用同一函数，加上同步来的本体半径和领域盒子高度。
- `VolumeMotionRuntime` 在抬升组合里先找漏斗座位，再退回圆柱座位。干地分支仍按外沿角速度转。入卷仍先看体积上限和 `WaterMomentum.settle`，窄口不能单独关闭实例。
- `ReleaseMotionLedger` 记下根实体和座位角。退出、抛出、关闭和名册丢弃时一起清掉。
- `DomainSyncPacket` 追加 `bodyRadius` 和根编号列表。`DomainMotionPreview.controlledRoots` 只返回这份列表。
- `docs/配置平衡指南.md` 写明该比例不是配置键。没有新增平衡键。
