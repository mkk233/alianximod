# 实测三项代码修复

## 1. 水带

`DomainFlowRenderer` 不再用同一角的直立径向面。

- 干地 `drawPlanar` 91–100 行：5 条水平内旋。外径用吸引半径，内径为外径的 0.1694，转 0.979 圈，半宽 0.58，贴在柱底以上 0.2。这组比例来自预览 `dry_v2_arm_0`（外径约 7.79、内径约 1.32、约 0.979 圈）。每条 24 段，相位随 `spin` 转动，U 沿带滚动。
- 组合 `layFunnel`：6 条，相邻点连成带。半径仍走 `FunnelOutline.radiusAt`，整段转两圈（`4π`），竖直半宽 `RIBBON/2`（0.28125）。每条 32 段。
- 水下 `drawUnderwater` 110–124 行：三层各 2 条，高度 0.44 / 1.19 / 1.94，口半径 0.75 / 0.94 / 1.125，外径 3.25，再按本体半径相对 2.5 缩放。每段中点用原来的 `waterOpen` 判断，不在水里或被实心挡住就不画。
- 气泡仍是 4 片上升膜，只在该点为水时画。宽目标是绕身约 260 度的水平短弧，加一条通向漏斗口的窄带。
- 每段画正反两面，渲染类型仍是 `entityTranslucent`，所以上方、岸边和水下都能看到带面。吸引半径、容量和费用没改。

## 2. 深海冲毁

`StillWaterLease.placeIfAir` 95–111 行：空气照旧放入。草、蕨、火把这类不挡移动、没有方块实体、没有流体、也不是可含水方块的附着物，先 `Block.dropResources` 一次再放临时水。楼梯、半砖（`LiquidBlockContainer`）、门、告示牌、梯子、甘蔗、气泡柱、传送门、箱子和其他方块实体、挡移动的地形建筑、天然水和其他流体不替换。

未放置的租约在 `reconcile` 279 行用传入 `ChunkAccess` 做同样判断并排队。`placed == true` 但格子已不是本术式临时水时仍摘租约，不回冲。掉落和 `setBlock` 仍在 317 行的 `TickTask` 里，且先看 `level.isLoaded`。加载回调没有 `Level.getBlockState`、`getChunk` 或 `setBlock`。

## 3. 施法者

`VolumeMotionRuntime.steerGroup` 320–322 行：候选根和它的乘客里有施法者时，`releaseCasterGroup` 解除这组的控制和位移意图，不入卷、不扣费、不关闭旋流。人离开坐骑后，坐骑不再带有施法者，下一拍可以按原规则重新被吸引；已经结算过的实体不会因为这次解除再扣一次。`liftBubble` 557 行对独立气泡和同一判断，组合挂载后的上升走旋流的 `steerGroup`，不会把施法者重新送上去。其他玩家仍走原来的 `selectable`。

## 建议实测

干地俯视旋流，应看到五条弯曲水带贴在地面附近转动。深海压在草、蕨、火把上，它们应掉落一次并变成不外流的水；楼梯、半砖、箱子和原本的水留着。自己站在旋流里或骑着马释放时，自己和这匹马都不应被吸走；另一名玩家仍应被吸引。
