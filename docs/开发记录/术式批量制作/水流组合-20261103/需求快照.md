# 最新已批准需求：独立旋流及水龙卷组合

用户最后明确授权：“这个版本不错，按照现在的去实现”。本文件记录讨论所得，不把此前过时提案当需求。

最新补充（实施准备期间）：“旋流自身聚怪不具备水势消耗衰减的规则，只有组成水龙卷才具备这个根据潮湿等级削减消耗补充水势的能力”。这条覆盖此前把潮湿结算直接赋予独立旋流的讨论。独立旋流生物入卷固定成本，任何潮湿等级不折扣、不返还；仅实际水域+上升气泡作用形成水龙卷时，生物入卷启用潮湿分档收支。弹射物标准成本×0.2是独立偏转规则，本次补充未取消。

## 功能与组合

旋流是独立水属性旋转牵引场，可在干地单独释放，自带可见水流但不生成可游泳或支撑气泡柱的完整水域。核心单一作用是吸入、向中心收束、绕轴分布。作用点继承链条空间参数，不能固定玩家脚下或按术式ID特判落点/分裂。

深海重压保留当前真正已实现且最新批准的效果，同时产生临时实际可参与水域判定的区域；可以支持气泡柱。不能仅有水面贴图和专属ID判断。先核当前领域/真实呼吸/水体功能，旧水属性术式.md可能已经过时，不能恢复已移除旧压强爆发。不覆盖实心地形，不无限流淌，到期只撤术式自己生成的部分，保留天然水和玩家后续改动。

气泡柱在自然或术式水域提供上升运动，单独可用；组合时为旋流场附加上升，沿螺旋升到顶部向外抛出。旋流没有气泡则不自行上升或抛出。三个术式不是按ID识别套装后启动另一套龙卷逻辑。复用现有领域/释放/挂载生命周期；确实缺少必要通用能力时由唯一Astra先裁决最小改动，不能在术式内绕过底座。

旋流可与其它持续攻击区域聚怪配合，与水幕防守配合；泼潮/雾雨的潮湿只有形成水龙卷后才用于入卷折扣与回流，不能使独立旋流获得折扣。此批不实现泼潮/穿涧/水幕新方案，仅要求旋流本身不被锁死成一条链专用。

## 吸引、运动与结算

- 水平半径8格圆形吸引范围，有方块遮挡就不吸引。接近中心速度增加，有速度上限，不瞬移或穿墙。
- 完全进入旋流本体时，读当前潮湿等级结算水势。外围吸力不按tick扣入卷费。
- 独立旋流始终固定生物入卷成本。只有已形成水龙卷时：无潮湿正常消耗，一级二级减少消耗，三级四级入卷净增加水势。此前试调建议为基础10、一级8、二级5、三级先付10返13、四级先付10返16；这组未被单独钉死，应在实现方案给出配置默认，不能冒充用户逐项确认。
- 一次释放同一实体只结算一次，含分体共用记录，离开重入不刷返还。卷内不再消耗入卷水势，仍可正常叠潮湿，升档不补入卷收益。高湿支付/返还视为完整结算，不在中间余额暂归零时误判溃败。
- 实体按碰撞盒占用空间均匀分布在不同角度/高度，不全部重叠在轴心，参考万剑归宗的分布观感。没有气泡时平面环绕；有气泡时螺旋向上，顶部向外抛出，同次已抛出不再吸回。
- 结束前尚未抛出的实体原地下落。实际落地按正常摔落体系结算一次，不在抛出时再造一份伤害，不强行取消落水/免摔伤机制。
- 气泡的竖直运动优先于压强下压。亡灵不能游泳也能受上升气泡运动。离开气泡恢复其他正常规则，不删除别人的状态。

## 溃败与实体分类

用户明确：水势不足和空间溢出统一使龙卷立即结束，势能不足或负载过高拖垮龙卷；术式消散，全部卷内实体开始下落。不是停止接纳、不是外圈排队。停止该实例的吸引/环绕和所属上升效果，其他独立领域不被清除。深海水域仍有自己的寿命。

所有实体范围不改成只敌对。具体旁观/无实体物理/施法者和盟友的现有关系约束须报告并裁决，不默默缩小需求。

- 生物/玩家：独立旋流固定入卷费；形成水龙卷后才按潮湿收支，均受负载约束。
- 掉落物：可卷入，不扣也不返水势，仍占空间负载。
- 弹射物：真正偏转才扣水势，不扣满常规拦截成本。用户最终明确消耗削减80%，即标准处理该弹射物成本×0.2（不是×0.8、不是此前×0.4）。同次同弹射物一次结算，继续飞行、不强制吞掉，不占长期排列槽。低成本不因整型向下取整变免费。标准拦截成本和实际水势精度先查现有底座，不能凭空发明按伤害/速度的新公式。
