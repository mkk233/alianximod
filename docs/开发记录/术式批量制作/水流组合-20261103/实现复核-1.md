## 硬缺陷

1. **干地不散开，座位失败也不溃败。** `orbit` 只有已经抬升的组合才在八个黄金角里选座。干地旋流把所有人按当前方位转到同一外沿，角速度相同的会一直叠在一起。优先座和圆柱座都失败时，仍然留在外沿，不关闭。`acquire` 只在「八个外沿座全满，并且当前位置还撞方块」时才失败，没有内圈。掉落物不挡碰撞，会一直叠到体积上限才关。触发：两只以上生物进干地旋流，或组合里合法座位已经没有。后果：叠在轴心附近一起转；设计 1 要求的不同角度和必要同心半径没有发生。最小修法：干地也走同一套选座；圆柱和预算都放不下时按原超载关闭。

2. **墙后仍会入卷或拖垮旋流。** `touching && !fits` 在通视判断之前就关闭。身体已经完整进入圆柱时，即使中心到轴心的 `COLLIDER` 射线被挡住，仍会扣费并占位，只是这一拍不转向。触发：栏杆、玻璃或后来放进柱内的方块挡住轴心；或大型碰撞盒隔墙擦到圆柱且装不下。后果：被挡住的目标照样入卷；装不下的隔墙接触会直接让这团旋流溃败。设计要求被挡住的这一拍没有吸引、环绕和入卷。最小修法：`clearLine` 失败时本拍直接跳过，不扣费、不占位、不因擦边关闭。

3. **船、矿车和骑乘组到不了抛出，还会被重新吸回。** 是否还在柱内看的是整组并集的头顶，抛出看的是载具自身顶面。乘客头顶先伸出柱顶后，组不再算「在内部」，抛出分支不会跑，也就不会记入已抛出。随后水平吸引会保住向上的速度，飞出柱外再落下，又被吸回来。触发：玩家坐船或坐矿车进入已经组合的水龙卷。后果：组在顶部循环升降，没有向外抛出，同一次释放会反复吸回。单独的玩家不受这个影响，默认上升 0.12 仍能落进顶部 0.2 格的窗口。最小修法：用并集顶面判断到顶和顶棚，整组一起记抛出。

4. **结束时留下环绕速度，不是原地下落。** 每拍都把水平速度写成环绕或吸引速度，关闭时没有清掉。寿命结束、空间溃败或水势耗尽后，卷内目标仍带着最多 `motionSpeed`（默认 0.45 格/刻）的水平速度飞出去。代码没有另写摔伤，但落点会偏，可能因此落进水里或错过落地。触发：还有目标在环绕时领域关闭。最小修法：停止控制时去掉本实例写下的牵引速度，再交给原版重力和摔落。

5. **气泡半径没有被玩法读取，干地方盒也会把气泡挂死。** `radius` 已声明，提升和上升判定用的却是方盒，不看圆柱。方盒四角、圆柱以外的目标也会被抬起；只改 `radius` 没有效果。挂载只要求底部方盒相交、主人相同。干地旋流的方盒角碰到水里的气泡就会挂上，气泡自己的上升因此停止；旋流圆柱里没有水，组合又不成立。父旋流关闭时还会把这根气泡一起关掉，不能恢复成独立水柱。触发：岸边旋流的方盒擦到水中气泡。后果：两边都没有上升，气泡跟着旋流一起结束。最小修法：上升和挂载都用气泡圆柱，并且只有支撑水体真正重合才挂载。

6. **水势已经是 0、柱内还没有人时，旋流不关。** 只有「当前握着目标且余额不大于 0」才在领域处理里关闭。空的旋流会继续白吸，直到有人付不起入卷费。设计要求余额被别的途径真正耗尽后，下一次服务端领域处理就关闭。预留占满可用额不会误关，这一点是对的。最小修法：余额已经不大于 0 时，下一拍关闭该旋流，不要等柱内有人。

7. **受控根编号同步在 64 个处截断。** 最小占位约 0.043 立方格，体积上限 12 时远不止 64 个根。服务器仍控制超出的目标，客户端名单没有它们。后续局部携带水带会漏画，也会把这些目标当成不受控。最小修法：名单与服务器控制集一致，或在超过上限时有明确的不分歧规则。

## 核对后认为符合设计的部分

两条开域都走 `domainSpace`。锁定实体在没有接触点时不挪原点；垂落不会把柱体放倒。名册键是释放组加声明下标，同一声明的分体共用，另一次声明不会并进去。父旋流关闭时会退役并关闭气泡，不会改挂到下一个旋流。

独立旋流固定收 `entryCost`。只有组合成立才读湿度：一档 8、二档 5、三四档先收 `entryCost` 再返 13 或 16。`settle` 按「原余额 − 毛费用 + 返还」写一次。余额 10、毛费用 10、返还 13 会直接变成 13，不经过中间 0。余额 0 再收正费用不会被 0.001 容差收成免费。一组载具一次结算，付不起不记账。

普通箭和光灵箭用冻结直伤乘射箭者湿度箭比，再乘固定 0.2，只抽一次并写入箭的数据。三叉戟和其他弹体用 `fallbackProjectileStandardCost`（默认 5）再乘 0.2。先付款再改速度，持续推进弹会改方向分量，不删弹。同一名册里的同一发只付一次。

`WetnessFlight` 的普通下落、恼鬼位移、末影龙位移和龙的下压修正都会先看有效上升。没有上升时原逻辑还在。深海静水进了水流体、水方块和 Forge 水类型标签，不向外流，没有方块物品；桶和玻璃瓶的玩家交互会被拒绝。多租约、玩家改过的格子不回填、区块加载和流体刻回收无主静水，这些路径在代码里是接上的。抬升后的漏斗优先轨道使用 `FunnelOutline`，只改速度，不改位置；宽身体会退回圆柱座。除气泡 `radius` 外，已声明的水流键都有读取点。客户端拿到的是包里的模式、盒子、速度、旋流半径和根编号，没有自己另算一套玩法默认值。

深海的慢、潮湿、耗氧和 40 点开域魔力没有被旋流的空原生策略接走。父挂载不会在关闭后复活。
