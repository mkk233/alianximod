- 编号 / 名称：water_vortex / 旋流
- 前置：使用现有施法物品装配旋流；用现有水系攻击积攒水势，准备不同潮湿等级目标、普通掉落物和实体方块墙。分别让施法者站在场内、场外，以及骑乘载具进入，验证自身排除。
- 步骤：先在干地单独施放，分别让不同潮湿等级目标进出本体；在墙后与墙外放目标；随后验证落点指定、一分为三及重复进出；增加目标直到实际超载。
- 预期：外围水平8格圆形吸引，近中心加速，墙后不吸；施法者本人及载着施法者的骑乘组不被牵引、入卷或扣费，其他玩家友军规则保持；干地只水平环绕，任何潮湿等级首次入卷都按固定基础费，同次重入/分体不重复收费；掉落物免费但占空间，过载或水势不足使所属实例整体结束；位置继承链条，实体不瞬移、穿墙或重叠在轴心。

- 编号 / 名称：water_bubble_column / 气泡柱
- 前置：装配气泡柱，准备天然水域、干地、普通生物及亡灵目标；另备旋流。
- 步骤：分别在水中和干地单独使用；在同一水域以“先旋流后气泡”和“先气泡后旋流”两种顺序组合；对高湿目标观察升到水面以上的过程；等父旋流结束。
- 预期：独立气泡仅在实际连通水体内有效，亡灵同样上升；两种先后顺序都能附加到兼容宿主；组合后高湿下压让位于上升，离水后仍能沿宿主升至顶部；父结束后挂载气泡消失，不转成独立气泡继续托举。

- 编号 / 名称：water_deep_pressure / 深海重压
- 前置：装配深海重压，准备有地形起伏的空气区域、草、蕨、高草、火把、天然水，以及楼梯、半砖、箱子和玩家可修改的方块；观察魔力、潮湿、速度与氧气。
- 步骤：在空气、天然水边以及与另一个深海领域交叠的地方释放；进入水域；在持续期中修改部分生成格子；分别等待一个/最后一个领域结束，并保存退出后重新进入同一世界观察遗留水。
- 预期：保留当前慢、湿和加快耗氧效果，无旧到期爆发或维护费；领域内空气格和水可冲毁附着物的位置生成不蔓延的真实水，能支撑游泳与气泡；草、蕨、火把等正常冲毁掉落一次，水收回后不恢复、不重复掉落；地形建筑、楼梯半砖容器、天然水和玩家后来改动保持；交叠水最后一份租约结束才回收，重载后的孤儿临时水安全清理，不可用桶复制。

- 编号 / 名称：water_deep_pressure + water_vortex + water_bubble_column / 水龙卷组合
- 前置：三项在同一位置生效，分别准备0至4档潮湿目标，观察水势；预留余额刚好10的情况。另准备普通箭、三叉戟和无直伤投掷物；在安全测试区域准备空旷出口与顶棚。
- 步骤：比较独立旋流与组合后的首次入卷收支；让已结算目标在场内升湿、离开重入或在组合形成前已入卷；观察上升、顶部外抛、持续期结束和资源不足；发射不同弹体穿过本体；在有顶棚处重复；分别落在地面和水中。
- 预期：默认组合0/1/2档扣10/8/5，3/4档毛付10后返13/16，上限100；余额10的三级结算后为13，不因中间0误溃败；旧目标不补算返还。弹射物实际偏转才按标准成本20%扣费并继续飞行，同次只付一次。主水流饱满、下窄上宽，水下有汇入回旋和气泡，宽目标周围有局部携带水带。普通目标错相上升并从可通行顶部抛出，顶棚不穿透；结束只释放运动，实际落地按原版结算一次，落水/免摔仍有效。独立深海水域不随旋流消失。
