## 一次集中确认的范围

建议批准下列完整首版，包括公共分支表达、费用、数值、地形保护和成长方案。另需明确同意两项底座变更：支持10格组合所需的12格链容量，以及把新资源效果接到同一次真实施法的共享账本。视觉另按草稿预览确认，批准玩法不等于批准素材。

已知现有链最多8段，火山组合“地表定位、喷涌、一分为三、错时、崩地、引爆、陨岩、命中接续、引燃、热波”需要10格。建议公共链验证上限改12，剑槽仍维持现有8格，法杖可承载至12格且提供可取得的12槽法杖配置，旧法杖保留原槽数；不免费扩容旧物品。具体12槽载体取得方式建议沿用现有法杖取得方式，不新增材料配方；若现行体系无法给出该规格，需再报告事实缺口，不能只改服务端上限假装可装配。用户若不接受容量变化，本批保留各基础术式，完整10格组合保持待澄清，不能偷偷省略费用或规则格。

## 公共费用与进度

建议采用现有费用的量级：攻击基础魔力为基础伤害向上取整×2，附魔基础魔力2，纯修饰规则0。它们在本批原表中仍是空格，因此此处只是建议；不是声称代码默认已经得到授权。

建议每项使用下列“魔力 / 冷却tick / 复杂度 / 装配消耗”值：

- 留焰：2 / 5 / 2 / 2。
- 陨岩：48 / 40（已定）/ 6 / 1。
- 热波：8 / 16（已定）/ 2 / 1。
- 地表定位：0 / 0 / 1 / 1。
- 喷涌：0 / 0 / 2 / 1。
- 错时：0 / 0 / 2 / 1。
- 命中接续：0 / 0 / 3 / 1。
- 种火：2 / 5（已定）/ 1 / 2。
- 引燃：2 / 5 / 2 / 2。
- 引爆：2 / 5 / 2 / 2。
- 幽冥：2 / 5 / 3 / 2。
- 崩地：2 / 5 / 3 / 2。
- 火苗：2 / 5（已定）/ 0 / 1。

攻击装配消耗1、附魔2参考《底座功能点》的实际装配说明；新规则设1是本次建议，不把表头混写的费用说明当实际容量算法。复杂度按火苗入门、热波中低档、陨岩高档排列，是新平衡建议，缺少足够同类样本，不能声称由旧表自动推算。通用类当前始终解锁，复杂度只作登记，不能谎称这些值会锁住通用规则。法术仍按现有法术等级解锁。

等级上限建议统一20；本批不新增伤害、冷却、尺寸或费用随单术等级成长，成长值显式为0。沿用现有使用次数记录与系统等级升级，单术等级展示不新增战斗倍率。这样不把尚未接入的熟练度成长包装成已实现功能。

复制按实际份数支付宿主费用，附魔按原装配格收一次，不按火径片段或目标数重复收。命中接续在出手前预约最坏情况下全部子段费用；实际产生一份子攻击提交一份费用，未触发的子段退款。三颗陨岩各接一份带引燃热波时，建议总报价为3×48 + 引爆2 + 崩地2 + 3×8 + 引燃2 = 174，纯规则不另收费。此例不包含额外附魔、能量增幅或额外复制。

错时采用每份间隔10 tick，第i份在组开始后10×i tick出生。与现有多重的成员间隔3 tick分开计算。整组预付/预约，后续出生不重新向准星取点。死亡、下线、换维、主手载体更换或相关装配改变取消未出生份并退回未提交费用；正常松键只停止下一组，不取消已承诺本组。已生成攻击不因松键消失，已生成无伤陨岩残骸继续保存。新组每次重新计费、生成新的真实施法标识；错时不是自动无限连射。

## 每项具体建议

### 留焰

每段残留40 tick，基础火径直径0.5格；受载体通用几何倍率同步缩放。每tick沿实际位移作连续线段扫掠，表现采样间距不超过0.25格，每个实际载体最多256个活跃表现采样点，超限合并相邻同龄段而不扩宽判定。高速位移仍使用扫掠线段，不因采样限额留下可穿越漏洞。

第一版只承接已有通用移动命中体：火苗、火球、陨岩及明确声明可留径的同类载体；不擅自把剑实体、光束、领域或固定斩击判为兼容。火径调用载体的直接伤害与附魔载荷，不再触发载体爆炸、撞击范围、命中接续或落地残留。陨岩火径仅作24点直接接触伤害，不在每片火径复制1.5格中心冲击。

一次命中型载体，每实际复制份对同一目标“本体或火径”合计一次；有明确持续命中间隔的载体共享原间隔，不能另起火径计时。复制份仍按原规则参与伤害份数，但产种/引燃/引爆使用整次施法去重。载体消失后已留路径保持到自身寿命结束。火径不额外产种、不独立存档。

### 陨岩

保持24点物理、冷却40、中心水平半径1.5、一个方块体量。建议默认抛射速度0.8格/tick，初始方向取出手方向后向上偏15度，重力0.08格/tick²，不另叠引擎重力；最大有伤飞行100 tick，超时转无伤残骸，不伪造撞击或接续。碰撞箱1×1×1格，中心冲击总高3格。允许弹道重写，不默认追踪实体；锁定只给初始方向，方向随重力改变。

残骸方块建议硬度3、爆炸抗性6、石镐及以上正常采掘掉落自身1个，工具不达标无掉落；不提供矿物、燃料或自动炼制用途，先作可放置建筑石。每实际岩体只创建一个方块或一个待安放残骸，不能两者同时存在。

接地后优先落点上方合法空格，再按水平距离升序搜索半径2格、上下各2格的候选；必须有支撑、完整空位、无活物碰撞且通过放置权限，禁止覆盖任何已有非空气方块。无位置则保存无伤残骸，每20 tick重试，仅在已加载区块处理，不强载区块、不因期限删除。待安放残骸及其崩地已执行标记需要存档；重启不能重复挖坑或复制方块。

### 热波

保持物理4、冷却16、内半径1.5、外半径5。建议独立和接续均使用总高3格，以事件点或施法脚部锚点为中心；无击退，视觉扩散12 tick，判定只一次。不可改成移动弹道，只接受锚点位置修饰。

目标体积与环带相交才候选；与中心区域相交者优先归中心。陨岩事件先保存中心候选/成立命中名单与遮挡状态，热波排除这些目标，中心即使因免疫不扣血也不借环带再试一次。生物两区的目标与遮挡在挖坑前确定，不能挖完再把墙后生物打进来。

### 地表定位

沿视线最多32格，取第一个可见碰撞面的上表面，只接受法线向上的承托面；撞墙、找不到上表面或攻击本体放不下均拒绝，不从墙后继续寻找。锚点为表面上方“本体半高+0.125格”，用最终缩放后的实际碰撞体检查净空。所有待生成复制的初始几何均须预检。无效时不扣本组魔力、不进冷却。领域类宿主可显式声明接受地表锚点，不能因此让所有领域接受一切旧安置修饰。

### 喷涌

建议初速1.0格/tick、重力0.08格/tick²；单份竖直向上，多份按半角25度的锥面均匀分布方位角，同一组冻结方向。三份为等方位角三向，更多份仍均匀分配；一分为三决定份数，喷涌不增加数量。同高度落回约23–25 tick，最高约5–6.25格，最大水平偏移约9.6格（离散积分可略有差异）。

宿主保留自己的寿命；建议喷涌运动上限100 tick、离喷口水平距离上限32格，到限按宿主正常无碰撞到期处理。陨岩转无伤残骸，普通飞弹消失，不伪造接续。喷涌/垂落/风暴同时在同分支出现时整分支拒绝并提示只能选一种完整路径，不靠书写顺序暗中覆盖。

### 错时与命中接续

错时按前述10 tick、预付及取消方案。命中接续建议使用“父段攻击 → 命中接续 → 子段修饰及附魔 → 子攻击”的明确装配语法。标记只绑定紧邻的已完成父攻击与后面第一个合格攻击段；这段子攻击从普通顺序执行中移出。首版不允许嵌套接续，重复标记、无父/子攻击、子段包含领域自动绑定或再次接续均在扣费前拒绝。

父段的索敌、路径、复制、附魔不隐式传给子段；子段只继承事件点、事件方向、主人、维度及真实施法标识。子段显式声明的复制照常计费，不能再继承父段三份。首版每次真实施法最多64个展开的实际攻击实例，超出整组拒绝，不静默截断，也不改现有无本批新规则的链。

### 种火

基础10、冷却5和倍率公式已经明确，不再询问是否要这10点。普通炉心11–16及过载22应由实际倍率计算，不登记为固定档位点数。与火苗同一命中的2+10先合成基础12，再按floor(12×产种倍率)入账一次，最后钳到100；例如倍率1.12时为13。这个取整顺序建议按N“基础相加，再按规则”采用；采集报告曾举“各自取整再合并”，那只是候选实现描述，不是用户批准的差异规则。

同一真实施法、同目标本次产种机会只用一次；同一命中的所有贡献必须先收齐。不同分支晚到的同效果、错时副本、火径均不再补一笔。旧点火/热光束/火球已有固定基数和既有倍率行为不顺手改动；共存时明确区分既有固定贡献与新乘炉心的贡献，合成一次提交，不能调用两个会新建上下文的入口。

### 引燃

建议采用原草案：启动n=floor(余额/10)，n<1不挂；每完整段请求10，伤害2×(1+F)，间隔10 tick，期限40+10n tick。F取启动时施术者炉心现行有效增伤系数，无炉心0，期间不刷新。首跳在成功挂载后第10 tick；恰好到期那一跳允许结算，随后结束。最多8条计划，满额在扣燃料前拒绝，不驱逐已有层。

同tick所有到期层一起按请求比例分账；不足的整数余数按轮换次序分配，避免同一层长期抢先。实付0则无伤；总余额到0即结束相关存活层，后来补种不复活。引爆与到期燃烧按服务端实际事件顺序争用同一余额；燃烧调度一轮内必须先集中分配，不能逐层先到先得。无新增伤害免疫绕过。

### 引爆

建议采用0.2×S×(1+F)，F在本次消费时读取，S是当时共享余额。每目标每真实施法最多一次；无余额仅保留载体原伤害。资源伤害只给该合法命中目标，无额外范围、击退、方块破坏，不继承燎里/焚天公式。

同一成功命中若同时有产种、引燃、引爆，建议固定顺序：载体命中成立 → 合并产种 → 引燃挂层 → 引爆即时消费。引爆清空会使刚挂层失去燃料并结束，界面应解释这个组合结果；不同时间事件仍按实际先后，不增加跨效果总锁。

### 幽冥

建议每20 tick基础产种5，进入领域不立即额外送首笔，第一笔在完整周期结束；本周期只给当时领域内合法敌对活物。乘该领域主人当前炉心产种倍率后向下取整。范围与时长只继承载体，不强求接触伤害大于0。

重叠区每目标每20 tick全局窗口只取最高有效产种请求一次；同值用稳定领域标识择一，不叠加，不因跨不同启动相位翻倍。蓝火只改处于有效幽冥领域内的火系表现，离开后恢复原表现；不改元素、伤害、免疫或实际方块。已有燃烧可使用新火种，但不延长其时长。

### 崩地

建议水平半径2、最大深度2格的浅碗形，方块中心满足水平距离r≤2，向下深度d满足0≤d≤2×(1-r²/4)。基础尺度固定；通用攻击体积增幅首版不扩大坑、挖掘数量或陨石方块数量。一次最多破坏32个合格方块，按离撞击点距离排序。

现有统一开关首版默认开启是已定需求。建议跳过基岩等不可破坏块、方块实体/容器、流体、传送门、管理员保护块与保护区域；逐块走玩家归属的服务器破坏权限/事件，取消即保留。合格方块按普通无工具破坏掉落规则，不模拟世界爆炸，不额外伤人。仅处理已加载区块。

两区生物结算与遮挡采样先完成，再挖坑，再安放陨石。空中撞击只先完成生物结算与子段，残骸实际接地才执行一次崩地。关闭开关仍可合法安放陨石，无位置则保留残骸。

### 火苗

保持基础火伤1、冷却5、基础产种2和已填索敌/弹道开关。建议速度0.8格/tick，寿命30 tick，默认直线射程24格，碰撞体0.25×0.25×0.25格，原版着火20 tick。撞实体单次结算后消失，撞方块消失，无爆炸；改写弹道后射程以实际路径与寿命为限，不保证直线24格。

火苗原版燃烧后续不产种、不耗种，不自动变成引燃。小尾焰只作表现，只有明确装留焰时才有残留判定。

## 可先交付的视觉草稿

无需等待这些玩法数值即可用独立Aseprite批次做：小火苗与短尾焰、留焰的连贯衰减片段、岩壳熔裂贴图、空心热波环、地表锚点、种火火星、引燃单次亮灭、引爆小/中/大三档火团、幽冥蓝火。草稿只确认形状、配色与辨识，不确认世界尺寸、寿命或伤害节拍。

喷涌、错时、接续主要是运动与调度，没有必要发明额外攻击贴图；可用同一载体草稿示意。崩地坑形等数值批准后再做场景预览，目前可做普通土尘碎屑草稿。陨岩先做方块贴图，不必先引入复杂三维模型；确有需要再Blockbench。所有草稿须人类预览确认后才归档为确认版并接入，不自动复用火种常驻火苗。
