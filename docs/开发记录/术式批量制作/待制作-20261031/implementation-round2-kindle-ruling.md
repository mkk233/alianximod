## 现行含义与算例

- n是本条计划启动时由目标共享余额计算的档位。余额上限100、每档10，所以合法余额自然得到n≤10；余额90时n=9、期限130，余额100时n=10、期限140。封10在这个合法余额范围内不改变批准公式。
- 8是同时存在的独立计划上限。一个n=10的引燃只占一条计划，不占十条；已有八条时第九条不能挂，不把既有每条的n收成8。
- 140tick是这条计划的最长存活期限，不是承诺14次足额伤害。单层、无其它消费、启动100、没有补种时，首跳+10tick、每跳消耗10，最多在+100tick完成第十次足额段并因余额归零终止；无炉心时合计20点资源伤害，不会凭空继续到14段28点。
- 若在余额归零之前有合法补种，存活计划可继续消耗，但仍不能越过启动时固定的140tick期限；到期时点的最后一跳按已批准规则可结算。这不是重新设计，而是原N允许存活层使用补种且不刷新期限的直接结果。

首轮从“最多8层”推导“8层期限应为120tick”，混淆了计划数量与单计划档位。余额80对应期限120确实成立，但不能据此将余额90/100也截为120。
