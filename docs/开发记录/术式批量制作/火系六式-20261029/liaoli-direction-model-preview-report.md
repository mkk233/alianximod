视觉沟通草稿，不是正式设计或实现复审。没有改游戏源码、运行时资源、制作表或记录。没有编译，也没有打开 Blockbench。

同目录有 `README.md` 和生成脚本 `build_preview.py`。纹理嵌在 bbmodel 里，灰蓝身体、深色背面、深红剑柄、金橙剑身、浅金剑尖都是实色立方体，不是贴图画出来的剑。

## 坐标

Blockbench 自由模型，+Y 朝上。玩家面向 -Z（北面是脸），背后是 +Z（南面是背）。眼睛和胸口标记凸在 -Z，背脊凸在 +Z。面向 -Z 时，玩家右侧是 -X，左侧是 +X。

八柄剑在背后同一扇形里，角度与 `LiaoliV6Layout` 的八个扇角一致：-180° 到 0°，左右成对，斜角相同。代码里柄的深度比尖更靠后；这次按用户方向反过来，不改生产代码。

## 柄和尖

扇心在背后，高度 y=18。柄落在半径 7、z=5.5 的弧上，紧挨背脊外侧。尖落在半径 18、z=17.5 的弧上。每把剑都是柄到尖的一串立方体，剑尖的 Z 比剑柄大 12。水平那对在 y=18，从 x=∓7 伸到 x=∓18；靠上的一对尖端约到 y=35.6，仍在头的后方。

分组：`Player`、`BackFan`、`sword_01_right_level` … `sword_08_left_level`。没有火焰、持剑和火环。

## 打开

用 Blockbench 直接打开上面的 bbmodel。拖到身体右侧、从 +X 朝 -X 看，能同时看见灰蓝身体、靠近背的深红剑柄，以及更远的金橙剑尖。
