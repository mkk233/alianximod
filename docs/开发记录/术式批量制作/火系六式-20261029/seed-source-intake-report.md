## 用户授权

任务书原话：用户直接点名授权修改三个已有术式：点火附魔后的术式或武器攻击额外给敌人2点火种；热光束每次命中给敌人1点；火球命中给敌人3点。

同批只读任务单里记录的更长用户授权是：现在没有为敌人挂载火种的术式都只有消耗，帮我修改现有术式中的点火，热光束和火球，让他们都可以给敌人挂载火种，点火附魔后的术式或者武器的攻击可以额外挂载2点火种值，热光束每次命中都给敌人叠加1火种值火球命中会提供三点火种值。

数值按这次授权：点火额外 2，热光束每次命中 1，火球命中 3。「额外」指可以叠加：点火加热光束共 3，点火加火球共 5。这是点名修改已有三项，不是从已完成自动抓新任务。旧记录里的「未授权新增来源」对这三处来源不再成立。六式消费者的现有设计不重做。
