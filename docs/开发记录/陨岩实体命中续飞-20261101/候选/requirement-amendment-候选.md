# 陨岩需求修订：实体命中后续飞

供唯一写回执行者更新当前需求。源码作者不改制作表。

## 用户原话

接下来修正一下陨岩，陨岩现在命中后会在命中位置生成石块并落下这个效果不好，撞到实体应该继续以目前弹道移动直到触地才变成方块。

## 被替代的旧行为

下列句子不再作为现行要求：

- 空中命中后立即在接触点生成无伤残骸，并以零水平速度直坠。
- `docs/开发记录/术式批量制作/待制作-20261031/approved-v1.md` 里的「空中撞击后只无伤坠落」。
- `author-c-content-final.md` 里的「空中命中或超时只生成第一段的无伤残骸」中，空中命中这一半。

超时且全程没有合法实体命中时，仍是无伤残骸，不叫撞地。

## 现行行为

第一次合法命中实体时，已有直接命中、中心冲击、附魔、接续和费用仍按原语义只结算一次。

实体接触后保持同一颗飞行陨岩。继承命中瞬间的位置、实际步长、弹道对象和已经作用的重力或改写。抛物线继续抛物线，垂落、喷涌和其他已经生效的改写按各自当前状态延续。不在接触点停住，不跳回起点，不另生成第二颗，也不把续飞做成无重力直线。

沿途再重叠同一实体或其他实体，不再打伤害，不再触发中心、热波、命中接续或再次消费。续飞不会因为卡在实体体内而每刻把位置拉回接触点。

续飞仍然做地形碰撞。第一次合法撞块才走原来的安全落块：先按既有规则崩地，再安放；有合法空气位、支撑和权限才放下方块。不穿墙，不覆盖任意地形，不强载区块。没有合法位置时，仍是原来的无伤残骸等待、重试和持久保存。已经结算过的中心和热波不会在落地再来一次。

没有提前命中实体就撞块的陨岩，仍是一次撞击、一次接续和一次落块。没有命中实体时，原来的攻击超时不变：到寿命只留无伤残骸，不打中心，不接续，不叫撞地。已经命中并续飞的那一支，不会被原来的攻击寿命提前清掉、在空中变成方块或再次计费。

服务器决定命中和落块。客户端外观跟着同一颗飞行体，直到它消失。飞行命中体本来就不存档；区块卸载或读档不重放这次伤害，也不复制残骸。伤害、半径、体积、费用和已有配置键不变，缺配置仍回各自默认值。

## 明确不改

- 第一次合法实体结算的中心、附魔、接续和费用语义。
- 撞块后的崩地、安放、失败重试和残骸持久保存。
- 直接撞块、未命中超时。
- 聚能、其他术式、火种账本、地形总开关和全局碰撞策略。
- 热波 v2 与陨岩中心排除的既有含义。
