## 使用与待游戏实测

以下是已批准实现的验收预期，尚未游戏验证。

- 名称：领域绑定（rule_domain_bind），通用无属性规则，沿用通用图标，规则自身魔力和装配消耗为0。
- 前置：进入世界，在装配界面将已学领域与攻击组成链，手持装配该链的对应武器或法杖；要求持剑的攻击仍须满足实际出手资格。
- 基础例：雾雨 → 领域绑定 → 垂丝。领域绑定必须紧接领域；施放后满20tick首发，此后每20tick触发，无目标也生成。有域内有效目标时默认朝最近目标；无目标使用随机方向，后续适用规则继续生效。转动玩家准星不应把自动攻击拉回玩家身边。
- 复制例：雾雨 → 领域绑定 → 一分为三 → 垂丝。每轮按既有复制计划生成；没有另行位置规则时保留垂丝0.72横排，最终源点限制域内，边缘钳制可能重合。
- 双重例：领域 → 领域绑定 → 双重释放 → 攻击A → 攻击B。捕获两段且按A后B执行，间隔沿用5tick；不会开域时另放一次，也不会把被捕获攻击留给下一次普通按键。未被捕获的尾段仍保留普通链行为。
- 费用：开域沿用原生成费/领域附魔起手费；子计划按每轮正常报价独立预留，真实成功的计划份提交，失败和未提交部分退款。同一计划份多个实体不重复收费。缺魔跳过当轮，领域保留至原定期限。领域基础附魔的每种每次1点接触收费沿用上一任务，不和绑定释放混为一笔。
- 多域与结束：每份领域独立触发/支付，开域冻结子链；换装不改旧领域的链内容。领域结束取消尚未生成部分，已成功生成的攻击保留自身寿命。无剑的自动操纵失败不应重复刷提示。
