# 多重释放底座接口裁决（唯一 Astra，设计 1/2）

已批准，可实现。原始需求见 approved-design.md；本文件细化边界。

## 结构
- ReleaseDefinition.multicastSpec() 默认无；MulticastSpec.fixed(N) 正整数与 remaining()，现有双重 fixed(2)，不新增术式/ChainRole。
- 唯一解析器读取原始装配槽，不先 TechniqueChain.split。递归共用单向游标：内层多重占父一格，读取其自身 N 格后父从新游标继续；所有修饰/附魔/攻击占格；不补读、不回绕。
- 不可变 Expansion 至少 startIndex/nextIndex/consumedIndexes/chargedIndexes/ignoredIndexes及原因/orderedMembers。成员包含 ordinal、hostIndex或独立附魔下标、继承修饰、本地修饰、有效复制下标。仅结构，不能存玩家/动态报价/目标/随机实体。
- 所有 ChainSteps、CompiledReleaseStep、领域捕获、旧多重辅助方法用此一个结果，不再各算窗口。非多重沿现有路径。

## 修饰与末尾
- 根多重前的可继承索敌/弹道/增幅作用整个展开及后代，同一原始项只一次。
- 内部修饰只找该作用域内随后首个适配攻击；可进入嵌套后代寻找首个，但不能广播给全子树。保持现有覆写优先和乘算规则。
- 一变多能力直接面对多重：消费格、标记 IGNORED_COPY_ON_MULTICAST，不参与费用/CD/复制、不重新后附。面对实际攻击则正常。能力判定不按ID。
- 尾部附魔在本作用域结束仍无宿主，生成原语义独立附魔队列成员，不跨到未读取的下一步。无宿主的非附魔修饰未用、不占时间、不收费/CD。
- 多重仅有实际执行成员才收费/CD；空展开拒绝，付款前失败。

## 调度与账务
- 唯一扁平队列：首实际成员立即，之后序号*3tick；修饰不占时序，独立附魔占时序，同成员复制同时。
- 保留不兼容真实前摇拒绝，付款和首发之前拒绝；不绕过前摇、不另造蓄力系统。
- 原始槽只计一次费用/CD，复制按原规则；结构动态报价分离。
- 父执行ID+触发组ID+ordinal唯一成员，复制派生；真实发布成功才保留份额，已发打空不退，未提交/取消/失败退一次。共享规则费用沿原成功保留语义，不因嵌套重复。
- 任意长度队列每成员可靠终结回执；异常也终结，不能被 ChainScheduler 吞后永久等。全部终结一次CD和推进。
- 手动一队列；动作每合法接触一独立队列，保留碰撞几何，窗口结束且组收束后父CD一次，无接触仅动作CD。
- 领域保留20tick独立轮，长队列可重叠，每轮独立预算/取消；冻结开域计划/域内source和target/LaunchAim/PublicationAttempt/部分退款，禁止写按键CD和游标；失效取消未发布，不能重选目标替换冻结轮。

## 缓存与领域
- 缓存仅不可变结构；声明不可变，改变N必须走现有登记/epoch，不关闭缓存逃避实现；候选查询保持。
- 领域原允许攻击条件保持，窗口用共享展开，遇不允许成员按原拒绝契约，不跳过后补格。
