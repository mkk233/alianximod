# 本次已批准设计快照

用户最终接受：类似Noita但不是抽牌；顺序读取原装配位置，所有层级共用向后移动的游标。每层多重提供N次直接格读取；读一个修饰/附魔/攻击/内层多重各消耗本层1格。读到内层多重，父层花1次，内层追加读取自己的N次，然后父层从新游标继续剩余次数；内层可越过外层原先固定N格范围。链尾停止、不回绕、不重读。穷尽表示从当前游标读取剩余全部，并非无限循环。没有抽牌、洗牌、弃牌或修饰自动补读一格。
能力需易扩展固定N和剩余全部；当前只让已有双重声明N=2，不注册三重/八重/穷尽物品、术式或新ID，避免按术式id分支。两重嵌套现有双重即可验证，未来定义层仅声明数量即可接入。
整个递归展开结果变为一条有序释放队列，忽略成员普通CD，第一项立即，后续实际成员按3tick节拍顺序执行；不为每层启动独立并行3tick子链。修饰解析不额外占时间节点，合法复制份同时生成，不能把3副本当3个间隔节点。不可借不等CD跳过真实蓄力/前摇；原不兼容前摇拒绝契约应保留，如何接通由设计裁决决定。
外置索敌/弹道/适用增幅等前缀作用于整个多重展开组合，包括嵌套后代。子链内部修饰按正常逻辑交给随后首个适用攻击，不泄漏到后续所有攻击。相同修饰不能因穿过多层重复乘；覆写型仍遵循原优先关系。修饰本身占读取格但不自动追加读取次数。
一变多复制类型（当前一分为三）直接作用于整个多重组合时只忽略该项，组合照常释放，不拒绝整链；不可变出多个多重子链。子链内部对单个攻击的复制正常生效；若内部复制直接修饰内层多重，也按同一原则忽略。按复制能力判定，不为某个id硬编码。忽略项的费用/CD/元数据如何清除须设计裁决明确，不能靠多层把它重新带入攻击。
付款沿实际参与计划及合法复制份额，不因层级重复计费；未提交份可退款，已发不因打空退款。最后所有实际成员终结后，统一本步骤CD和一次游标推进；同一原装配项不可按层级/复制次数重复加CD。普通A+B、E+Z+A、独立附魔、普通冲刺等非多重路径不受影响。
动作+多重继续支持接触触发：每次合法接触触发一套已展开队列，组内新3tick；多个接触组仍独立且父CD项目只算一次，无接触只动作CD。保留原实际接触几何、取消与付款身份。
已实现领域绑定也必须兼容此通用多重底座：捕获范围/结构计划/自动队列顺序/3tick统一，不能继续只认2个终结攻击或5tick。保留领域每20tick产生独立触发轮、显式域内源/目标、开域冻结、原报价/PublicationAttempt真实提交/部分份退款/主人生命周期。本次不重新设计或重审该外部任务，仅改多重相关接线。
结构缓存只存结构/下标/规则描述。费用、法杖、玩家、目标、随机几何仍按既定时机读取；多重能力声明变动应遵守结构代际失效，不禁用或移除缓存来绕实现。保留候选查询复用和性能统计。

示例（纯攻击A/B/C等）：
- 双重,双重,A,B,C,D -> 本次A/B/C，0/3/6tick，D留下一步。
- 三重,四重,A,B,C,D,E,F,G -> A..F，0/3/6/9/12/15tick，G留后续（三四仅接口推演，不新增注册）。
- 双重,一分为三,A,B -> 本次A三份同时，B留后续。
- 三重,落点指定,A,B,C -> 本次A带落点，B不带，C留；修饰占1格。
- 锁定,双重,双重,A,B,C,D -> A/B/C均继承外置锁定，仅作用一次。
- 一分为三,双重,A,B -> 不复制整段，A/B各一次。
