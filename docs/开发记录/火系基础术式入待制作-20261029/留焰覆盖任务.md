## 已被用户采纳的留焰设计

留焰是火系附魔，不是独立攻击。移动中的攻击体沿真实经过路径留下短暂存在的火焰轨迹，敌人接触该火径时受到该载体规则下的攻击。作用是把已经走过的路径变成短暂危险区域，不是慢速漂移火源，不是持续定向喷射光束。

- 普通移动投射体+留焰：留下直线火径，可用于封住追击路线。
- 风暴轨迹+留焰+移动攻击载体：旋转运动不断留下火径，组合形成火焰风暴。
- 喷涌+留焰+兼容移动载体：沿上升及下落路径留下弧形火迹。
- 火径与原攻击共用真实施法上下文及对同目标的命中计时。多个重叠片段不按片段数重复伤害，本体和火径也不能重复结算同一次命中；不得每片段/每tick创建新释放 token 绕过去重。留焰不额外复制一次攻击伤害。
- 留焰自身不生产或消费火种。种火、引燃、引爆由对应附魔提供，仍遵守同次释放去重和目标唯一共享火种余额。引燃多层共存、逐段争用火种；引爆只用即时剩余余额。不能靠火径重叠倍增产种、挂层或即时引爆。
- 不放置会蔓延的原版火方块，不破坏地形。只是短时攻击轨迹及其表现，不生成陨石残留、不取代灼地区域驻留。
- O视觉：移动攻击体后方出现连贯的火焰尾迹，沿实际路径短暂停留后由旧到新衰减、熄灭。旋转时形成连续弧形/环绕火径，喷涌时形成上升下降弧线。可见火径与有效判定位置对应，不把整个视觉漏斗都算伤害。
