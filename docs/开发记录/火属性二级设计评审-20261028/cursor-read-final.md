## 1. 标题、章节、主旨、战斗循环

正文没有一级标题，从「## 1. 设计目标与硬约束」起笔（块 1）。四节为：目标与硬约束（块 1–36）、术语与稳定 ID（块 42–59）、玩家可见循环与目标数值（块 65–123）、炉心状态（块 129–194）。文件在块 194 结束，没有火种术式、助燃术式、结算顺序或验证清单。

主旨（块 7–18）：火系围绕炉心·过载做爆发窗口。普通炉心是低风险过渡和预热；过载是最高火伤与最高火种获取效率的窗口。炉心本身不产生被动火种光环。

玩家循环（块 10–14）：

燃烧进入过载 → 火术式在敌人身上积累火种 → 助燃术式消耗火种，换成本次伤害、持续时间或范围 → 冷却结束窗口，用蒸汽冲击拉开距离。

状态机（块 71–90）允许跳过预热：无炉心可直接燃烧进入过载。不存在从过载降回普通炉心的路径；要再走普通炉心，必须先冷却，再从无炉心施放升温。窗口时长不是 7.5 秒或 10 秒，这两格是从 0 爬到火伤封顶的时间（块 99–100）。炉心持续时间为无限（块 137），主动出口是冷却。

## 2. 已写明的规则

行号均为逻辑块。决定性数值尽量按原文保留。

**硬约束（块 24–36）**

1. 火种是火系唯一可积累、可消耗的资源。
2. 火种挂在目标实体上，不挂施法者；不注册 CASTER 或 WORLD 火系资源。
3. 没声明火种绑定的术式，不得自动产生或消耗火种；伤害数值不能反推火种。
4. 同一目标在同一次施法中最多获得一次火种。
5. 同一次施法对同一目标最多消耗一次火种。
6. 同一次施法中已被消耗火种的目标，不得再从该次施法获得火种。
7. 火焰伤害本身不自动给火种，必须是显式生产者。
8. 炉心火伤与火种 `BURST` 增伤在同一个加算层，不二次乘算。
9. 冷却释放是固定蒸汽伤害，不读取炉心层数、火伤爬坡、火种、能量或规则增伤。
10. 冷却只恢复生命上限，不恢复当前生命。
11. 炉心三式各自占技能栏，各自结算魔力与技能冷却，不能互相替换或改写冷却。
12. 火种获取量为 0 时必须得到 0，不能被「最低 1 点」规则变成 1。
13. 规则类术式可以放大火术式基础伤害与体积，但不能放大火种获取量或消耗档位。

满窗口例子（块 114–123）：过载火伤爬满，并用满 60 点火种触发 `BURST` 时，总加成 = +60% + 24% = +84%，最终火伤 = 基础伤害 × (1 + 0.60 + 0.24)。这 84% 是一个加算层，之后只走项目正常的护甲、附魔、抗性与承伤管线，不允许再乘 1.6 或 1.24。

**生命周期（块 135–144）**

载体必须是 `mod:furnace_core`。持续时间无限。正常玩法只有升温、燃烧能给施法者自己施加。不注册药水、喷溅、滞留、药箭或酿造配方；管理员命令只用于调试。牛奶不能移除炉心；拦截后保持同一 amplifier 与同一运行态，不得重新开始计时。退服保留状态与运行态；登录从保存进度继续，不累计离线时间。死亡清除状态与运行态，不触发蒸汽，不修改升温、燃烧的技能冷却。主动冷却结束状态并触发一次蒸汽，每目标只结算一次。其他来源移除都算非主动结束：清理运行态，不触发冲击，不改技能冷却。燃烧覆盖普通炉心时，必须在同一服务端提交内完成 amp0→amp1，并保留同一个 `FurnaceRuntime`。若不能原地改 amplifier，可以替换 MobEffect 实例，但必须留下累计值，避免重复播放施加音效/粒子，且不得表现为先移除炉心再重新进入。

**运行态（块 150–165）**

```text
FurnaceRuntime {
    playerId
    amplifier                  // 0 | 1
    accumulatedFireBonus       // 0.0 .. 0.60，当前已累计火伤
    lastRampUpdateGameTime     // 服务器游戏时间
    enteredAtGameTime          // 调试与 HUD，可选
}
```

`accumulatedFireBonus` 是权威值，必须按玩家写入持久数据。不能只按进入时间重算，因为覆盖时成长速率会变。登录恢复同一 amplifier 与累计值。有 MobEffect 但运行态丢失：按当前 amplifier 新建运行态，从 0 开始，并写警告日志。有运行态但 MobEffect 丢失：清理运行态，不触发冷却，不补发状态。

`docs/火系攻击术式设计.md`（2026-10-21，依据当时 86 行的底座功能点）用现有角色拼火球、爆燃：火球伤害 5、速度 1.2、40 tick、点燃 4 秒、魔力 10；爆燃伤害 8、速度 0.6、半径 3、魔力 16。该文第 11 行写明本轮不做新资源、新附魔、持续伤害或引爆层数，也不改火球、爆燃和既有规则数值。二级设计新增的是炉心、实体火种和蒸汽类型。它没有把火球或爆燃声明为火种生产者。按块 26–30，未声明绑定的术式不得自动产消火种，火焰伤害和原版着火也不自动产火种。三式自身「调用原版着火」为否（块 188）。因此旧火球的 4 秒点燃不会按本文件自动变成火种；是否已在代码里绑定，尚未核对代码。
