- 最新分工原话：修改建议由主会话提供；设计环节只有实现术式制作表时由 Cursor 负责；用户直接找主会话讨论设计时，应由主会话思考具体修改建议。
- 用户新增方向：玩家可选持续燃烧或单次引爆，两者均消耗火种；终极奖励术式焚天点燃周边范围内所有挂有火种的实体，100点最多40tick烧完，多段燃烧，每段基础伤害2。
- 已确认倍率：每10点火种值对应1个增幅档，每档乘1.2；10档单段为2×1.2^10≈12.38，不是每档乘2，也不是加算20%。
- 本轮前只重读记录并核对输入哈希；未派发新的 Cursor 或 Astra 设计任务。
- 主会话建议（尚未获用户批准）：持续路线以总收益和持续压力为优势，引爆路线即时兑现但同投入总伤害略低；焚天作为范围急燃终极消费者；施放时锁定各目标投入火种、段数及倍率，一次投入并扣除，之后每4tick结算一段，每完整10点对应一段，100点在第4至40tick共10段；完整段伤害保持初始倍率，不随消耗下降。
- 该建议下，不计炉心与减伤：10点为1段共2.4；50点为5段共24.8832；100点为10段共123.834728448。均为理论结算值，未游戏验证。

- 组合建议：焚天指数转换不再叠加旧BURST每10点+4%；保留炉心同层加算时，完整段伤害为2×[1.2^档数+炉心火伤加成]；同一目标不重复挂载多份焚天燃烧。
