# B2 键与消费者

入口是 `ModTechniques.declareSpecialBalances()`。它在外部注册之后、封存之前调用，只登记专项。未封存或键未声明时，读取退回调用点传入的原始值。封存后玩法读取当前侧快照。魔力在真实扣款处乘一次全局魔力倍率。伤害贡献走一次 `damageContribution`。

每个已改源文件的修改前副本在 `docs/开发记录/配置平衡-20261101/pre-B/` 下的同相对路径。`SpecialBalance.java` 是新文件，没有备份。

## 只读取、不由 B 声明

| 术式 | 键 | 读取点 |
| --- | --- | --- |
| water_mist / water_deep_pressure / fire_nether_gloom | manaCost | DomainService 用 initialCost 原始值缩放一次。雾雨和深压默认 40，幽冥默认 0 |
| water_prison | manaCost | 成功目标扣款。unitManaCost 保持 40。退款退本次缩放后的金额 |
| 自身状态 | manaCost | SelfStatusCommit 用 explicitManaCost 缩放一次。回执退同一笔 |
| phantom_sword / tide_mark / fire_liaoli / water_prison | damageMultiplier | 仅在已声明时做一次 damageContribution。未声明时保持原来的 float 收窄 |
| fire_nether_gloom | C 的资源周期 | NetherDomainCycle 三处调用 NetherContract.periodTicks()：开窗取模、窗口编号、首次等待 |
| fire_scorch_field | C 的 lifetimeTicks / halfExtent | B 不声明。定义寿命 getter 在该键已声明且已封存时会读到它。焦土 open 调用保持原样 |

## 伤害换算

- 幻剑：生成时先乘场帧倍率，再 `damageContribution("phantom_sword", 原始武器伤害)` 一次，写入 copiedDamage。读档的 Damage 不再缩放。
- 潮印：条数独立。幻剑生成时 `damageContribution("tide_mark", 条数 * 2)` 一次。
- 燎里：只缩放物理撞击 `基础伤害 + 1.5 * 接近速度`，上限仍是 40。原始撞击大于 0 时，配置结果为 0 也照样结算。火种伤害留在 C 的引爆里。
- 水牢压迫：原始 4 点走一次 `damageContribution("water_prison", 4)`。没有单独的最终伤害键。环境伤害仍无攻击者。

## 费用拆分

- 领域开启费就是 `Technique.manaCost()`，使用标准键 manaCost。不另声明 spawnManaCost。
- 水幕和水环的 `Technique.manaCost()` 是显式 0。真实费用是 spawnManaCost 与 upkeepManaCost。报价和成员分摊要用这两把键，manaDefault 传空。
- 水牢成功费就是标准 manaCost。不声明第二把 successManaCost。按键路径应继续跳过重复扣款。
- 自身状态只在 SelfStatusCommit 扣 manaCost。
- 领域接触报价保持种类数乘原始 1。扣费把单价缩放一次再乘种类。

## 未接入

- 潮印领域光环加成仍是原始魔法伤害。DomainAuraResolver 不在本作者范围。应在解析器里对 tide_mark 做一次 damageContribution，不要在 B 侧再乘。
- 垂丝的注水、泄水和坠落在 WeepingCurtain.java，客户端布局也读静态常量。本作者不能改这些文件，所以这三项没有声明。
- 场地维护没有现行水系产品调用，不声明场地维护费。
- 幽冥产种数量、焦土寿命和半边长、播种数量、引火分段、清凉半径、藤标记控制、点燃秒数属于 C。
- 剑来和万剑归宗不要开 damageMultiplier。幻剑面板基础伤害 2、万剑归宗面板基础伤害 8 都不是剑实体伤害。
- 水牢基础伤害是 0。A 需要为 water_prison、phantom_sword、tide_mark、fire_liaoli 声明 damageMultiplier，否则贡献读取保持原值。
- 幻剑飞过 64 格弃置、插地嵌入、水幕前放 2 格、柔带表面刻、漩涡滚动展开、陨岩重力和俯仰、喷涌重力和半角，都保持原结构。
- 寄生种子份数保持 3。寿命为 1、速度为 0、厚度为 0 的结构哨兵不登记。
