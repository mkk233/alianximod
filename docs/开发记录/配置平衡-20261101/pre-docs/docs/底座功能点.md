# 底座功能点

更新日期：2026-10-30。

本文按当前源码说明底座已经能做的事、可以怎样组合，以及每条能力的边界。读者是玩法与内容设计。这里写的是源码行为，不表示这些组合已经做过游戏验收。

机制名只在需要区分入口时出现。下文不列具体术式清单，也不把某几件术式的命名组合当成底座规则。玩家现在能装配出来的内容，和释放定义上可以声明、但还没有对应可装配条目的接口，分开写。

一次释放先把有序装配收成段，或按多重声明展开，再由服务端按 tick 排队提交。提交时写入一帧几何和修饰。命中体按自己的运动和体积去碰活物。伤害要么立刻打出，要么先记入账本再一次结算。动画只在宿主组已经提交成功之后通知。取消姿态不会把已经提交的几何收回。

## 能力速览

- 组合调度：有序链可以按住连放、要求重新点按、插入段间延迟和蓄力；多重按读取格展开，复制按份数打在宿主上。
- 定位、轨迹与几何：锁定、出手瞬间的初瞄、落点和散布决定往哪打、从哪生成；直线、垂落、跟随、函数和螺旋决定怎么走；不可变形态只改点和刀面。
- 伤害与附魔：命中可贯穿并去重。多份先入账再结算。根伤害和持续接触对无敌帧的处理不同。元素反应是一张固定表。没有后续宿主时，附魔可以印在主手上。
- 资源、状态与模式：魔力与水势分开预扣和退回。潮湿分档并限制飞行。火种在同一目标上积累，再用引爆或分段燃烧花掉。炉心有普通和过载两档，并改写自身属性。
- 场地、护体与领域自动链：球形场地钉在原地并按维护扣魔力。护体跟着主人。领域按寿命留存，可以把后面的攻击冻成子计划，自己按轮次发射。
- 条件、控制与防御：条件查询按目标收费。薄墙和障碍挡住身体。治疗和牵引是一次性的。偏转用潮湿档和水势买下箭或近战。监禁把人拉回锚点。
- 学习、装配与存储：复杂度、两系等级和领域许可决定能不能用。剑技四个槽，法杖一条链。术式石进 27 格个人收纳。服务端重新编译并校验后才释放。
- 扩展、动画与诊断：别的模组可以登记进同一条链。姿态在攻击已经提交之后才播放，取消姿态不收回几何。结构缓存、候选查询和性能记录只帮助计算与观测。

## 最小单元与统一链

`Technique` 是最小单元，带伤害、冷却、类型、属性和是否附魔。类型只有四种：

| 类型 | 装配去向 |
| --- | --- |
| 剑术 | 只能进剑技 |
| 法术 | 只能进法技 |
| 通用 | 剑技和法技都能进 |
| 动作 | 装配界面允许进两边 |

管理器里「剑技兼容 / 法技兼容」的查询不含动作。真正的装配界面允许动作进入剑槽和法杖。以装配界面为准。

释放种类是动作、命中体积、规则、自身状态。角色是下面十个。新内容登记到同一角色，就走这一类的收集和结算，不按术式编号单独接落点、弹道、规则或附魔。

| 角色 | 当前玩家侧 | 作用 |
| --- | --- | --- |
| `ATTACK` | 命中载体 | 这次释放打出去的宿主 |
| `ACTION` | 可装配的动作 | 动作本身。自身状态也用这个角色，但是另一条提交 |
| `SEEK_SPACE` | 可装配的落点修饰 | 改生成位置，不改弹道种类 |
| `SEEK_ENTITY` | 可装配的锁定 | 标记活物，供接受瞄准或弹道可变的宿主使用 |
| `TRAJECTORY_TRACKING` | 可装配的追踪修饰 | 把追踪标志交给后面的宿主。宿主是否跟着转，还看它自己的开关 |
| `TRAJECTORY_DROP` | 可装配的垂落修饰 | 覆盖路径。同一段里靠近宿主的最后一条路径声明留下 |
| `TRAJECTORY_SCATTER` | 可装配的三维交错 | 改散布，不做索敌 |
| `RULE_TRIPLE` | 可装配。复制因子固定为 3 | 把因子乘到后面第一个能承接复制的宿主上 |
| `RULE_DUAL` | 可装配。多重固定向后读 2 格 | 当前唯一可装配的多重 |
| `RULE_DOMAIN_BIND` | 可装配的绑定标记 | 必须紧贴零伤领域，把后面的合格攻击冻成领域子计划 |

弹道枚举是直线、垂落、跟随视线、函数、螺旋。螺旋注释写明轴向速度用攻击自己的速度，不改斩击形状。

存档里若还留着已移除的旧规则标识，释放时跳过，不占角色，也不占多重的读取次数。它们不会再出现在可装配列表里。

### 修饰挂到谁身上

普通切段不先做多重解析。附魔先攒着，挂到后面第一个不等宿主的段上。链尾剩下的附魔各自成段。会等宿主的是落点、锁实体、三种弹道角色、因子 3 的复制、固定读 2 格的多重，以及链能量倍率不是 1 的定义。

修饰能否挂上，看宿主能力，不看术式编号：

- 落点和三维交错要求宿主接受安置修饰。默认只有攻击角色且种类为命中体积，并且没有屏障、领域、护体、场地和条件释放。弹道固定的斩击也接受，因为它们只改生成位置和刀面。
- 锁实体要求初瞄、持续索敌覆盖或弹道可变三者之一。
- 垂落和追踪要求路径覆盖或弹道可变。
- 链能量只被「法术、非附魔、属性不是空、种类是命中体积」的宿主收下。
- 能承接复制的是领域、屏障、护体、场地、条件释放，以及攻击角色的命中体积。动作、多重声明自己、复制声明自己不能承接。不按基础伤害是否大于 0 一刀切。
- 能接附魔的条件是基础伤害大于 0，或者定义上带领域、屏障、场地、护体或接触条件。

修饰扫描沿装配顺序走向后面的攻击，直到碰到基础伤害大于 0 且不是附魔的段，把该段记成攻击并停下。落点、锁实体、追踪和交错碰到一次就生效，不互相取消。垂落类角色每次用该定义自己的弹道覆盖路径，所以靠近攻击的最后一条路径声明留下。不在多重展开里时，角色 `RULE_TRIPLE` 每遇到一次就把份数乘 3。角色 `RULE_DUAL` 记下规则段，恢复点跳到它放出的最后一名成员之后。当前这件可装配多重已经有展开对象，成员间隔是 3 tick，不使用没有展开对象时的 5 tick，也不使用更早的 10 tick。

执行时还有一次反向角色扫描。边界是前面的正伤非附魔段。若两边属于同一次多重展开，这条边界被跨过。路径只在尚未写入时收下，因此同样是离宿主最近的一条垂落声明生效。

结算顺序仍是索敌、弹道、规则、攻击。索敌只决定往哪打，不改弹道种类。`trajectoryMutable` 为假的攻击只改生成位置和刀面。为真的攻击才接受路径覆盖。

## 装配、按键、延迟与蓄力

一条链最多 8 段。客户端发来的是槽号和手势：点一次、按住、松开。服务器不相信客户端算出的伤害，会重读主手、玩家槽或法杖链，并重新编译领域绑定。

手持法杖时只有右键，对应槽 0。手持剑技载体时，右键、C、V、R 对应槽 0 到 3。有界面时一律松开按住。空手只有这一格的链含操纵世界剑、并且客户端能看见自己还活着的剑实体时，才把按键发给服务器；否则留给原版，也不打开装配。装配键同样要求主手已经是载体。

服务端再查一次。槽号必须是 0 到 3。法杖只接受槽 0，链上不能有剑术。不是载体时，必须这条链是操纵剑、且当前维度里有该玩家拥有的存活剑，否则静默返回。操纵链若既没拿剑、世界上也没有自己的剑，会提示需要手持剑。定义若要求必须手持剑，斧、镐和三叉戟不够，主手必须是剑。

按住会给该槽做标记。服务端每 tick 末尾，冷却不忙且槽仍按住时再发一次，不再公告。冷却中或魔力不够时仍保持按住；装配不合法才松开。链上任一格要求重新点按时，这一槽的按住循环直接跳过，冷却结束也不自动再放。死亡、下线、换维会清掉全部按住标记，抬高蓄力纪元，退回未提交水势，取消该玩家的执行会话，并关掉其场地和领域。

非步进时，段与段的间隙才加上。下一段若带着附魔，间隙是这些附魔冷却之和，每条至少 1 tick，再乘元素反应的冷却倍率。否则前一段基础伤害大于 0 时用它的基础冷却，否则间隙是 0。冷却缩减在发包处再乘一次。步进链把整段冷却交给步进游标，段内不再加这段间隙。

调度器在服务端 tick 末尾跑队列。计划时刻不晚于当前 tick 就立刻跑，否则入队。单次异常只记日志，不拆掉后面的任务。

蓄力 tick 大于 0，且本轮尚未武装、也没有蓄力旁路时，段执行先预约水势，再推迟这么多 tick。到点若纪元变了或施法者已死，水势退回，不再进入释放。自动领域轮改看寿命令牌，不看按键纪元。蓄力 tick 不大于 0 时，当场提交水势。打断只清场，不放收招。只有声明了蓄力拍数的定义才等待。

松开提前结束是定义开关。按住循环不读它。目前是生成命中规格时由对应效果抄进规格，不是调度器的通用取消。

### 自身状态

种类是自身状态才走这条提交。它不生成命中体。合法装配里不能再有别的有效段，因此这次按键没有后续段可排。先预检炉心和魔力，扣款成功才改炉心；炉心没改成就退款。魔力不足、炉心没变化，或动作是结束，都不进冷却，这次按键就此结束。

自身状态同时打开混链拒绝，并要求松开后再按。

### 混链拒绝

公共路径读定义上的布尔，不按术式编号分支。有效段多于 1，且其中任一格操纵世界剑，或定义打开了混链拒绝，整条拒绝。自身状态的提示是不能和其他术式装配；其余走操纵术式的提示。操纵世界剑的段即使自己的混链拒绝开关是关的，只要和别的有效段在一起，也会被这条判断拒绝。

## 多重、复制、作用域与退款

多重解析读原始装配下标，不先切段。从游标跳过紧邻的已移除规则、前缀修饰、复制和附魔，遇到多重声明才打开。固定次数读那么多格，链短了就停在链尾。读到链尾则一直读。已移除规则不占次数。

复制、附魔和可继承修饰先挂起，遇到宿主再分配。作用域结束时，仍无宿主的附魔变成独立成员，其余挂起修饰记为未使用。复制若直接对着多重，整格被消费并丢弃，不进费用和冷却。内层多重接走外层挂起，接不上的再退回。写在多重声明之前、被当成前缀收下的索敌、路径和链能量，整段展开的成员一起继承。写在层内、某一名宿主前面的修饰，只给这一名，不给后面的兄弟。

成员视图的折叠顺序是先继承下标、再本地下标。索敌、交错、追踪碰到一次即生效。路径覆盖以后写的为准。链能量在折叠里相乘。复制因子只乘在该成员收下的复制下标上，因子至少为 2。多重成员的份数用这份连乘，不再额外套一次「遇到 `RULE_TRIPLE` 就乘 3」。当前可装配的那一件因子就是 3，所以放在多重里仍是 3 份，不会叠成 9 份。连乘超出 int 时，付款步骤拒绝，份数不截成最大整数，也不把溢出后的负数当成 0 费。独立附魔成员份数固定为 1，不吃复制。

空展开会在付款前失败，账单为空，这一步不推进。被忽略的复制、无用修饰和已移除规则不计费、不计冷却。计费下标每个原始格只入账一次，成员自己的宿主下标不会在规则份额里再加一次。成员份额按该成员的复制份数另计：普通宿主是这段魔力乘份数；零伤领域、屏障和护体只把开域费或生成费乘份数；单价已经写在术式上的，以及声明了复制合并的条件释放，不按份数再乘。份数或这笔费用超出 int 时，展开报价拒绝。

### 玩家能装配的，和只有接口的

当前能装配的多重只有固定向后读 2 格这一件，角色仍是 `RULE_DUAL`。读到的实际成员里，序号 0 立刻出手，后面每个实际成员间隔 3 tick。同一成员上的复制份共用这个序号。修饰、附魔、内层多重和复制声明各占一格，它们本身不是额外的时间节点。

当前能装配的复制只有因子 3 这一件，角色是 `RULE_TRIPLE`。它不是多重。不在多重展开里时，它乘到后面第一个接受复制的宿主上。放进多重之后，只乘到收下这些复制下标的那一名成员，并且不再额外乘 3。

固定成其它次数，或从当前格一直读到链尾，是 `MulticastSpec` 的声明方式。没有对应物品，也不另开角色。下文场景里用到它们时会标明扩展接口。

没有展开对象时，旧的双重序列才退回每个序号 5 tick。当前这件可装配多重已经带展开对象，所以走 3 tick。计划对象上的波数只会被写成 1，不会再按波数拆出第二串。更早文档里的 10 tick 间隔不在现行调度上。

复制份数大于 1 且批次存在时才开账本。账本在第一次入账之后 6 tick 冲刷。这是命中汇总，不是成员出手间隔。

### 部分成功时钱怎么退

宿主组提交不是定义字段自由打开，而是登记表里的标识集合。集合外走即时释放。集合内，每一份复制都按全局实体倍率展开，这些份额必须全部预留到魔力；少一份就取消这一波已留的份额。这个倍率不是另一条复制声明，也不单独打开 6 tick 账本。真正生成时，必需份数都成功才提交一次。失败、重复、父释放结束后的迟到调用不生成。施法者离开，或纪元、手持条件不满足时，取消该组。

多重的自动轮另算：成功发布的份额留下，未发布的退回。规则费在本轮第一笔真实成功发布时保留一次。条件释放按目标计费，见后面的条件一节。自身状态在炉心没改成时退回整笔。蓄力被纪元或死亡打断时，只退水势。

## 索敌、初瞄、弹道与几何

### 锁定与两种瞄准

锁实体的查找是眼睛沿视线 20 格，候选框再膨胀 8 格，取得离这段视线最近、且到视线距离不超过 8 格的活物。候选来自共用的活物查询。找到就记下实体编号；在段执行里还会给 200 tick 发光。找不到就清标记。生成位置不因这次索敌改变。

领域自动轮不读玩家准星，也不读这枚锁定标记。目标仍有效就用本轮目标；失效就用本轮基准方向。宿主组若已冻结视线，整组跟这份视线。

持续索敌覆盖默认关闭。它为真，并且弹道可变时，这一发可以跟着标记转。

初瞄默认等于持续索敌覆盖，所以两者一起关或一起开时，不会单独走出专用初瞄。专用初瞄要三者同时成立：接受初瞄、不接受持续覆盖、弹道不可变。这时帧锁定关掉，只在出手瞬间把方向收成目标中心，生成点不因此改，之后也不跟着转。

命中体上的追踪运动是另一层。规格追踪为真、不是陷阱、路径是直线、垂落或螺旋，并且当帧弹道可变，才换成追踪运动。它采样原路径的速度，不把实体拽回那条路径。直线且带锁定时，起始方向可朝已标记目标。跟随施法者、静止瞄准和函数路径不进这层替换。世界剑悬停时的朝向是剑自己的状态机，不是这层追踪运动。

### 落点、散布与几种路径

落点指定和交错在弹道不可变时走斩击几何：只改生成点和刀面，视线方向保持。落点抖动半宽 1.5；仅交错时半宽 1.0。交错再加滚转和法线偏转。弹道可变时走弹丸几何。

中心点按这一发的开关选取。弹道可变且带落点或螺旋时，用批次准星。可变且交错且未锁实体时，用身体中点，并记下脚底高度，低于脚底的点抬到脚底。仅落点用批次锚。其余用眼睛。领域自动轮用本轮原点，撒点再钳回领域体积。

螺旋把锚放在中心，相位按黄金角铺开。落点，或「交错且没有实体锁」时，在半宽 1.5 的立方里撒点。仅交错且锁着实体则不撒成立方。垂落把点抬高 8 再向下，水平位置留在已经选定的点上。接触原点会盖掉这些覆写，把每一份收到同一个锚上，并清掉已经散开的标记。

运动都在命中体上每 tick 取样，不改收集规则：

- 直线、垂落、螺旋、函数走轨迹采样。
- 跟随施法者在自动轮里跟发射快照，否则跟主人；钉住后停在原点。
- 静止瞄准要么锁在锚和法线，要么跟主人视线。
- 贴身挥斩按寿命进度从主人朝向左侧 70 度扫到右侧 70 度。
- 陷阱下落每 tick 下降 0.35，碰到碰撞或世界底就插住。

同一条链上有多条路径声明时，成员视图以后写的一条为准；段扫描里则是靠近宿主的最后一条垂落声明留下。

## 自身能量、链能量与尺寸

能量层是所有术式共用的来源大小，写在 `energyScale()` 上，默认 1。链上的链能量另记为释放输入，不并进自身倍率，也不并进附魔半径。多条链能量相乘。倍率恰好为 1 时仍是新的一份输入，不收成单例。

一次释放的能量边界是「非附魔、命中体积、攻击角色」。提供链能量的规则和动作宿主不是边界。双重展开内部更早的宿主可以被跨过。剑技、无属性、动作、规则、附魔和空链的冻结输入是基准倍率 1。

几何能量是定义自身能量乘这份冻结输入。无效或非正数按 1。附魔半径不进这份几何能量。体积倍率是几何能量再乘附魔半径；非有限或非正则按 1。有限持续时间只乘链输入。倍率为 1 时尺寸和有限持续时间不变。

弧带关闭且倍率不是 1 时，定义分别决定长、宽、高、模型是否跟着乘。默认都乘。弧带半径和半宽只在快照冻结时乘一次。弧带快照会清掉运动和形状。

费用、伤害、冷却、距离、搜索和速度不乘能量。元素反应的同属性系数和相生系数是另一套：它们可以改伤害、冷却、半径、持续时间、距离、搜索或速度，不并进这份能量。

## 命中形状、去重、账本与无敌帧

命中体积和世界里的剑是两套实体。命中体默认无物理、无重力。

规格上的形状是弧扇、有向盒、轴对齐盒、球。只有路径和贴图都空时才用这四者。路径或贴图任一有值，枚举被换成尺寸盒。定义上的形状枚举不由命中实体读取。

| 形状 | 怎么碰 | 方块 |
| --- | --- | --- |
| 轴对齐盒 | 只测当前位置与目标盒相交，不扫移动 | 不看方块 |
| 有向盒 | 目标中心投到实体水平朝向，半轴内即中 | 不看方块 |
| 弧扇 | 以锚或施法者脚为心，看水平半径、高度和半张角 | 不看方块 |
| 球 | 上一位置到当前位置的线段去碰膨胀后的目标盒 | 不看方块 |
| 尺寸盒，普通 | 精确体积只认当前半长、半宽、半高里的目标中心；非精确还接受上一中心扫到当前中心，目标盒膨胀 0.2 | 不看方块 |
| 尺寸盒，三维姿态 | 用刀面法线、滚转和目标半身 | 不看方块 |
| 尺寸盒，跟随路径 | 不挡实心时，线段对膨胀目标盒 | `clipsSolids` 为真时走剑前走廊，实心碰撞体挡在接触点前面就打不中。走廊遮挡只这一条 |
| 弧带快照 | 按进度切片，窄相只测弧片与包围盒 | 没有方块裁剪 |

实体默认贯穿。间隔不大于 0 时，每个目标标识只进一次。间隔大于 0 时，同一目标在间隔内不重复记。碰墙不会因为贯穿而停，除非规格打开着地爆散：上一位置到当前位置若碰到碰撞体，就停在击点并走到期回调，不走引爆。着地爆散碰到活物时只调命中回调然后丢弃，不进入伤害结算。这个开关默认关。

陷阱是另一条专用规格。插地后有人踏进膨胀 0.3 的盒子才引爆：范围再膨胀 1.5，逐个结算并挂生命吸取，放一颗爆炸粒子，然后丢弃。这不是原版世界爆炸。到期、松开结束和寿命到点，都只调到期回调再丢弃。

主人自己、旁观者和已死目标打不中。

### 账本与无敌帧

有账本时，这一下先入账，不立刻造成伤害。账本在复制份数大于 1 且批次存在时打开。同一目标、同一轮、同一复制序号只收一次。轮次从第一次入账起，用间隔去除经过的 tick。伤害留下最后一份再乘份数。潮印条数按份累加。非伤害载荷合并成一份。第一次入账之后 6 tick 冲刷。

| 结算路径 | 无敌帧 |
| --- | --- |
| 根伤害，以及没有持续接触载荷的账本冲刷 | 出手前把目标的无敌时间暂记为 0，打完后取原来的值和打完后的值中较大的一个写回。若原来的无敌时间大于 10，同时保留更大的上次受伤量。同一段里的多份因此能全额落下，目标对其他伤害已经持有的无敌时间会写回去 |
| 确认伤害：持续接触的账本、接触附魔、领域接触计费 | 必须尊重无敌帧。只有最终正伤且事件没有取消，才施加载荷和火种 |
| 没有账本的普通命中 | 走根伤害 |
| 没有账本、但这一发打开了持续接触 | 当场走确认伤害 |
| 监禁的环境伤害 | 没有攻击者，不绕过无敌帧，也不给攻击者记水势 |

持续接触开关默认关。间隔大于 0 不会把它打开。

没有账本时，爆裂命中在第一次有效目标后丢弃实体，不再按伤害结算。火种在伤害被接受后才存入。账本里同一目标同一轮只留最高点数。潮印把附加值并进原版那一次结算，不另开一种伤害类型。

## 附魔与固定元素反应

段内附魔按原胚和附魔元素做反应，折进这一段，并参与段魔力和携带伤害。正伤段带着附魔下标时，伤害用附魔奖励算过的携带值。

修饰扫完却没有攻击、也不是多重序列、也不是留给接触的段时，这些附魔印到主手。场地半径大于 0 的附魔不印。再次写入覆盖。印记要求灼烧、附加伤害、潮印或火种至少一项，否则不写。

没有潮印的印记，在原版攻击实体事件里另打一刀玩家攻击，并附带灼烧、灭火、减速和击退。火种只在这刀打中后存入。标签在事件末尾去掉，不论这刀是否打中。带潮印的印记不走这刀：附加值是潮印条数乘 2 再加保存的附加伤害，并进原版那一次主目标伤害。只有原版伤害被接受、标签内容没变、而且活印戳还对得上时才消耗，并补灼烧和火种。

反应只有三种结果：缺属性为无，同属性为同，下面五对为生，其余为无。没有相克，没有未列出的属性对，也没有运行时改表。

| 关系 | 效果 |
| --- | --- |
| 同属性 | 伤害 ×1.30，冷却 ×0.70 |
| 木生火 | 半径 ×1.10，持续时间 ×1.10 |
| 火生土 | 距离 ×1.10 |
| 土生金 | 搜索 ×1.10 |
| 金生水 | 速度 ×1.10 |
| 水生木 | 持续时间 ×1.10 |

原胚属性不限制能刻哪种术，只在刻印时记下，释放时和术式属性比。

已注册附魔只有火、木、水、土、金。效果标识也只能是这五种。折叠时层数加 1，半径、持续时间、伤害、速度倍率连乘反应系数。水印的魔法伤害固定为 2，其余是 `ceil(2 × 伤害倍率)`。快照落地是专用的：火给点燃秒数和 2 点火种，木给缓慢，水给潮印计数，土给 0.35 击退。木属性缓慢时长写成至少 1 tick、按持续时间倍率缩放的 40 tick，多条取较长，施加时等级为 4。附魔叠层是倍率累乘，不是任意效果队列。

控制不是通用控制状态。剑实体命中若带控制 tick，同样给缓慢 4 级。场地脉冲的减速是缓慢 1 级，时长来自定义。领域减速用策略里的等级和时长，且不覆盖更强或更长的现有效果。

## 魔力、法杖与水势

默认魔力是 `max(0, ceil(基础伤害 × 2))`，也就是先乘 2 再向上取整，再压成非负整数。优先顺序是：附魔走附魔魔法伤害，至少为 1；条件释放若写了非负显式费用就用它；有领域则用开域费；规则种类为 0；其它非负显式费用优先于伤害公式。防御和治疗因此不会因为伤害是 0 就变成免费。

魔力在玩家术数据里，默认 100/100，和水势一起写入人物持久数据。扣款先看法杖库存，再扣玩家池，并记下法杖身份与两边各出多少。付不起时玩家池和法杖都不改。收据把预扣放在原余额，追加的费用进另一只口袋。退款先动追加口袋，再按预扣比例退回原法杖和玩家池，不退给后来手上的另一根法杖。已生效份额只划出可退余额，不退钱。父收据追加时，付不起或法杖身份冲突，池和上一张收据都不变。

一轮释放先预留当次收据。生效份额提交后划出。收束时把未生效份额退回。扣款当时会保存玩家数据。上一张收据和回复计数只在内存里。崩溃发生在扣款之后、退款之前时，余额已经是扣后的数，重启后退款收据找不回来。

回复每 20 tick 一次，基础 5 点。手持法杖再乘这根法杖的恢复效率，四舍五入。先填玩家池，剩余才进法杖。登出忘掉这人的回复记账。

现有一根基础法杖是 6 个槽、额外魔力上限 100、恢复效率 +20%、冷却缩短 10%。备用魔力记在耐久条上，不会被正常耐久打掉。冷却记在这根法杖上，不占四个剑技槽，也不和另一根法杖共用。常驻画面只有快捷栏上方一行魔力：玩家池加上主手法杖里的备用魔力。没有四个技槽的常驻图标。

### 水势

水势是另一本账，0 到 100，超出丢掉。可用额等于余额减去尚未提交的预留。预留不改余额，提交才减去，取消只放弃预留。预留表在内存里，重启后消失；未提交的预留不会变成扣款。

出手定义上的水势消耗先预留再提交。实际受到或打出的正伤害按实际掉血入账。同一发不能花自己刚加上的水势。监禁的压强伤害不再给攻击者入账。旧重水进入不再预留、不再提交水势，新会话一律不是重水。

水势还被偏转账本当钱包。没有注册宿主时，收购直接失败，并且不扣水势。

## 潮湿、火种与炉心

属性数值壳目前只有两个标识：潮湿和火种，上限都是 100。精确整数放在实体持久数据里。没有第三种属性状态的施加、药水和到期逻辑。

### 潮湿

潮湿 0 到 100，档位是 1–25、26–50、51–75、76–100。成功施加走累加：加上数量后钳制，并挂 1000 tick（50 秒）药水，药水等级为档位减 1。直接改精确值时，不把计时刷回 1000。进世界时只对潮湿做对齐。数值还在、药水没了，视为到期并清零。档位和药水不一致则保留剩余时间并改档。药水被移掉且不是主动编辑时，外壳把该标识写成 0。站在水里不会自动挂上。

移速削减挂在药水上。这张档位表本身不写状态、不注册事件。

| 档 | 移速削减 | 攻击回势 | 门槛资金 | 近战花费 | 箭花费比例 | 呼吸倍数 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 无药水，削减为 0 | 0 | 20 | 20 | 1 | 1 |
| 1 | 15% | 0 | 20 | 20 | 1 | 1 |
| 2 | 15% | 1 | 15 | 15 | 0.75 | 1 |
| 3 | 30% | 2 | 15 | 15 | 0.75 | 1 |
| 4 | 30% | 2 | 10 | 10 | 0.5 | 2 |

飞行限制已接到生物、飞行体、悦灵、恼鬼和末影龙的移动。三档竖直速度上限 −0.08，四档 −0.30。已经更快则不再追加。乘客、落地、实际流体不下降。速度夹紧不改摔伤。恼鬼和末影龙只裁追加的竖直段。豁免按实体注册名配置，默认含末影龙。空列表表示谁都不豁免，不会自动回到默认。名单里的生物只跳过潮湿带来的下坠，别的潮湿效果仍在。火种不走这套药水和飞行。

配置里另外几项「是否记录泥土方块、魔法数字、物品列表」会加载进静态字段，玩法代码不读它们，不能当成伤害或冷却倍率。

### 火种

火种是实体上的 0 到 100 整数，不注册药水。0 与无资源相同。读写、预览、扣点和生产只在服务端主线程且目标存活时进行。余额变化会通知客户端显示，那份副本不参与生产和消耗。

一次逻辑施法共用一个施法上下文。同一上下文、同一目标只能生产一次、消费一次。复制体必须复用这个对象。新建另一个上下文，即使标识相同，也是另一本账。生产量是 `floor(基数 × 倍率)`。已满 100 时增加量可以是 0，机会仍记下。消费请求用最大整数表示全部余额；负数不是全部消费。先用同一笔余额做完校验，失败不写余额、不标记消费。

固定点数存入每次新建上下文，倍率固定 1.0，不进入消费者共用批次，也不改生产或消费去重。已接入的存入点包括命中结算、批次接受后的种子、接触附魔、领域接触载荷、剑实体运动和武器附魔。

引爆在分量合格后一次扣完当时可投入的点数。炉心热量作为加成读入快照，不作为第二笔余额。按段燃烧另扣，不占这次施法的引爆机会。同一拍燃料不够时，按需求比例向下取整，余数再按权重分，权重相同则打乱次序。挂载有计划数量上限。同一施法、同一目标、同一效果键重复则拒绝。生物 tick 推进燃烧载体。

死亡清火种键，不动同一复合标签里的其他状态。玩家死亡克隆不再抄回火种。末地回主世界的存活克隆和生物转化只补火种这一个键。下界和末地传送用同一玩家对象，持久数据留在身上。燃烧账在死亡时清除，存活克隆才复制。档位是 `floor(余额 / 10)`，维持 tick 为档位数乘 10。

炉心能按档位和热量算出种子生产倍率：普通档随热量从 1.12 到 1.60，过载为 2.2。主源码里的存入不调用它。存入倍率仍是 1.0。

### 炉心

炉心只服务玩家，分普通与过载两档。进入、升级、结束和主动冷却都先对账。不能从过载降回普通。重复进入同一档会被拒绝。非玩家、客户端、非服务器线程的转换直接拒绝。主动冷却是结束炉心模式的一种操作，不是技能槽的冷却计时。

热量以千分位整数走。在线一拍只加一拍，离线间隔不会被乘进去。普通每拍 +0.002、上限 0.300。过载每拍 +0.003、上限 0.600。

属性改写用同一组修饰器。升级先摘再挂，避免两档叠乘。普通把生命上限乘 0.75，护甲和韧性乘 0.5。过载分别乘 0.6 和 0.25。退出只恢复上限，当前生命保持钳制后的数值，不按新上限比例回填。治疗事件把治疗量乘 0.5，过载乘 0.3。自身抗性提升在玩家带有效炉心时不算减伤。

显式火伤结算读炉心热量加成，并且一帧只结算一次。显式水或冰伤把承伤乘 1.4，过载乘 1.7。没有这层显式元素帧的普通攻击保持原数额。主动冷却先结束模式，成功之后才放一次蒸汽。被动结束和死亡只清效果、存档和修饰器，不放这股蒸汽。技能槽的冷却计时结束也不放蒸汽。

## 球形场地、跟随护体与领域

这三套都占一块空间或一层防护，维持规则各写各的。

| | 锚点 | 存续 | 扣费 |
| --- | --- | --- | --- |
| 球形场地 | 钉在施放时的身体中点。链上索敌和弹道只记在场地上，不挪锚点 | 维护节拍扣得起魔力，并且主人活着、在线、留在放置维度 | 每到维护节拍扣魔力。扣失败、死亡、下线或跨维就拆掉，且不打到期爆发。只有正常到期才打一次中心爆发 |
| 跟随护体 | 中心在主人位置加上身高比例，跟着主人 | 维护扣得起，且未到期、主人未死亡、未跨维 | 维护失败、到期、死亡或跨维就拆。同类再次激活会刷新寿命，并保留动画起点和维护节拍 |
| 领域 | 放置时冻结。脚点为空时盒子落在施放者脚下；不为空时整盒平移到接触点，再按输入放大。不跟着主人移动，也不写成玩家永久状态 | 只看寿命，以及主人存活、在线且留在宿主维度 | 定义上的维护费和周期仍能读出。服务不再据此扣款，也不再形成节拍。开域收初始费乘份数；父会话已经预留时不再扣 |

三套都是服务器内存表。重启不恢复。下线或跨维会关掉该玩家拥有的领域。卸下一个维度只丢掉该维度的偏转宿主，不清领域、护体和水势账。

### 场地重叠时各取什么

施放瞬间数一次包住施放者身体的场地份数。零份或一份时，这一发的伤害倍率是 1。两份及以上，倍率等于份数，并乘进这次伤害。

治疗、牵引、潮湿、灭火、垂落轨迹和锁定各取第一份非零，不累加。跟随是或。周期脉冲里的压强、侵蚀、灭火、潮湿、牵引、减速同样各按一份，不按场地份数乘。卸力另取最大一份，再封顶 0.6，不进入伤害倍率。

治疗量存在场地上，周期脉冲不给治疗。站在场地里的人下次放攻击时，才把场地的治疗、牵引、潮湿、灭火抄进这一发。场地接触附魔只在出生时、且快照接触伤害大于 0 才挂上。

卸力与护体卸力同时存在时，取较大比例减伤。减掉的数额在伤害确认后记水势。护体优先时走护体记录。

### 领域里同时发生的三件事

原生脉冲只做策略里写下的潮湿、减速和水势。潮湿对同一目标在窗口内取更大的一份补差，不重复刷满。减速不盖过更强或更长的效果。水势只给完全处于盒内的友方。策略不执行外接附魔，也不靠受伤换水势。呼吸放大只在倍率大于 1、且目标被判定在敌对侧内部时标记。免疫、创造无敌、水下呼吸或不能在水中溺水则跳过。

封印边界在身体完全进入后，按轴裁切穿出的位移。开放边界不裁。传送不走这套裁切。友方完全在盒内时，所有领域只加一份最大的光环伤害，不附带潮湿、固定水势或灭火。

绑定是第三件事。标记必须紧挨在零伤领域宿主后面。中间夹了别的格，或标记后面没有合格攻击，编译失败，整份布局不可用，投影链不会悄悄丢掉标记继续放。合格攻击是正伤、攻击角色，且不是领域、护体、屏障、条件释放或自身状态。不放多重时，绑定后面有一记合格攻击即可。

绑定后面若能展开多重，捕获看展开结果，不要求必须凑满两记攻击。至少要有一名实际成员，并且每一名都是合格攻击。复制和附魔可以占读取格，只留下一名合格攻击也成立。固定读 2 格因此可以是攻击 A 加攻击 B，也可以更短，或被修饰占去一格后仍只剩攻击 A。没有实际成员才失败。玩家现在能装配的固定读 2 格带有多重展开，走的是这一条。

绑定后面展不开多重、向后扫描才遇到双重角色时，仍走旧兼容：要两记合格攻击。附魔和链上修饰在点数时被跳过，不因为占格本身失败。少了第二记，整条失败。

两条路径都会把标记及其捕获的攻击从当场释放里拿掉，冻成该领域的子计划。当场释放只负责把领域打开。

绑定计划非空时，开域后 20 tick 打第一轮，之后每 20 tick 一轮。采样点在几何内。目标必须存活、非旁观、非主人、非友方，且身体完全在盒内。同距离取标识较小者。没有合格目标，就用该轮种子在球面上取方向，仍可释放。子计划费用不在开域时预扣，由自动执行器另收。失败的轮次不从开域费里退。自动轮不占按键冷却，不推进链进度，不读准星或锁定标记。复制份同一刻发布。多重成员按 3 tick 间距排队。生成点钳在领域体积内。松散成功按计划份数保留；宿主组只认原子回执。人暂时不在时，不会把缺的轮次一次补爆。关域、到期或主人离开宿主维度会使寿命令牌失效，并取消未完成轮次。没有绑定计划的领域不进入这轮调度。

同一主人、同一效果键、同一费用和寿命、同一声明后缀，在同一 tick 的重复放置被当成已经放过。

接触附魔每 2 tick 采样，只对接触伤害大于 0 的快照打开。领域实例的接触费单独记账。屏障、场地、护体和普通攻击不进这本账。按快照里不同基础附魔的种类预扣。这一下没有打出确认的正伤害或吸收削减，预扣退回原法杖和玩家池。

代码里有两份现成领域声明，都是轴对齐盒加原生策略。公共代码不把盒子尺寸写死成某一种天气。

## 条件、障碍、治疗、牵引、偏转与监禁

### 条件查询与按目标付费

公共链只认零伤释放定义上的条件效果。默认没有该能力：单价 0、复制不合并、不承接接触附魔。见到条件释放，普通的立即提交直接拒绝，不用正伤害凑回执。

只读查询能写资源下限、药水仍有效，以及若干条的与。未知标识不命中，这里不发放、不对齐状态。内建可读资源只有潮湿和火种。扫描是施放者同维度周围活体，末影龙部位收成主体。可要求挡方块。全圆为真时不看朝向。关系可换门，现成预设只有敌对捕获，并排除施放者本人。没有或、没有非，也没有任意脚本。

全仓只有一个实现。半径 12，全圆且挡方块。条件是潮湿数值至少 1，且潮湿药水仍在。关系用敌对捕获。排序是潮湿档高的在前，同档更近，再按目标编号。父操作号与目标折叠成子操作号，复制序号不进入编号。同一子号已有预约则跳过。准备失败继续下一个。提交失败退回该目标刚扣的单价。成功才留下这笔。一个都没成功则整段拒绝。中途魔力不够就停下，已经成功的保留。它不刷新已有监禁，也不在扫描快照外补目标。

单价是 40。单价大于 0 时，段预扣只留附魔一次，不含每个目标的 40。成功目标再记进父收据。该实现打开复制合并，基费不乘份数。当场失败会取消本段未提交份额，并退回后面段已经预扣的魔力。延后执行时，若已中止、施放者死亡、换维或蓄力代次变了，取消份额且不再尝试。火种能被查询读到，这个实现不查它。领域绑定的合格攻击排除条件释放。

### 障碍、治疗、牵引

障碍是临时命中体碰撞盒，不改方块和流体。可跟着已有命中体，也可在锚点直接放一块静止盒。服务器 tick 会推动被挡住的身体。定义默认不挡移动。

薄墙放在脚下朝向或冻结接触点。先为墙内实体找让出位置，找不到则整次不放。衰减和是否接弹写在墙定义上，默认不接弹。

治疗是一次 `heal`。命中载荷在非「治疗施放者」时治疗目标；为真时治疗施放者。默认治疗量是 0，默认不治疗施放者。炉心另把一切治疗乘以档位系数。没有持续治疗通道，也没有按属性状态回血的通用规则。场地里的治疗量要等下一次攻击抄走，脉冲本身不回血。

牵引是一次速度增量，朝锚点或施放者。竖直分量再乘 0.25（命中）或 0.2（场地脉冲）。距离过近则不加。默认强度 0。它不锁定位置，也不阻止传送。

### 偏转

注册表为空时没有接触，生产路径不会收购。会真正登记的有五类：

| 宿主 | 何时在表里 | 出口 |
| --- | --- | --- |
| 护体环 | 护体定义打开偏转才登记。中心跟着主人，换代用新的代次 | 环带轨道。构造路线时取一次随机。近战已经提交成功后，只有环会摆水平姿态 |
| 薄墙 | 墙已进世界且定义打开才登记 | 按接触法线反射 |
| 径向弧 | 命中体在活动窗内、模式为径向刃且打开偏转才登记。窗结束即注销 | 沿当前切片运送 |
| 垂幕 | 体积算完后，实体仍声明偏转才登记。空段、死亡或主人不在就注销 | 只用该段水平前方，入射速度不改方向 |
| 监禁壳 | 创建时登记，结束时注销。登记失败不回滚牢 | 向内反射，并把箭身放回壳内。只接受被困者本人从壳内穿出 |

弹体只认原版普通箭和光灵箭。药箭类仍算普通箭。三叉戟和重写命中的子类不进表。判断插在原版穿透查找之前。水比合法实体或方块更远时不接。同一支箭完整承接上限 3 次，达到后不再看。主人和盟友的来弹放行。

近战接在玩家攻击和生物近战上，线段从眼到目标盒最近点。缺省近战拒绝零长度。环改用主人身体的水平外扩包络。

资源从宿主主人的水势扣。门槛和单价用射手或近战攻击者当时的潮湿档，数值见上面的档位表。箭：可用额低于门槛就换下一个宿主；够完整费用则按直接伤害乘该档箭比例整段买下；不够则花光可用额并留下残伤。近战是固定的档位近战费，低于门槛或付不起就是不挡，没有部分挡。完整承接才取消这一拍剩余飞行并按路线放出，箭归宿主主人。部分承接停在这一面，不启动捕获。收购失败且这笔已经占用则停住，否则继续看后面的宿主。异常也停在这一面。

宿主缺省接受一切来向。不打开偏转的护体、墙和命中体不会进表。没有「任意弹体、任意近战、任意条件」的总开关。

### 监禁

监禁是独立运行时：准备、提交、按目标查看、按原因结束、选目标和抑制增强窒息。服务本身不扣魔力。上面的条件释放才按目标收 40。普通移动被拉回锚点。真正传送放行，完成后若坐标或维度变了就破裂。环境伤害每 20 tick 4 点，没有攻击者，不绕过无敌帧。活动结束后仍未扣到的湿度写成世界存档票据，不恢复牢体。登出、跨维、停服和重新进入都有专门回调。它不能把任意效果装进一个通用牢笼。

场地牵引、领域封印裁切和监禁拉回锚点是三套位移规则，不会合成一个约束求解器。

### 幻影

幻影工厂把生成交给现有命中体。返回的句柄永远不活动，结束是空操作。规格只有原点、朝向和寿命三个读取口。没有分身智能，也不代理伤害。

## 世界武器实体

剑实体单独存在。主人标识写入同步数据和存档，并保存状态、已命中集合、追踪、插地方块、召回点和停滞标记。按主人查找只认当前维度里活着的剑。丢出一把剑技载体会取消掉落，改成在世界上生成一把属于该玩家的剑实体。

飞行每拍用碰撞体裁线段，先沿截断后的线段打人，再插地。剑轴与来向平行，剑尖朝方块内，尖约埋入半格。流体不算落地。同一段飞行里每个目标一次，全剑最多 5 个，主人除外。主人在线时伤害走根结算。

悬停满 10 tick 后起飞。悬停期间，自动发射快照朝本轮目标；否则先跟主人视线，带锁定时再朝主人当前标记。起飞后方向冻结，不再跟标记转。

幻剑速度 2.5，80 tick 或飞过 64 格丢弃。真剑速度 1.2，40 tick 后若不是在归标、也没开追踪，就开始坠落；低于世界底再低 8 格则把物品还回主人。幻剑插地满 400 tick 丢弃。插着的方块变空气时，幻剑丢弃，真剑把物品掉出。真剑追踪超时 60 tick 后关掉并清空目标，这只写在剑的飞行步里。

召回可由飞行、停滞、插地进入。命中集合先清空，所以归途可以再打到以前打过的目标，仍受 5 个上限。落点是眼睛外侧 1 格，按每把剑自己的水平方向散开。途中每步最多 1.5 格，这段不裁方块。与主人盒相距 1.2 内收回：幻剑回复固定魔力后消失；真剑优先主手，其次背包，再不行掉落。主人不在时召回改成停滞，等主人回来再收回。

有的剑宿主在脱离一条轨道时会再开一次飞行并打开追踪，出发前先清空命中集合，因此第二程也能重新命中。留下的标记若已经打过则留空，改走剑自己的选敌。这种波次和轨道半径不是所有剑宿主的公共调度。

## 姿态与已经提交的攻击

姿态会话的身份是主人、实体、维度、纪元和递增序号。播放中或暂停中不能直接再采纳一条新姿态。替换才是允许打断当前采样的入口。停止把阶段收成取消，并沿开始时的序号发取消包。已经结束的姿态不能再停。暂停只接受播放中。恢复要求当前是暂停，且时刻不早于暂停起点。死亡、离线、换维会把会话收成取消并抬纪元。

攻击组不能无许可通知。许可必须主人、组标识和动作标识一致。同一组在账本覆盖期内算重复。许可只能消费一次，对不上就不消费。账本每个主人最多 256 条，默认保留 1200 个服务端 tick。正常结束只标终态。死亡、离线、换维和停服才整组清掉。

宿主组只有在回执已经提交之后才发动作通知。通知抛错被吃掉。视觉失败不回滚已经提交的攻击组。无许可的攻击组通知直接拒绝。客户端准入拒绝更旧的纪元和序号。同一条生命里，已取消之后不再接受后续包。已终态只还接受取消包。更旧的修订号也不接受。

姿态命令可以播放、停止、暂停、恢复已登记姿态。命令自己说明不会因此造成伤害，也不改已经提交的攻击几何。

## 学习、刻印、槽位与对外登记

玩家进度写在人物持久数据里：术数据、四个绑定槽、27 格术式收纳。死亡换身体时这三份会抄到新身体上，重生后再同步给客户端。登出时再存一次术数据。

登录时，复杂度为 0 且还没学会的术式会自动学会。通用和动作始终解锁。剑术看剑术等级是否不低于复杂度，法术看法术等级。领域许可可以绕过等级。释放时若链上有领域，而等级和许可都不够，直接拒绝并提示还没学会。

领域进度是后加的。已经学会过的两份旧领域，在登录迁移里各发一次许可，以后即使等级不够也仍算解锁。声明了达级自动学的领域，要等对应剑术或法术等级达到复杂度才补学，而且只补还没学会的。当前这两份会自动学的领域复杂度都是 10。迁移版本是 2。升级成功后会再试一次自动学。等级后来被命令改到复杂度以下时，没有迁移许可的领域会再次放不出来。那两份旧领域因为登录时拿过许可，仍可放。

剑术等级和法术等级上限 20，用来开复杂度和剑技容量。每次成功释放，该系使用次数加一。下一级需要的使用次数和经验都是 `10 × (当前等级 + 1)`。经验从玩家总经验里扣，不够就停在这一级。通用和动作不参与升级。

每个术式还有自己的使用次数。管理界面按一张 0 到 20 的表把它显示成熟练等级、伤害加成、冷却缩短和暴击率。这张表目前只被管理界面读取。释放结算不乘这套倍率。打开管理界面的网络包还在，当前按键和界面都没有发送这个包，所以玩家现在进不去这张表。

四个绑定槽在玩家身上，不在武器物品上，槽号 0 到 3。空链会清掉。术式收纳是玩家身上 27 格。右键术式石塞不进去就提示已满。收纳箱物品右键打开的就是这 27 格，不是箱子自己的独立仓库。打开时还会把旧版匣子物品里的清单搬进这 27 格。

技是玩家装出来的有序链，类型只有剑技和法技。存档记名称、类型、每段术式标识和刻印时的原胚。读回来时不认识的标识会丢掉。旧的纯文本标识仍能读，原胚视为无。展示用的总伤害是各段相加，总冷却取各段乘过原胚冷却系数后的最大值。服务器释放时重新计算，不采用客户端展示数。

剑技容量按剑术等级算：`10 + (max(等级, 1) - 1) × 5`。0 级和 1 级都是 10，满级 20 是 105。超了就装不上。法杖不走这套容量，只受法杖槽位数限制。装配消耗默认是附魔 2、动作 0、有伤害 1、其余 0。释放定义可以自己写死。

刻印台要求已经学会并且当前解锁，原胚槽有原胚、成品槽空着，才消耗一个原胚打出一颗术式石。术式石不能直接释放。右键是尝试收入那 27 格。

现在按装配键打开的是术式石装配界面：左边 27 格收纳，中间是齿轮链。手持法杖时链长等于法杖槽数，关闭时写回这根法杖。手持剑技载体时是 4 条、每条 8 格，关闭时写成玩家四个槽。法术石放不进剑槽。可以按类型和木火水土金筛选。法杖若要求取回，对应格会锁住。换掉这根法杖后界面不再认它。旧的技能装配界面和它的菜单类型还注册着，但没有任何打开它的入口。

别的模组可以在本模组登记完内置内容之后，往同一条链上加术式或附魔。客户端和专用服务器必须登记同一批标识。登记术式必须同时给出术式条目、效果和释放定义，而且两边的标识必须一致。空参数或标识已被占用会拒绝并记一条警告。登记附魔同样要求标识一致，效果标识只能是火、木、水、土、金。没有对外的卸载或热替换。

剑技载体还可以从外面追加判断。剑、镐斧锄铲、三叉戟、工具动作、物品标签之外，别的模组可以再注册一条「这件东西也能当剑技载体」。法杖永远不算剑技载体。未知实现不会因为看起来像攻击就自动打开释放定义上的那些开关。外部术式若要进释放计划缓存，必须自己声明支持，否则整条链不走缓存。

## 性能支持

结构计划缓存默认关闭。未知实现整条链走现场解析。内置登记和水定义显式打开，并要求相关读取没有世界、玩家和时钟副作用。缓存只保存已经解析过的链结构：分段、角色标志、修饰模板、成员下标、份数、锁定、垂落和链输入。费用、伤害、冷却数字、武器、视线、目标和随机结果仍在原来的时刻读取。它不缓存当次资源或当次目标。超过长度或容量的链不放入缓存，这一次改走原来的动态路径，不会因此放不出来。代际变化后旧记录作废。不能据此声称服务端 TPS 提升。详见 [术式链计划缓存说明](术式链计划缓存说明.md)。

同一服务端 tick、同一维度里，密集攻击体和飞剑可以共用一份活物空间候选。每次请求仍按自己的精确范围和原条件过滤。缓存里只有可再过滤的实体引用，不保存能否命中、最终目标、伤害或锁定选择。命中、锁定、伤害、无敌帧和费用仍走原来的实时流程。详见 [候选查询复用说明](候选查询复用说明.md)。

轨迹、转向、追踪步进，以及近战走廊的重叠、接触距离、阻挡，都进纯计算入口。不写启动参数时用 Java 参考实现。公开批量入口条数小于 8 仍走 Java。已经接入的单次计算，在本机库就绪且能力位匹配时，可以按一条进入本机实现。未请求本机库、库路径无效或握手失败时留在 Java。这里不承诺 FPS 或 TPS。详见 [纯计算后端使用说明](纯计算后端使用说明.md)。

`/shuperf` 可录一段服务端 tick，最长 6000 条完整 tick，再导出。这是诊断，不改玩法。用法见 [性能记录使用说明](性能记录使用说明.md)。

## 已有限制与尚未接入

上面各节已经把边界写在对应能力旁边。这里只收最容易看错的缺口：

- 幻影句柄生成后不活动，没有分身智能，也不代理伤害。
- 单术熟练度会记下来并在管理界面换算成伤害、冷却和暴击，释放结算不乘这套倍率。管理界面当前也没有按键入口。
- 技能书右键只念出组成，并提示装配与释放尚未开放。`/shu book bind` 把书里的技写进副手武器的物品数据，提示会显示已绑定技。真正释放读的是玩家四个槽和法杖链，不读这件武器上的书数据。
- 炉心的种子生产倍率能算出来，存入不调用它，固定存入倍率仍是 1.0。
- 领域定义上的维护费和周期还能读，不参与扣款，也不决定存续。
- 场地治疗量要等下一次攻击抄走。场地脉冲不是区域内持续回血。
- 条件查询只有与、资源下限和药水仍有效。不能写成任意条件脚本，也不能把底座当成可任意登记的状态机。属性状态目前只有潮湿和火种。
- 修饰能不能挂上，看宿主声明的能力。落点和交错默认不改屏障、领域、护体、场地和条件释放。链能量不进剑技和无属性。动作和多重、复制声明不承接复制。不同宿主不会自动继承另一类宿主的修饰。

另外这些入口默认不发生，要定义自己打开：持续索敌覆盖、路径覆盖、专用初瞄、弹道可变、操纵世界剑、混链拒绝、重新点按、松开结束、蓄力、水势消耗、重水预算、弧带、拍号、宿主组提交、接弹、持续接触结算。能量和链能量默认 1。场地半径 0 就不是场地。护体、屏障、领域、条件释放、自身状态默认空。内置的固定读 2 格和因子 3 是已经声明过的例外，不是所有攻击自带的多重。

重水的签名还在，新会话不再形成水势预算。波数循环当前不会发出第二波。按住连放不会因为「松开即结束」而提前停掉下一次按键。

## 复杂使用场景

下面只用攻击 A、攻击 B 这类占位。每个场景都写组合、结果、费用或寿命，以及成立前提。

### 1. 多重与复制的作用域

固定读 2 格只能占两格，复制也占一格。就这两格怎么排，能装出来的结果是下面三种。不能在这两格里同时放下「复制、攻击 A、复制、攻击 B」。多重前面还可以另放链能量或落点，那是前缀，不占用这两格。

两名成员、各 1 份：多重后面紧跟攻击 A、攻击 B。A 立刻出手，B 在 3 tick 后。各 1 份，复制份数不大于 1，不开账本。

一名成员、3 份：这两格是因子 3 的复制，然后攻击 A。复制不是时间节点，只有 A 这一名成员，3 份在同一 tick。份数大于 1 才开账本，第一次入账之后 6 tick，按最后一份伤害乘份数做一次玩家攻击。攻击 B 若排在这两格之后，不在这次多重里。弹道不可变的斩击仍只改点和刀面。

复制被丢掉：因子 3 的复制直接顶在多重声明前面，后面才是攻击 A、攻击 B。这一格复制不进费用、也不进冷却。多重仍读 A 和 B，各 1 份，间隔 3 tick。

写在多重声明之前的链能量和落点，作为整段前缀，读到的成员一起继承。链能量仍然只乘进有属性的法术命中体积，剑技和无属性停在基准 1。落点只改接受安置修饰的攻击命中体积。每个原始格只入账一次。被丢掉的复制格不计费。攻击 A 若展开成 3 份，这名成员的魔力按 3 倍计，不是只收一格的价，也不是把复制格再单独收一笔。单价已经写在术式上的，以及声明了复制合并的条件释放，不按这个份数再乘。波数是 1，不会把同一份攻击再拆一串。

扩展接口场景：要让攻击 A 和攻击 B 各自带一份复制，读取格数至少是 4，或者改成读到链尾。当前没有这种可装配条目。成立时，写在某一名宿主前面的复制只乘这一名，不广播给兄弟；成员间隔仍是 3 tick；同一宿主的份数是它收下的因子连乘，不再额外乘 3。外层若再套一层固定次数，前缀的链能量和落点仍给整段继承，层内的锁实体只对接受初瞄、持续覆盖或弹道可变的宿主生效。屏障、领域、护体、场地和条件释放默认不接落点。连乘或费用超出 int 时，付款前整次拒绝。空展开也在付款前失败。

### 2. 领域里的自动攻击链

前提是法术等级已经达到该领域的复杂度，或者这份领域拿过迁移许可，因而已经解锁。链的顺序可以是：零伤害领域、紧挨着的绑定标记、然后攻击 A。攻击 A 必须是正伤、攻击角色，且不是领域、护体、屏障、条件或自身状态。

现在能装配的固定读 2 格走多重展开。绑定后面放上它，读到至少一名合格攻击就成立。两格都是攻击 A 和攻击 B 时，两名都捕获。其中一格是复制或附魔、只剩下攻击 A 时，仍然成立，不会因为没凑满两记而失败。声明要读 2 格、链上却只剩攻击 A 这一名实际成员时，也成立。展开结果里一个实际成员都没有，整条才失败。

旧兼容只在绑定后面展不开多重、向后扫描才遇到双重角色时出现。那时仍要两记合格攻击，附魔和链上修饰会被跳过；少了第二记，整条失败。玩家装出来的固定读 2 格不走这条。

按下释放只打开领域并付开域费。几何钉在当时的脚下或接触点。开域后 20 tick 打第一轮，之后每 20 tick 一轮。每一轮在盒内取一点，朝完全位于盒内、且不是主人或友方的最近活体打出冻住的那一段。没有合格目标就用该轮种子取一个球面方向，仍然可以打空。用的是这一刻主手的武器加成。子计划的魔力由自动执行器另收，失败的轮次不从开域费里退。自动轮不读准星，不占这次按键的冷却。人死、下线、离开该维度或寿命结束，领域和未打完的轮次一起关掉，不会跟到另一个维度，也不会写进人物存档。盒内敌对侧仍按原生策略收到潮湿或减速，友方只可能拿到一份最大光环伤害和水势。这三件事不互相替代。

### 3. 两块场地、一层护体，以及两种资源

施放者先在两个不同的世界坐标各放一块球形场地，再给自己挂一层跟随护体，然后站在两块场地的重叠里打出攻击 A。攻击 A 带治疗、牵引和潮湿。

两块场地的锚点保持放置时的坐标。维护各自扣魔力。任一块扣失败只拆那一块，不打它的到期爆发。只有正常到期才打一次中心爆发。攻击 A 的伤害按 2 倍计算。治疗、牵引、潮湿、灭火各只抄到第一份非零，不按两块相加。卸力取场地最大份与护体份中的较大者，场地份不超过 0.6。减掉的伤害在确认后进入水势。水势预留要等这发真正提交，才从 0 到 100 的余额里减。治疗打在被命中者或施放者身上，是一次性治疗，不是站在场地里持续回血。牵引是朝场地锚点的一次速度增量。护体中心跟着施放者。护体到期或维护失败后环消失，场地不因此移动。三套东西的寿命互不相绑。

### 4. 潮湿门槛筛选，再按目标付费

前提是周围有若干敌对活体，其中一部分潮湿至少为 1 且潮湿药水仍在。施放者打出那条唯一接好的条件释放。扫描半径 12，全圆，挡方块。不满足潮湿的目标不进名单。名单按档位从高到低，同档更近的在前。

段预扣只留附魔那一次，不含每个目标的 40。每个成功目标再从父收据扣 40。某个目标提交失败，只退该目标刚扣的 40。一个都没成功，整段拒绝，并退回后面段已经预扣的魔力。中途魔力不够就停下，已经成功的监禁留下。它不刷新已有监禁，也不补扫描快照之外的目标。火种即使很高，这条实现也不拿它当门槛。复制打开了合并，基费不乘份数。

### 5. 同一目标资源的积累与两种消费方式

前提是目标活着，施放者带着普通或过载炉心。一次攻击结算、一次接触和一次武器附魔各自新建施法上下文，所以三次都能按固定点数存入，互不占用生产名额，倍率都是 1.0。炉心查询里的 1.12 到 1.60 或过载 2.2 不参与这三次存入。若三次故意复用同一个上下文，第二次起对这个目标的生产会被拒绝。已满 100 时增加量可以是 0，这一次生产机会仍然用掉。这些存入进的是这一个目标上的同一笔火种余额。

引爆和分段燃烧是这笔余额的两种消费，共用同一个数。引爆在校验通过后一次扣完当时可投入的点数，并打一记火伤。若这一下把当时能投入的火种扣尽，已经挂上的分段燃烧就没有这笔燃料可用。分段燃烧不占引爆名额，也不会在引爆之后自动补回同一笔余额。之后只有新的合法存入，才会再有余额。余额还在、同一拍又不够分时，仍按需求比例向下取整，余数再按权重分。同一施法、同一目标、同一效果键的重复挂载会被拒绝。玩家死亡后火种和燃烧账都没了。若只是存活维度回传，火种整数还在，燃烧账按存活克隆规则复制。

### 6. 自身状态换上炉心

前提是这条链里只有自身状态，没有别的有效段。它要求松开后再按。技能槽的冷却走完不会自动再放，也不会因此放蒸汽。按下时先看炉心能不能变成目标档，并且魔力够不够。不够，或重复进入同一档，或试图从过载退回普通，都不改炉心，不进入技能槽冷却，这次按键结束。扣款成功才改炉心。炉心没改成则退款。这条链里没有后续段。

进入普通后，生命上限乘 0.75，护甲和韧性乘 0.5，受到的治疗乘 0.5。进入过载则分别是 0.6、0.25 和 0.3。热量只在在线时每拍加一拍：普通 +0.002，上限 0.300；过载 +0.003，上限 0.600。显式水或冰伤按 1.4 或 1.7 放大。没有显式元素帧的普通攻击数额不变。被动结束或死亡只清效果和修饰器，不放蒸汽。退出只恢复上限，当前生命保持钳制后的数，不按新上限比例回填。主动冷却会先成功结束模式，然后放一次蒸汽。

### 7. 宿主组提交之后，再取消姿态

前提是攻击 A 在宿主组登记表里。要预留的个数，是每一份复制再按全局实体倍率展开。少一份，这一波已留的份额全部取消，不生成。必需份数都成功，才提交一次，然后才拿到许可去播攻击组姿态。实体倍率不单独打开账本。

姿态随后被停止、替换，或因为断线收成取消，都不收回已经提交的命中几何。通知播放失败同样不回滚。无许可的攻击组通知直接拒绝。同一组在姿态许可的覆盖期内，重复许可不会再消费。这本许可账和下面的 6 tick 伤害账不是同一本。死亡、离线、换维和停服才把许可账整组清掉。复制份数大于 1 且没有持续接触时，6 tick 后走根伤害，暂时让出无敌时间。同一本账本在持续接触打开后改为尊重无敌帧，载荷只在正伤确认后施加。复制份数不大于 1 时没有这本 6 tick 账：普通命中走根伤害，持续接触则当场走确认伤害。

### 8. 用潮湿档买下一次偏转

前提是施放者身上有一层打开了偏转的护体，或者一面打开了偏转的薄墙，并且水势够用。来的是普通箭或光灵箭。门槛和单价看射手当时的潮湿档：0 档和 1 档门槛 20、箭比例 1、近战费 20；2 档和 3 档是 15、0.75、15；4 档是 10、0.5、10。

可用额低于门槛，这个宿主让给下一个。箭够完整费用就整段买下，取消这一拍剩余飞行，按该宿主的路线放出，箭归宿主主人。同一支箭最多完整承接 3 次。钱不够完整费用时，花光可用额并留下残伤，停在这一面，不启动捕获。近战没有部分挡：低于门槛或付不起就是不挡。主人和盟友的来弹放行。三叉戟不进这张表。没有宿主注册时，收购直接失败，水势不动。护体跟着主人移动；墙钉在放置时的位置。两者的水势都从宿主主人的那本 0 到 100 的账里扣。

## 命令

都需要权限 2，除了客户端的 `/shulog`。

- `/shu give`：给空白原胚和木属性原胚。
- `/shu stone <术式标识>`：按标识给一颗术式石。
- `/shu list`：列出已登记术式。
- `/shu learn <术式标识>`：学会一条。
- `/shu reset`：重置术数据。
- `/shu mana <上限>`：设置魔力上限并补满。法杖加成仍额外加上。上限至少为 1。
- `/shu rank`：查看剑术和法术等级。`/shu rank sword <等级> [熟练点]` 与 `/shu rank magic <等级> [熟练点]` 修改对应一系，等级 0 到 20。
- `/shu cd`、`/shu cd off`、`/shu cd on`：查看或开关全部释放冷却。
- `/shu entities <数量>`：每个本来生成 1 个实体的生成口改为生成这么多个。范围 1 到 4096，全服一份，默认 1，不进存档，重启回到 1。宿主组里，每一份复制都按这个数量展开；少一份就取消这一波已留的魔力份额。它不是另一条复制声明，也不单独打开 6 tick 伤害账。
- `/shu book give sword|magic|cross_slash`、`/shu book write`、`/shu book list`：发放、写入或列出技能书。
- `/shu book bind [1-4]`：主手技能书、副手武器。把书里的技写入武器物品数据。这不写入玩家四个释放槽。
- `/xuexi action play|list|stop|pause|resume`：只操作已登记姿态，不造成伤害，不改已提交的攻击几何。
- `/shuperf start [tick数]`、`stop`、`status`、`export`：服务端诊断。目标 tick 为 1 到 6000。
- `/shulog on|off|clear`：客户端调试记录。开发环境默认开着，正式包默认关。关闭后不留内容，最多留 200 行。
