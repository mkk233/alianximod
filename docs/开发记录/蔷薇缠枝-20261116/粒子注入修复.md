## 根因

用户日志要求的 handler 是：

`(Lnet/minecraft/core/particles/ParticleOptions;Lnet/minecraft/core/particles/ParticleOptions;DDDDDD)Lnet/minecraft/core/particles/ParticleOptions`

原 handler 只有 `(ParticleOptions;DDD)ParticleOptions`。日志指出 index 1 收到 double，但期望 `ParticleOptions`。

## 签名证据

Forge 1.20.1/47.3.33、Parchment `2023.06.26-1.20.1` 的本地 recomp 构件中，`ParticleEngine.createParticle` 的真实描述符是：

`(Lnet/minecraft/core/particles/ParticleOptions;DDDDDD)Lnet/minecraft/client/particle/Particle`

Mixin `0.8.5` 的 `Injector` 常量包含错误模板：

`%s has an invalid signature. Not enough arguments: expected argument type %s at index %d`

`ModifyVariableInjector.inject` 的字节码先压入被修改值，再调用 `pushArgs` 按目标方法参数顺序压入捕获参数。因此 `argsOnly=true` 时，handler 必须是“修改后的值 + 原方法全部参数”。这里就是第二个 `ParticleOptions` 加六个 double，不是把原粒子参数放到末尾。
