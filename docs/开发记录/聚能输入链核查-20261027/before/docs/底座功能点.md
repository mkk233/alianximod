# 底座功能点

本文描述当前代码的拼接行为。新术式登记 `ChainRole`，走同一套收集和结算。不按术式 id 单独接落点、弹道、规则或附魔。`ChainRole` 只有这 8 个值，不新增。

结算顺序是索敌 → 弹道 → 规则 → 攻击。修饰术式自己不造成这次攻击，必须挂在后面的攻击术式上才生效。离攻击更近的同类修饰覆盖更远的那条。

魔力花费是 `ceil(基础伤害 × 2)`。规则术式花费为 0。附魔另按附魔定义计算。

## 角色

| 角色 | 已登记术式 | 作用 |
| --- | --- | --- |
| `ATTACK` | 下面的攻击列表 | 这次释放的载体 |
| `ACTION` | 冲刺 | 动作。后面的攻击由它带出 |
| `SEEK_SPACE` | 落点指定 | 决定生成位置，不改弹道种类 |
| `SEEK_ENTITY` | 锁定实体 | 标记生物。可变弹道会朝标记飞 |
| `TRAJECTORY_DROP` | 垂落术式、风暴轨迹 | 覆盖可变弹道的曲线。两者靠 `Trajectory` 区分，不另开角色 |
| `TRAJECTORY_SCATTER` | 三维交错 | 改弹道散布，不做索敌 |
| `RULE_TRIPLE` | 一分为三 | 把后面第一个攻击复制三份，伤害汇总 |
| `RULE_DUAL` | 双重释放 | 带上下一个，再加后面两个；实际攻击按顺序放 |

`trajectoryMutable == false` 的斩击只改生成位置，形状不变。`trajectoryMutable == true` 的攻击可以改曲线。

## 索敌

**锁定实体。** 准星方向 20 格内、离视线 8 格内最近的生物。找到则标记并发光，找不到则清标记。可变弹道朝该生物飞行。生成位置不因这次索敌改变。

**落点指定，用在可变弹道上。** 边长 3 格的立方体里均匀取点。中心是准星射线打到的方块，射线最长 32 格；方块前 1.5 格内有生物时，改用该生物中心。攻击自己的发射方式保持不变，只是从这些点发出。

**落点指定，用在斩击上。** 仍用斩击锚点：视线 8 格内离准星线段最近的生物中心，没有生物则是眼前 4 格。刀面的高度、倾角和旋转仍走原来的斩击散布。次元斩走这条，不走弹丸的立方体。

## 弹道

同一条链上有多条弹道术式时，离攻击更近的那条生效。

**垂落。** 只改高度，水平位置留在已经选定的点上。从该点上方 8 格出现，再按 0.08 格/tick² 自由落体。不沿准星平移，也不把所有弹丸收到同一个水平坐标。

**风暴轨迹。** 龙卷风。落点是准星打到的位置；光线上有生物时用该生物中心。没有装配落点指定时也会取这个落点。弹丸从落点上方 12 格、半径 5 格的圆周出发，转 3 圈并收到落点。多发按黄金角错开，铺在同一条漏斗上。寿命的前三分之二用来旋转，之后停在落点，直到寿命结束。持续术式跟着这条路径移动，到达后留在落点继续生效。速度为 0 的持续术式也会转。生成点在螺旋顶部，不先放在落点上，避免起飞前打中目标。

**三维交错。** 只改弹道。前面没有其他索敌时，在玩家身体周围 3 格立方体内取点，低于脚底的点抬到脚底，再沿随机三维方向射出。和落点指定一起用时，位置留在落点立方体里，方向改为随机。斩击不套这套随机向量。

立方体取点先把序号打散再抽样。连续序号不能直接交给 `RandomSource`，否则第一轴几乎不动，点会排成一条线。

## 规则与附魔

**一分为三。** 后面第一个攻击执行三次。三份共用一本账，大约 6 tick 后一次结算，伤害乘命中份数。不改无敌帧。

**双重释放。** 带上下一个术式，再加它后面两个。有伤害的术式按装配顺序逐个释放，间隔 10 tick。修饰不占这一拍。只有一个有伤害的术式时不多放一份。同组仍共用这次的弹道，下一发不出生在上一发的命中点。魔力按每个实际放出的攻击自己计算，不再把同一个攻击的波次乘 2。

**聚能。** 规则术式，自己不攻击。把后面这次攻击的能量乘 2，碰撞体积跟着变大。热光束的截面按同一倍率放大，能量为 1 时仍是信标粗细；水带宽度也乘这个倍率。多挂一条再乘一次。双重释放带出的几发攻击共用这一次加成。伤害、冷却、持续、距离、搜索和速度不乘。不另开 `ChainRole`，加成写在 `chainEnergyScale()` 上。

**附魔。** 不占规则释放位，记在后面第一个攻击上。没有攻击时记在主手，下一次普通攻击消耗。点火是附魔，不是爆炸。

## 命中

攻击体积由 `TechniqueHitSpec.spawn` 生成，命中在 `TechniqueHitEntity` 上判定。每发各自记录已经打中的目标，同一发不会对同一目标重复结算。

能量层是所有术式共用的来源大小，写在释放定义的 `energyScale()` 上，默认 1。链上的聚能再乘 `chainEnergyScale()`。碰撞体积的倍率是能量乘上附魔里已经含有元素反应的半径。长、宽、高和弹丸模型一起乘。倍率为 1 时尺寸不变。爆燃的爆炸半径用同一个倍率，默认仍是 3 格。伤害、冷却、持续时间、距离、搜索和速度不乘能量。

潮湿是第一种属性状态药水。精确值 0 到 100，由术式调用 `WetnessState.grant` 累加。1 到 25、26 到 50、51 到 75、76 到 100 四档，每次成功施加都刷新 50 秒。到期或效果被移除时数值归零。站在水里不会自动挂上。现有攻击没有调用它，所以旧术式的命中不变。

龙卷风的落点如果在目标身上，不能把实体先放在落点再拉到天上。那样会在飞行前结算，并把真正落下时的命中用掉。

水势记在玩家身上，和魔力分开，0 到 100，多出来的丢掉。出手时若这发声明了消耗，先扣预留；没打中也扣。实际打出的伤害和实际受到的伤害随后再加。同一发不能花自己刚加上的水势。蓄力被打断时预留退回，不放收招。只有声明了蓄力拍数的术式才等待，旧术式仍是立刻放出。

魔力仍按伤害向上取整乘 2。释放定义若写了 `explicitManaCost()`，这发改用那个数，防御和治疗不会因为伤害是 0 就变成免费。

场地是高级附魔，可以单独放。锚点钉在施法时的身体位置，索敌和弹道不挪这个点，只记在场地上。一分为三直接生成三块，生成费先按块数收齐，维持费各自再扣；扣失败、死亡、下线或换维度，这块就拆掉。之后在场地里放的术式，伤害按身体同时被几块包住来乘：一块是 1 倍，两块是 2 倍。索敌、弹道、治疗、牵引、潮湿、灭火各只套用一份。灭火只熄灭生物身上的火。凝结障碍走原来的命中体，挡住移动，不改方块和流体。幻影只有生成契约，没有分身。

旧术式不填这些字段时，消耗、弹道和伤害算法保持原样。人站进场地后再放，才会吃到上面的场地规则。

留下的水系术式是水刃、水幕、水雾、水环、深海重压、让锋、缺月、垂丝，复杂度都是 0，登录就会学会。水刃、水幕、水雾、水环、深海重压走 `WaterFormEffect`。缺月走函数曲线。垂丝是水帘，命中盒子只覆盖当前还在的那段水，聚能只加宽加厚。让锋和缺月是水属性剑术，只能装进剑技，法杖不能装配也不能释放。让锋先在身前铺开水面，再从中间劈开；水分开没有伤害，只有中间那一刀，伤害 40，冷却 600 tick。水幕会在身前放一块会挡人的水墙，并削去站在场地里受到的一部分伤害，削掉的数值记进水势。深海重压保持删掉前的效果：半径 5、持续 100 tick、减速、潮湿、压强，到期中心爆发 14。潮印仍是灭火附魔，断潮仍是不可变的水切。缠绕也还没有。

`/shu entities <数量>` 只放大攻击体积和幻剑的生成次数，范围 1 到 4096，默认 1。不放大魔力、冲刺、剑来和万剑归宗。额外副本使用不同的结算序号，避免被汇总账当成同一发。

## 攻击载体

可变弹道：奥术飞弹、热光束、持续试射、金针、寄生种子、幻剑术、火球、爆燃。

不可变弹道：刺击、横劈、竖劈、空间切割、断潮、岩槌。

操纵剑实体：剑来、万剑归宗。万剑归宗拒绝和其它术式混在同一条链里。幻剑仍要手持剑才生成。

火属性零件是火球、爆燃、风暴轨迹。下面这些名字不注册，由零件组合出来：

| 想要的效果 | 装配 |
| --- | --- |
| 火焰风暴 | 风暴轨迹 + 火球 |
| 火雨 | 垂落 + 落点指定 + 一分为三和/或三维交错 + 火球 |
| 陨石 | 垂落 + 爆燃 |
| 爆炸 | 爆燃 |

火球：伤害 5，速度 1.2，40 tick，命中点燃 4 秒。爆燃：伤害 8，速度 0.6，40 tick；撞到生物或方块立刻爆炸，否则到期爆炸。半径 3 格，只爆一次，点燃 4 秒。

次元斩仍是：落点指定 → 一分为三 → 三维交错 → 空间切割。需要点火时把点火挂在空间切割上。

## 测试指令

权限 2。

- `/shu mana <上限>`：设置魔力上限并补满。法杖加成仍额外加上。
- `/shu entities <数量>`：技能生成实体的全局倍率。
