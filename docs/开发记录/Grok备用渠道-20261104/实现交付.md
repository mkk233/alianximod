## 自动切换

触发：该 task 最新 Cursor attempt 的 stderr 或 `type=error` 事件匹配规则 `cursor-weekly-limit-v1`，即 `ActionRequiredError: Weekly usage limit reached.`。lifecycle 必须仍是 `failed`，且没有协议异常。然后写入 `failureKind=cursor_quota_exhausted`、脱敏 `quotaEvidence` 和 `fallbackEligibility=eligible`。同一次调用不启动 Grok。

不触发：普通 429、网络、认证、审批拒绝、编译失败、结果正文或工具输出里的相同句子、模型自报、缺终局，以及配额句子伴随协议异常（`blocked_protocol`）。

调用：主会话对账后执行 `Resume -UseQuotaFallback -ResumeReason <对账>`，需要写时另加 `-WriteMode`。启动器复核 eligible、父 attempt、身份、输入版本、授权、写路径、依赖、进程戳和排他锁。通过后持久化预留 UUID，再启动 Grok。

恢复：每个 task 只切换一次。`grokLaunch=starting` 时返回 `session_uncertain`，不生成第二个 UUID。`grokLaunch=none` 且意图为 `reserved` 时，只重用该 UUID 的 `--session-id`。切换后的普通 Resume 只 `--resume` 同一 Grok 会话。Grok 失败保持失败，不回 Cursor，不换模型。

## 会话与终局

Grok 首次 `--session-id`，之后 `--resume`，二者互斥。stdout 必须是唯一 JSON 终局。`stopReason=end_turn` 且 sessionId、cwd 一致时 lifecycle 为 `reported`，再单独解析 `<<<CURSOR_TASK_REPORT>>>`。退出非 0、error 对象或其他 stopReason（含 `max_tokens`）为 `failed`。退出 0 但没有可识别终局为 `missing_result`。多个终局、会话或目录不一致、`modelUsage` 出现未批准模型为 `protocol_error`。缺少 `modelUsage` 记 `modelAssurance=unverified`，不伪造 wire 模型。`reported_done` 且 `writesSettled=false` 保持原值。退出码 0 不代替有效报告。

实际参数：

- 没有证据的 `Start` 仍走 Cursor。
- `Start -UseQuotaFallback -AccountQuotaEvidence <绝对路径>` 在证据有效时直接建立新的 Grok UUID 和任务状态，不调用 `create-chat`，也不写 Cursor UUID。
- `Resume -UseQuotaFallback` 不带证据时，仍只认本 task 最新 Cursor attempt 的周额度失败。
- `Resume -UseQuotaFallback -AccountQuotaEvidence <绝对路径>` 用于尚未切换的 task。最新 attempt 必须是已收束的 `failed`。TLS 或其他普通失败保持原 lifecycle，不会被改成 quota，也不会伪造 Cursor attempt。审批拒绝返回 `approval_not_bypassable`。协议异常返回 `protocol_unresolved`。取消、缺终局、中断或未收束进程不能换渠道。
- 每个 task 仍然最多切换一次。之后普通 `Resume` 只续原来的 Grok 会话。额度恢复后，新 task 不带证据就回到 Cursor；已经在 Grok 上的 task 不自动切回。
- 证据不提高读写、编译或文件权限，也不重置复审额度。启动器把 `launcherProvesAccount=false` 写入回执。它不能自动证明当前登录，主会话必须核对 `currentLoginScope`。

`sourceKind` 也可以是 `user_confirmation`，此时 `sourceLocator` 写非秘密的聊天或消息定位。`verified_attempt` 会只读复核来源错误通道里的周额度句子；对不上就拒绝，并且不改来源文件。确认时间到 `validUntil` 不得超过 14 天。过期返回 `evidence_expired`。`invalidated=true`（例如 `invalidReason=quota_recovered` 或登录已切换）返回 `evidence_invalid`。`currentLoginScope` 与 `accountScope` 不同返回 `account_mismatch`。含 token、key、cookie、base_url 或 Authorization 的文件返回 `unsafe_evidence`，不把秘密写入回执。
