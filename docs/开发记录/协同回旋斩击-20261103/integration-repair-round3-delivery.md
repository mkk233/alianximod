# 协同回旋斩击第 3 轮返修

这一轮只修冲刺的后续接触。前面六项没有改回去。

## 后续接触

每次合法接触生成一个 `ContactStrike`。它有自己的标识、账本、守卫和发布槽，不再占用第一次接触的槽。第二个目标的点、方向和目标标识进入这一次体积，不会复用第一下的玩家体积。

同一名目标只进入一次。冲刺窗口原有的去重还在。一次接触里玩家和分身共用这一次的攻击份额，只提交一次。第一次使用开族时已经挂上的攻击份额；再往后的接触只另收同样的攻击金额，收不到就不发出。回旋或冲刺的动作费、协同费不按接触重收。技能冷却也不按后续接触再叠一次。

## 目标消费

`TechniqueHitSpec.localTargetId` 在生成时抄进 `TechniqueHitEntity.contactTargetId`。体积仍先按范围扫描。指定目标再走同一套 `contains` 和 `TechniqueHitSettle.tryHit`，已经命中过的目标不会再记一刀。没有接触目标的旧体积不读这个字段。

没有跑 Gradle，也没有进游戏。本阶段实现额度已经用完，这次返修没有追加复审。
