## 几何和落点

1. 先沿用旧规则得到这一发的竖直落柱。有落点立方时，每一份仍用自己的散布点再抬高 8 格；没有立方时，起点仍是原来的中心正上方 8 格。水帘这类本来就不抬高的宿主，不以眼高再加一次 8 格。接触点若已换掉抬高后的原点，不再补一次抬高。领域只在原点缺失时抬一次。
2. 从该落柱向下，只在已加载区块里找第一个碰撞顶面，作为这一发的固定锚点。射线不穿过碰撞体，也不为了看见地面去加载区块。起点已经贴在承托面上（竖直高差小于 0.05 格）时不横移。落柱所在区块未加载时也不横移。整段都没有碰撞时，锚点取扫描能到达的最低处，斜线仍汇向这条柱，而不是停在眼高。
3. 倾角 θ 在 0° 到 30° 之间，水平方位绕竖直轴取一整圈。种子来自这一次释放，并混入复制序号、生成序号和落柱水平坐标。生成后把起点、锚点和朝向留在实体上，飞行中不再抽签。
4. 新起点的高度与旧竖直起点相同，水平偏移是 `高度 × tan θ`。公共采样仍是 `0.04 × age²` 的竖直位移。消费层用这段竖直位移占整段高度的比例，把水平偏移收回锚点。落到锚点高度时水平位置与旧落柱重合；竖直节奏和宿主寿命、速度都不变。

斜线提前碰到障碍时，仍走该宿主原来的碰撞，不为了抵达锚点穿墙。

## 原生路径和显式垂落

显式垂落指链上垂落修饰把这一发的路径改成垂落，且宿主接受这次改写。判定看的是这次路径覆盖确为垂落，不是宿主注册轨迹是不是 `DROP`。风暴复用垂落角色，但它的弹道是涡旋，不会被当成垂落。

保持原行为的有：

- 未装配垂落修饰时的本体原生竖落（持续试射）。它自己的 `dropThisCast` 不会触发倾斜。
- 寄生种子没有垂落修饰时的竖直陷阱下落。
- 陨岩没有垂落修饰时的抛物线，以及命中实体后沿当时步长继续飞、再按原规则触地的后续。继续飞行的子体不重新抽倾角，也不改地形安放。
- 风暴的涡旋、喷涌、未装垂落的幻剑视线方向。
- 不可改弹道的斩击。它们不会因为垂落修饰被转成飞弹或旋转刀面。

接受显式垂落后会倾斜的有：弹道可改、或声明接受路径覆盖、并且这次确实改成垂落的命中体，包括挂上垂落的陨岩，也包括注册轨迹本来就是垂落的持续试射。是否倾斜不看注册默认轨迹。寄生种子在显式垂落下仍用陷阱运动，但每颗种子按自己的散布落柱单独倾斜，运动中不再把方向改回正下方。幻剑在显式垂落下从抬高后的落柱斜向锚点直线飞，速度仍是幻剑自己的速度；悬停结束不再改回主人视线或锁定目标。该标记随剑的存档保存。

没有落点立方时，同一次生成里的额外实体共用原来的落柱，但倾角样本按生成序号分开。一分为三和复制不改份数，各自保留已经分开的落点。

## Java 与原生

公共 `DROP` 公式两边都没改，仍是起点正下方的二次下落，方向 `(0, -1, 0)`。斜向只发生在 `DropMotion`：用采样给出的竖直位移构造斜向位置和固定朝向。没有锚点时，位置和朝向与采样结果相同。因此旧的原生库和新的 Java 公式不会走出两种竖直下落。

追踪在还没有咬住目标时，落在这条斜线上；咬住之后仍按原追踪转向，步长仍取公共采样的间距。不改选敌。
