# 交接：对外注册口（2026-10-16）

给下一会话落地第一刀。代码还没改。已经在跑的行为以 `交接-2026-10-16-当前进度.md` 为准。设计全文在 `superpowers/specs/2026-10-16-对外注册口-design.md`。

## 已经定的

两边都要：别的模组能登记新术式；本模组以后也要认别的模组的剑、法杖、魔力。先做对外登记。

用本模组自己的 MOD 事件总线，在 `ModTechniques.registerAll()` 之后抛 `RegisterXueXiContentEvent`。

- `registerCast`：一次写入术式、效果、`ReleaseDefinition`。
- `registerEnchantment`：只登记附魔。`effectId` 仅限现有五行，否则拒绝。
- 已有 id 不能覆盖。
- `ReleaseBatch.open` 对 `"rule_cast_anchor"` 的 id 判断改成读 `ChainRole.SEEK_SPACE`。

构造函数里的 `modEventBus` 目前是局部变量，落地时要留下字段再 `post`。

## 不要做

新 `ChainRole`、新附魔元素、`SkillCarrier`、第三方魔力、术式名单同步包、数据包 JSON、没接线的载体或魔力方法。不要把 `phantom_sword` 标成操纵剑。

## 调度

```powershell
grok -p "任务" -m deepseek-flash --cwd D:\alianximod --no-subagents
```

通读用 `deepseek-flash`，改文件用 `deepseek-v4-pro`。需要读仓库或改文件时不要加 `--max-turns 1`。
