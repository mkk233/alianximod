## 模组概述

这是以剑诀与术法组合为核心的 Minecraft Forge 模组（MC 1.20.1）。名称取道法仙术，不用西幻法师、奥术或修炼境界。剑修与法修只是两种用法：剑修以剑诀御剑，法修以法器施展术法，二者可以组合。基础法器是伞。施法消耗法力，不使用灵力，也不把法力写成修炼产物。代码标识不改。核心思想：通过基础的**术**组合成**技**。

- 例：剑术「刺击」+ 动作「冲刺」→ 剑技「突击刺击」
- 例：术法「灵符」+ 术法「点火」→ 法器技「引火灵符」

## 核心系统

### 一、术系统（基础单元）

术是最小的单一功能单元，分为4类：

| 类型 | ID | 说明 | 示例 |
|------|------|------|------|
| 剑术 | sword | 近战攻击类 | 刺击、横劈、竖劈 |
| 动作 | movement | 位移/身体动作 | 冲刺、跳跃 |
| 术法 | magic | 术法效果类 | 灵符、点火、生成水 |
| 通用 | universal | 可用于剑技和法器技 | 锁定实体 |

**术的组合规则：**
- 剑技只能使用：剑术 + 通用
- 法器技只能使用：术法 + 通用

**术的熟练度系统：**
- 每个术独立计数使用次数
- 使用包含该术的技时，对应术熟练度+1
- 熟练度提升属性：释放速度、伤害、暴击率、消耗
- 后期可通过工作台消耗原版经验值快速提升

**术的绑定规则：**
- 剑术 → 只能绑定剑/近战武器
- 术法 → 只能绑定法器，基础法器是伞
- 通用 → 都可以绑定

### 二、技系统（术的组合体）

技是术的最终表现形式，由玩家自行组合命名。

**创建流程：**
1. 在「技法撰写台」选择技类型（剑技/法器技）
2. 从可用术列表中选择组合
3. 自定义命名
4. 输出技物品（剑技=剑谱造型，法器技=符箓造型）

**绑定流程：**
1. 在「技法刻印桌」放入武器
2. 放入技物品
3. 选择绑定槽位（1-4）
4. 输出绑定后的武器

### 三、操作绑定

| 按键 | 功能 | 说明 |
|------|------|------|
| 左键 | 原版挥砍 | 不影响正常攻击 |
| 右键 | 技槽1释放 | 剑技或法器技 |
| C键 | 技槽2释放 | |
| V键 | 技槽3释放 | |
| R键 | 技槽4释放 | |

### 四、GUI系统

1. **术管理界面** - 查看已学习的术、熟练度、属性
2. **技法撰写台** - 组合术→技的界面
3. **技法刻印桌** - 绑定技到武器的界面
